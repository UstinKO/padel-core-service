# LFPT-1488 — Все уровни: сервер

Статус: approved (прямое задание пользователя 27.11.2026). Расширяет #1009; интерфейс #1489.

Единственное открытое значение мероприятия — существующий `TODOS`. Оно доступно в серверном списке категорий для всех форматов/полов; действующие создание, сохранение и копирование используют его без миграции.

При `TODOS` каждый существующий участник должен иметь реальный уровень профиля. Разница ступеней и сумма пары не ограничиваются, резерв зависит от действующих правил вместимости. Для отсутствующего уровня сохраняются PlayerLevelRequired / PARTNER_LEVEL_REQUIRED. Новый гостевой профиль создаётся существующим отдельным процессом; эта задача не вводит обязательный аккаунт или сбор нового поля гостя.

Пустая категория и SIN_ESPECIFICAR не обозначают открытое мероприятие и отклоняются при самостоятельной записи. Конкретные категории и исключения существующих открытых форматов сохраняются. Права не расширяются. UI и локализация существующих поверхностей — #1489.

Проверки: матрица форматов/уровней, оба существующих участника пары, конкретные категории, вместимость, сохранение/копирование/роли в совместной браузерной приёмке.

Уведомления: сохранённый токен TODOS в названии события локализуется по языку адресата писем и Telegram. Внутреннее значение и сохранённое название не переписываются; другие слова и категории не меняются.
