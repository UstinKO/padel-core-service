# LFPT-0936: Короткая ссылка для рассылок WhatsApp

Задача: #936.

Публичный GET /wa-broadcast возвращает 302 на испанскую главную со списком
турниров. Метки: whatsapp / messaging, кампания whatsapp_broadcast.
Ссылка общая для всех турниров. Источник регистрации сохраняется по
существующим правилам атрибуции, а турнир определяется по самой записи.

Используется существующий MarketingRedirectController. Входные параметры
запроса не меняют назначение. Правила согласия на аналитику и остальные
маршруты сохраняются.

Проверка: запрос гостя без авторизации возвращает 302 на точный URL с
UTM. После выпуска проверить переход из рассылки и источник тестовой
регистрации на выбранный турнир.
