# LFPT-0906: Feature frontend UI v2 — главная и каталог мероприятий на реальном API

## Статус
done

## Источник
[GitHub issue #906](https://github.com/UstinKO/padel-core-service/issues/906), напрямую из issue.

## Контекст / зачем
Перенести главную и каталог из визуального направления UI 0.7 на production-каркас React. Источник данных — публичные контракты #898, без fixtures, demo session и клиентских расчётов вместимости.

## Связь с MASTER.md
Правила форматов, регистрации, резерва и оплаты не меняются. Сервер определяет формат, модальность, вместимость и доступность записи. Каталог исключает скрытые мероприятия; переход к деталям использует действующий `/torneo/{id}` до реализации #907.

## Требования
- Главная `/preview/`: hero, реальные счётчики, каталог, шаги участия и FAQ в визуальном языке UI 0.7.
- Каталог `/preview/torneos`: формат, категория, уровень, модальность, клуб и диапазон дат; серверная пагинация по 12 карточек.
- Фильтры и страница хранятся в query URL. Изменение фильтра сбрасывает страницу; back/reload сохраняют выбор. Некорректный номер страницы безопасно нормализуется.
- TanStack Query, отмена устаревших запросов через AbortSignal, отдельные loading/empty/error/retry. Ошибка списка клубов не блокирует остальные фильтры.
- Карточки показывают серверные PLAYERS/PAIRS, свободные/занятые места, резерв, `registrationOpen`, цену/валюту и статус. Никакого пересчёта мест и прав из строк статуса.
- Время форматируется через Intl в `America/Argentina/Buenos_Aires`. По умолчанию каталог начинается с текущей даты этой зоны.
- ES/RU/EN, доступные подписи, клавиатурный focus, responsive 320/390/1440 px, reduced motion.

## Вне скоупа
Переключение production `/` и `/torneos`; карточка события/клуба, авторизация, запись, live-экраны, новая бизнес-логика и переработка серверной локали. Существующие страницы foundation/components остаются служебными.

## Изменения в системе
### API
Клиент использует `GET /api/public/home`, `/catalog`, `/clubs` из #898; типы согласованы с OpenAPI. Мобильные API не меняются.
### БД
Без изменений.
### UI
`HomePage`, `CatalogPage`, `Catalogue`, `EventCard`, существующие layout/токены. BrowserRouter под `/preview`, никаких hash-route и demo query-параметров.
### Документация
Обновить `frontend/README.md`, `docs/frontend-react/contract/screens.md`, `docs/frontend-react/plan.md` и `.agents/PROJECT.md`.

## Критерии приёмки
- [x] Реальные API формируют главную и каталог; fixtures находятся только в тестах.
- [x] Deep link, reload, back, фильтрация и пагинация сохраняют URL и серверный результат.

- [x] Нет overflow на 320/390/1440 px; ES/RU/EN полны, элементы доступны с клавиатуры.

## Edge cases
Пустая подборка, недоступная БД/API, устаревший номер страницы, некорректный фильтр, отсутствующий клуб/уровень, длинное название события, UTC-переход даты относительно Буэнос-Айреса. Retry повторяет только GET.

## Открытые вопросы
Нет. Внешний акцепт и переключение боевых URL выполняются отдельно.
