# LFPT-1179 — продолжение парной записи после входа

Согласовано по мобильному макету 18.11.2026.

Возврат игрока по существующему якорю #tournament-registration к открытому парному турниру открывает форму, сохраняя проверки уровня и контактов. Якорь убирается до открытия, поэтому перезагрузка не повторяет действие. Закрытый, начавшийся турнир и уже зарегистрированный игрок не получают автоматического действия. Одиночный формат сохраняет явное подтверждение кнопкой.

При открытии формы ни один режим не выбран. До выбора поля и блоки режимов скрыты, отправка недоступна. Только WITH_PARTNER показывает поиск и ручной ввод. SEARCH и ADD_LATER сохраняют действующие согласия и правила резерва. Повторное открытие возвращает выбор режима. Новые строки переведены на ES/RU/EN. Открытие формы сохраняет существующие события аналитики, отправка регистрации требует действия пользователя.

Проверка — мобильный браузер, возврат после входа, выбор всех трёх режимов, закрытие/повторное открытие, перезагрузка, отсутствие POST регистрации при автоматическом открытии.
