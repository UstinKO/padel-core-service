# LFPT-0890: Feature черновики публикаций — данные парного Americano и «Короля корта»

## Статус
in-progress

## Источник
[GitHub #890](https://github.com/UstinKO/padel-core-service/issues/890).

## Контекст и связь с MASTER.md
Организатор готовит итоги для двух площадок из официального результата Team Playoff или закрытого проведения «Короля корта». Используются существующие роли и правила доступа на управление турниром, итоговое место определяется по финалу. Бизнес-инварианты не меняются.

## Требования
Закрытый GET `/admin/tournaments/{id}/social-draft` отдаёт дату, категорию, клуб, пары, счёт, путь к сетке и необязательное ближайшее мероприятие. Для парного турнира матч должен быть единственным завершённым финалом завершённого турнира. Для «Короля корта» используются первые два места и очки из итоговой таблицы завершённого проведения. При равных очках на границе первого или второго места черновик недоступен. Имя гостя берётся из той же проекции, что у существующей сетки. Следующее событие берётся из публичного расписания для той же категории и группы, при наличии свободной записи и будущего времени начала.

## Изменения в системе
Контроллер, read-only сервис и DTO. Миграций и загрузки фото нет. Контракт описан в `docs/endpoints/social-drafts.md`.

## Приёмка
- [x] В тесте победитель справа возвращается первым, итоговый счёт упорядочен.
- [x] Без прав данные финала не читаются.
- [x] Некорректный финал отклоняется, неподдерживаемый формат отличим.
- [x] Просроченные, занятые и чужие по категории события пропускаются.
- [x] Проверены завершённый индивидуальный зачёт, активное проведение и равенство очков за второе место.
- [ ] После интеграции проверить маршрут и запрет доступа в тестовом окружении через обычную админскую сессию.

## Вне скоупа
Выкладка, хранилище фотографий, другие форматы. У индивидуального Americano критерий выбора победителя при завершении не сохраняется.
