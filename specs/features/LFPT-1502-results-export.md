# LFPT-1502 — Универсальный экспорт результатов

Согласовано владельцем 27.11.2026. Сервер #1502, интерфейс #1503. Любой организатор и клуб, только SUPER_ADMIN.

## Контракт

GET `/admin/tournaments/{id}/results-export/preview`: счётчики, предварительность, машинные коды предупреждений без имён/контактов. POST `/admin/tournaments/{id}/results-export` под сессией и CSRF: `format=XLSX|CSV`, `contacts=false`, `acknowledged=false`. Телефоны доступны только при contacts=true и acknowledged=true. Роль проверяется на каждом запросе. Старая техническая выгрузка /admin/export также закрывается для OWNER, чтобы не оставлять альтернативный путь к результатам и контактам. XLSX — Tournament / Participants / Matches, CSV — ZIP с тремя одноимёнными UTF-8 файлами. Схема 1, стабильные английские имена колонок для интеграций. Ответ no-store, файлы только в памяти, без внешней отправки. В обычном файле нет даже колонки телефона. Имена и спортивные ID входят в оба режима; email, Telegram, вход, оплаты и произвольные заметки исключены.

Снимок REPEATABLE_READ использует фактически сохранённые таблицы и существующие расчёты рейтинга. Для King берётся актуальное проведение по тому же порядку, что на сайте (active DESC, id DESC), не архивные версии. Фактические победители и проигравшие результата важнее первоначальной пары корта. Americano использует сохранённый итоговый порядок. Круговые дополнительные встречи меняют места, но не круговую сумму. У плей-офф гарантированы места финалистов; остальным — достигнутая стадия, без придуманного полного распределения. Предварительные места отделены от итоговых; незавершённые/отменённые встречи не получают выдуманного победителя. Отдельно игровые очки, бонус кортов и ручные изменения. Отсутствующие технические признаки не выводятся из счёта или свободного текста.

Регистрации, резерв и отмены остаются видимыми по статусу; один профиль — одна строка, связи с командами отдельно. Профили из матчей без действующей заявки также входят. Неидентифицированный текстовый партнёр сохраняется отдельной строкой с пустым ID профиля, как в сохранённых данных; состав сохраняется в матче и даётся отдельное предупреждение. Для тренировок/Cancha Abierta без результатов — сведения и участники, пустой Matches, предупреждение. Дата/время — сохранённые значения мероприятия и его IANA-зона; момент снимка — UTC.

После формирования файла отдельная запись аудита: субъект, время, мероприятие, формат и контактный режим, число строк. Журнал не содержит телефонов и не меняет турнир. Формулы из пользовательского текста не исполняются в XLSX/CSV.

## Проверка

Изолированная PostgreSQL: все форматы, дополнительные встречи, бонусы, ручные составы, отсутствующие данные, отмены и предварительность. Отдельная матрица ролей с прямыми запросами, CSRF, стандартный/контактный режим, целостность файла и отсутствие изменений результатов. Учебный пример XLSX. Мерж и production отдельно.
