# LFPT-1096 — Совместимость кабинета пилота с актуальным сайтом

## Задача
Подготовить отдельную тестовую ветку, содержащую пилот 23 игроков и актуальный master. Старые ветки и боевой сайт не изменять.

## Поведение
- Сохранить график Elo, все турниры с результатами, достижения и прогресс категории.
- Сохранить актуальные блоки участия, обработку регистрации пары и локализацию ES/RU/EN.
- Сохранить закрытый список пилота. После LFPT-1093 основной адрес снова обслуживается прежним кабинетом; `app.spa.routes` остаётся пустым. Совместимость с возможным включением React вынесена в backend-задачу LFPT-1098.
- Исторический рейтинг 353 игроков должен совпадать с проверенным снимком.

## Проверка
Реальный браузер: участник пилота, игрок вне списка, отключённый пилот, мобильный экран. Проверить King of Court и Team Playoff, исправление результата, восстановление исходного рейтинга после удаления тестовых событий из учёта. Все действия — только в изолированной тестовой базе. Выпуск на боевой сайт запрещён.
