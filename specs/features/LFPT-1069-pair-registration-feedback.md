# LFPT-1069. Сообщения при регистрации пары

На странице турнира и в личном кабинете выбор профиля передаёт идентификатор. При ручном вводе отправляются заполненные поля партнёра. Подтверждение условий сохраняется в обоих случаях.

Интерфейс сохраняет выбранного партнёра после отказа и показывает сообщение сервера на языке пользователя. При истечении сессии предлагает войти. При технической ошибке выводит код запроса, если сервер его вернул.
