# LFPT-0989: форма редактирования имени игрока

В карточке игрока суперадминистратор может сохранить новое имя и фамилию. Форма подставляет текущие значения. Сообщения доступны на русском, испанском и английском.

Форма отправляет данные в `POST /admin/players/{id}/name` с CSRF-токеном. Для остальных ролей карточка показывает имя как текст.

Зависит от #988.
