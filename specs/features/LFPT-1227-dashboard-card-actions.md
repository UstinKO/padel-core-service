# LFPT-1227. Действия в привычных карточках кабинета

Поручение владельца 19.11.2026 после ручной приёмки #913: отдельный список заявок неочевиден. Перенести действия в карточки текущего кабинета, сохранить рейтинг и оформление, проверить в закрытой копии, без production-выпуска.

Frontend поверх #1204. Существующие API /api/players/me/events и participation, PairTerms и форма управления партнёром остаются источниками правил. Java, роли, статусы, финансовые условия и расчёт рейтинга не меняются.

В профиле preview кабинет показывает в обычных карточках серверные статусы, очередь, партнёра, свой платёж, доступные подтверждение/отказ, выход/отмену, контактное согласие и поиск замены. Действующие условия пары и добавление/замена партнёра сохраняются. Карточки с ожидаемым ответом выделяются и идут первыми; рядом со вкладками есть переход к ним. Вкладка истории включает отмены, включая прошлую отмену при повторной записи. Историческая карточка не предлагает повторную регистрацию или мутацию.

Отдельная ссылка «Управление заявками» и самостоятельный список запросов участия больше не нужны в preview-кабинете. Прямой React-адрес остаётся доступен для совместимости. В других профилях подключение нового отображения отсутствует. Рейтинг, график, достижения и их DOM не перерисовываются. Фильтры и текущий язык сохраняются.

Для мутаций действуют CSRF и серверные availableActions. Повторный клик блокируется на время операции/сверки. Неопределённый результат перечитывается без повторного POST; ошибки и истёкшая сессия показываются явно. Все строки ES/RU/EN. Проверка: отдельная PostgreSQL, браузер с настоящим API и синтетическими парами, десктоп/телефон, история после отмены/повторной записи, права/CSRF, ошибка сети и возврат фокуса. Физический iPhone отмечается отдельно.
