# LFPT-0871: Fix результат «Короля корта» — подставлять напарника выбранного победителя

## Статус

testing

## Источник

[#871](https://github.com/UstinKO/padel-core-service/issues/871). Зависит от [#870](https://github.com/UstinKO/padel-core-service/issues/870).

## Решение

Форма нового результата открывается в режиме по распределению и предлагает выбрать первого победителя. Второе поле показывает напарника из этого матча и доступно для изменения в ручном режиме. Переключение режима сохраняет введённый счёт. При правке форма показывает фактически сохранённых победителей; смешанная пара открывается в ручном режиме.

Пояснения и ошибки доступны на RU / ES / EN. В индивидуальном Americano координатор вводит счёт команд, там нет аналогичного поля выбора победителей.

## Приёмка

- [ ] Выбор любого участника подставляет его назначенного напарника; переключение между парами обновляет второе поле.
- [ ] Ручной выбор независим. При возврате к распределению второй победитель снова следует первому.
- [ ] Правка повторно открывает сохранённую смешанную пару. Форма работает на телефоне и компьютере.
