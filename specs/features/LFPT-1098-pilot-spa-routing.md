# LFPT-1098 — Выборочный кабинет при включённом React

## Задача
При `app.spa.routes=/players/dashboard` участник закрытого пилота должен видеть серверный кабинет с рейтингом. Остальные продолжают получать действующий React-кабинет.

## Правила
- Решение принимает сервер по аутентификации Spring Security, разрешённым ID и проверенным алиасам того же снимка, который использует кабинет.
- GET/HEAD только на `/players/dashboard`; другие маршруты и методы не меняются.
- Параметры, cookies и заголовки с ID не дают доступ. Выключенный пилот не создаёт исключений из React-маршрута.
- Проверка доступа не запускает пересчёт и не загружает снимок повторно с диска.
- Оба варианта кабинета: Cache-Control private, no-store и Vary Cookie, Authorization.
- Список пользователей, формула Elo и данные матчей не изменяются. Тестирование только в изолированной базе; боевой выпуск не разрешён.

## Проверка
Проверить обычного участника, подтверждённый дубль, постороннего и анонимного пользователя; отказ подделке ID; отключение пилота; GET/HEAD/POST и другие маршруты. Затем браузер на обычном тестовом профиле с включённым React-маршрутом и автообновлением Elo.
