# LFPT-1479: Рассылки Telegram по языку профиля

Запрос владельца 27.11.2026: получатель получает произвольную ручную рассылку на языке своего профиля es/ru/en. Национальность и язык организатора не используются. Продолжение #1394, интерфейс отдельной зависимой задачей.

Подготовка принимает необязательные texts.es/ru/en рядом с прежними requestId/selection. Отсутствие texts сохраняет прежний API и старый текст; непустой texts включает языковые версии. Каждая версия не длиннее 4096 UTF-16 единиц, недостающий текст для доступного получателя отклоняется до создания черновика. У неподдерживаемой/отсутствующей локали профиля существующий fallback es. Проба требует перевода для языка собственного профиля.

В предпросмотре сохраняются язык каждого адресата и его конкретный текст, а также все версии кампании. После подтверждения, рестарта и retry отправляется этот неизменяемый снимок; последующее изменение языка профиля не переписывает уже проверенную кампанию. Для нового языка нужен новый предпросмотр. Изменение любой версии при прежнем requestId — конфликт. История показывает язык и текст; прежние строки с отсутствующим снимком используют общий исходный текст без выдуманной локали.

Новые колонки добавляются отдельной миграцией, существующие данные не переписываются. Права, область турнира, явное подтверждение, проба себе, /stop/WhatsApp, поколение связи, UNKNOWN/FAILED и независимый пилот квитанций сохраняются. Подготовка и история не отправляют сообщения. По уточнению владельца организатор пишет один текст на удобном языке. POST /translations готовит ES/RU/EN через OpenAI Responses, передаёт только исходник без данных игроков. Ограничения: 6 запросов/мин и 60/час на автора, JSON Schema, store=false, без инструментов и автоматического повтора. Проверяются завершённость, все переводы и длина. Без серверного ключа и явного включения перевод недоступен. Настоящий ключ отсутствует по ответу владельца; реальная проверка провайдера остаётся перед отдельным выпуском.

Приёмка: смешанная аудитория ES/RU/EN, fallback es, недостающие/слишком длинные переводы, идентичность UUID, снимок после изменения профиля, проба и retry, старые кампании и права. Отдельная QA PostgreSQL и подменённый Telegram; full verify, docs-drift, relay. Мерж, production и реальные сообщения не выполняются без отдельного поручения.

Проверка 27.11.2026: полный clean verify на отдельной PostgreSQL — 1776 тестов, 0 ошибок/падений, 13 штатных пропусков. После финального ревью повторены 19 проверок кампаний/переводчика. 48 relay-тестов, docs-drift, agent-migration и единственное дерево Liquibase (100 ресурсов) прошли. API OpenAI и Telegram подменены; настоящий перевод без серверного ключа не проверялся.
