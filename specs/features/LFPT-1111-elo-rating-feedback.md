# LFPT-1111: Сбор отзывов о рейтинге Elo

Действующий допуск к пилоту применяется и к приёму отзывов. Обращение сохраняет тему, текст, автора из сессии и одну из двух страниц-источников. Повтор отправки того же запроса не создаёт второй отзыв.

Список обращений доступен суперадминистратору. После сохранения отправляется письмо со ссылкой на админку, получатель задаётся настройкой. При сбое SMTP отзыв остаётся в списке со статусом ошибки отправки.

Функция включается настройкой `app.rating.pilot.feedback-enabled=true` (`APP_RATING_PILOT_FEEDBACK_ENABLED=true`). По умолчанию выключена.
