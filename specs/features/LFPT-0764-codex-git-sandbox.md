# LFPT-0764: Fix Codex-воркер — разрешаем Git только в копии задачи

## Статус
approved

## Источник
https://github.com/UstinKO/padel-core-service/issues/764

## Контекст / зачем
Пилот показал, что рабочая песочница запрещает запись в `.git`. Агент отвечает на вопросы,
но не может создать ветку и коммит для реализации задачи.

## Связь с MASTER.md
Бизнес-правила приложения не меняются.

## Требования

### Функциональные
При запуске `codex exec` передать `--add-dir` с абсолютным путём к `.git` конкретного одноразового checkout.

### Нефункциональные
Песочница и остальные ограничения остаются включены; другим репозиториям права не выдаются.

## Вне скоупа
Изменение прав основного рабочего дерева и бизнес-логики приложения.

## Изменения в системе
API, PostgreSQL и UI не меняются. Обновить документацию по окружению и тесты воркера.

## Критерии приёмки
- [ ] В одноразовом клоне с включённой песочницей агент создаёт ветку и локальный коммит.
- [ ] Аргумент `--add-dir` указывает только на `.git` checkout текущей задачи.
- [ ] Тесты relay проходят; остальные рабочие деревья не затронуты.

## Edge cases
Пути с символическими ссылками нормализуются на уровне корня задания.

## Открытые вопросы
Нет.
