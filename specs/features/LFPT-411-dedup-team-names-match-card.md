# LFPT-411: убрать дублирование названий команд в шапке карточки матча квалификации Team Playoff

## Статус
approved

## Источник
Клиентский запрос [specs/requests/LFPT-411-dedup-team-names-match-card.md](../requests/LFPT-411-dedup-team-names-match-card.md), issue [#411](https://github.com/UstinKO/padel-core-service/issues/411).

Telegram-сообщение (для reply): 4605

## Контекст / зачем

В админке Team Playoff (`/tournaments/team-playoff/admin/{tournamentId}`, шаблон `admin/americano/tournament-playoff.html`) в блоке "Раунды квалификации" каждая карточка матча показывает названия команд дважды: один раз в серой шапке карточки (`match.note`, формат `"№5 Martin Fiori / German Agustin vs №10 Danila Gorbanev / Nikita Gorbanev"`), второй раз — в основном теле карточки (`team-left`/`team-right`), где те же имена уже показаны слева/справа от счёта. На мобильном экране это визуальный шум и лишняя высота карточки, особенно заметно при большом количестве одновременных матчей во время турнира.

Нужно убрать только верхнее дублирование (текст `match.note` в шапке), оставив в шапке только номер корта. Основная часть карточки не меняется.

## Связь с MASTER.md

Не затрагивает бизнес-инварианты `specs/MASTER.md` — чисто визуальное изменение в уже реализованном UI Team Playoff (см. `MASTER.md § Форматы турниров`, Team Americano/Team Playoff). `MASTER.md` не меняется.

## Требования

### Функциональные
- В шаблоне `admin/americano/tournament-playoff.html`, блок "Раунды квалификации" (`qualRounds`, `.match-header` для `qmatch-*`, строки ~503–513): убрать `<span th:text="${match.note}">` (текст вида "Команда 1 vs Команда 2"), оставить в шапке только `#{admin.playoff.label.court}` + номер корта + кнопку смены корта.
- Основная часть карточки (`.match-body`: `team-left` / `vs-center` со счётом / `team-right`) — без изменений, продолжает показывать команды и счёт как сейчас.
- Значение `match.note` (используется бэкендом, в частности `AmericanoMatch.getTeam1DisplayName() + " vs " + ...` в `TeamPlayoffService`) как таковое не удаляется и не перестаёт вычисляться — меняется только его отображение в этой конкретной шапке. Поле используется в других местах того же экрана (например, лог/данные для JS), их не трогаем.

### Нефункциональные
- i18n: новых пользовательских строк нет (убирается текст, ничего не добавляется) — правки `messages_{es,ru,en}.properties` не требуются.
- Безопасность: нет новой точки входа данных от пользователя, чисто визуальное изменение шаблона.

## Вне скоупа

- Другие шапки карточек в этом же файле, где дублирования нет (шапка раундов плей-офф, строки ~640–651, показывает "Cancha N" + стадию плей-офф — это не дублирование команд; шапка карточки очереди, строки ~1008–1011, показывает позицию в очереди — тоже не дублирование).
- Шаблон одиночного Americano (`admin/americano/tournament.html`) — там шапка показывает "Cancha N" + `#matchNumber`, имён команд там нет, дублирования нет.
- Шаблон Team Americano round-robin (`admin/americano/tournament-double.html`) — там `match.note` используется в шапке карточки аналогично, но в исходном клиентском скриншоте показан именно экран Team Playoff (видны номера посева "№5", "№10" — специфика `tournament-playoff.html`). Если тот же паттерн нежелателен и там — отдельная задача от заказчика, не додумываем расширение скоупа сейчас.
- Публичные (не админские) страницы просмотра турнира (`tournaments/team-americano/view.html`, `tournaments/americano/view.html`) — запрос касается именно админки, публичные страницы не трогаем.
- Превью-страницы (`admin/americano/preview-rounds.html`, `preview-double-rounds.html`) — не являются рабочим экраном проведения турнира (см. `.claude/CLAUDE.md` про "мёртвый роут"/предпросмотр), не входят в запрос.

## Изменения в системе

### API
Нет изменений — чисто фронтенд/шаблон.

### БД
Нет изменений.

### UI
`src/main/resources/templates/admin/americano/tournament-playoff.html` — блок `.match-header` внутри `th:each="match : ${round.matches}"` (раунды квалификации, `qmatch-*`): убрать строку `<span style="font-size:.75rem;color:#94a3b8" th:text="${match.note}">Equipo A vs B</span>`.

## Критерии приёмки
- [ ] На странице `/tournaments/team-playoff/admin/{tournamentId}` в карточке матча квалификации серая шапка показывает только "Корт N" (+ кнопку смены корта, если матч не завершён) — без текста с названиями команд.
- [ ] Основная часть карточки (команда слева — счёт — команда справа) визуально не изменилась — оба игрока каждой команды по-прежнему видны, счёт/форма ввода счёта работают как раньше.
- [ ] Другие шапки карточек на той же странице (раунды плей-офф, очередь) не затронуты — по-прежнему показывают то, что показывали (стадия плей-офф / позиция в очереди), не команды.
- [ ] `./mvnw compile -DskipTests` проходит без ошибок (изменение только в HTML-шаблоне, но компиляция — обязательный шаг проверки).

## Edge cases
- Матч без `note` (в round-robin `tournament.html`/`tournament-double.html` не встречается в этом шаблоне) — не относится к этой карточке; в `tournament-playoff.html` шапка квалификации после фикса не зависит от `match.note` вообще, так что null/пустое значение `note` больше не может повлиять на отображение шапки.
- Матч, где ещё не назначен второй игрок команды (гостевой второй игрок, см. issue #360, уже исправлено) — не влияет на этот фикс, тело карточки (`team-left`/`team-right`) не меняется.
