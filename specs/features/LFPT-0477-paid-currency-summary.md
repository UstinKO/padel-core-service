# LFPT-0477: Fix сумма по валюте на странице платежей турнира не фильтрует по статусу «Оплачено»

## Статус
Реализовано локально, выпуск не выполнялся.

## Источник и согласование
GitHub issue #477. Пользователь согласовал исправление в текущей сессии: «Ну, хорошо, давай делаем».

## Поведение
Верхняя сводка на `/admin/tournaments/{id}/payments` учитывает только `PAID` при суммировании ARS, USD, EUR и USDT. Карточка валюты видна, если есть положительный оплаченный платёж. Неоплаченные суммы остаются в форме, но не входят в итог. Пустая валюта по-прежнему считается ARS. Отдельные оплаченные платежи партнёров учитываются наравне с основными.

## Границы
Только фильтры существующего шаблона, без изменений Java, БД, формы сохранения, переводов и оформления. Раздел «Платежи» MASTER не меняется: ручной учёт оплат сохраняется.

## Приёмка
- Суммы с любым статусом кроме PAID, включая пустой, исключены.
- Оплата партнёра не теряется.
- Валюта без положительных оплаченных платежей скрыта.
- Проверены все четыре валюты и пустое значение валюты.

## Проверки
`PaymentSummaryTemplateTest` рендерит действующий блок `.summary-stats` через SpringTemplateEngine; проверяет итог и видимость карточек в десяти сценариях.

Полный `verify` на отдельной БД `lfpt0477_test`: BUILD SUCCESS, 617 тестов без failures/errors. Проверки docs-drift и agent-migration — без расхождений; 48 тестов relay прошли. Chromium зависает в среде, поэтому браузерная проверка не подтверждена. Существующая тестовая БД не очищалась: обнаружено предшествующее несовпадение checksum миграции v1.58.
