# LFPT-1028. Срез Elo для тестовой версии

Тестовый сайт принимает согласованный срез общего Elo. Страница рейтинга и кабинет получают строки из одного среза. Строка содержит ID игрока, имя, Elo, категорию, статус, место в категории, размер категории, общее место и прогресс подтверждения.

Срез подключается в профиле `preview` через `app.preview.elo-snapshot`. Свойство указывает путь к внешнему JSON-файлу с полями `asOf` (дата) и `rows` (строки рейтинга). Срез загружается при старте. Для обновления на тестовом сайте подставляется новый проверенный файл и перезапускается приложение. Файл с данными игроков хранится отдельно от репозитория.

Формат данных описан типами `Snapshot`, `Row` и `Progress` в `PreviewEloRanking`. Срез от 8 ноября 2026 года включает 352 игрока. Отображение описано в LFPT-1029.
