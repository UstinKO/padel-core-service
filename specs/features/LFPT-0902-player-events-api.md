# LFPT-0902. API «Мои мероприятия»

Кабинет #910 читает собственные регистрации через отдельный REST-контракт. Контракт мобильного клиента `/api/players/me/tournaments` сохраняется.

- Предстоящие содержат активные заявки на будущие мероприятия. В истории видны начавшиеся и завершённые мероприятия, мягко отменённые заявки и доступные события отмены по #900, в том числе после повторной записи. Статусы резерва и участия соответствуют #759 и #760.
- Карточка показывает формат, клуб и время мероприятия, режим заявки, имя партнёра, очередь и последний действующий платёж собственного участника в текущей записи. Контакты партнёра, платёжные реквизиты и идентификаторы транзакций в ответе отсутствуют.
- Сервер вычисляет действия из существующих правил. Ответ на участие и подтверждение отмены пары используют существующие операции, включая цену отмены. Индивидуальный выход и переключение видимости контактов проверяют версию заявки и права под блокировкой турнира.
- Отказ или отмена выполняются явным запросом с CSRF при входе через браузер. Кабинет перечитывает актуальное состояние после действия.
