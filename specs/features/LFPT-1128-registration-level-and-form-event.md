# LFPT-1128: Fix форма записи — спрашивать уровень заранее и измерять открытие формы

Источник — [#1128](https://github.com/UstinKO/padel-core-service/issues/1128). Зависит от #1127.

- Если уровень обязателен и отсутствует, карточка турнира предлагает сохранить его до заполнения формы пары или отправки одиночной записи. После сохранения открывается обычный сценарий парной записи, а для одиночной записи игрок подтверждает участие кнопкой на карточке.
- Если отсутствие уровня обнаружено только при отправке, выбранный режим, партнёр и введённые данные остаются в открытой парной форме. Повторную отправку подтверждает игрок.
- GA4 получает `tournament_registration_form_opened` с `tournament_id` при показе формы парной записи и наличии согласия на аналитику. `tournament_registration_start` по-прежнему означает попытку отправки. Для воронки с открытием формы нужен парный сценарий: одиночная запись может пройти без формы.
