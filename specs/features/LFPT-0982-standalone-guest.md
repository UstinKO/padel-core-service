# Создание гостевой карточки без заявки

POST из списка игроков доступен суперадмину. Сервис создаёт гостевую карточку по имени и фамилии и возвращает переход на страницу профиля по присвоенному ID. При совпадении с активным профилем или неверном имени контроллер возвращает в список игроков с сообщением и введёнными данными.

Создание карточки не записывает игрока на турнир, не сохраняет результат матча и не отправляет уведомление. Повторная отправка формы проходит действующую проверку совпадений имён.
