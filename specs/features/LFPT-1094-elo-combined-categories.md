# LFPT-1094. Объединённые категории в пилоте Elo

Зависит от LFPT-1086 / PR #1088. Исправление разрешено только для тестовой версии.

## Проблема

Проверенная история содержит нормализованные категории: C7_C6 → C7, C6_C5 → C6, D7_D6 → D7. Новые результаты сайта поступают с обозначением диапазона. Расчёт его не распознаёт и для нового игрока не применяет стартовую поправку, не ведёт прогресс категории.

## Решение

На входе события в расчёт поддерживаемые соседние диапазоны приводятся к более слабой границе, как в проверенной истории. Принимаются обозначения сайта с `_` и их отображаемая запись с `/`:

| Диапазон | Категория события в расчёте |
|---|---|
| C9/C8 | C9 |
| C8/C7 | C8 |
| C7/C6 | C7 |
| C6/C5 | C6 |
| C5/C4 | C5 |
| D9/D8 | D9 |
| D7/D8 | D8 |
| D7/D6 | D7 |

Соответствия одиночных уровней остаются прежними: D7 → C8, D8 → C9, D9/PRINCIPIANTES → «Новичок». Название турнира, дата, формат и ссылка сохраняются. Нераспознанные обозначения, SUMA и уровни вне поддерживаемой шкалы не угадываются по имени события или текущему профилю игрока. Это исправление не расширяет шкалу рейтинга и не меняет правила допуска к турнирам.

K=24, старт 1500/C8 и шаг 40, правила подтверждения и список участников пилота не меняются. Обработку получают архивный и автоматический источники через единый вход событий. Полный исходный срез 353 игроков должен воспроизвестись без изменений.

## Проверка

Проверить первый матч, накопление результатов нескольких турниров, подтверждение категории и сохранение метаданных. Результат каждого диапазона должен совпадать с эквивалентной одиночной категорией по всем строкам. Проверить неизвестные значения и все строки действующей истории. Публикация только как черновой PR, без выпуска.
