# LFPT-0910. Мои мероприятия в React

Экран `/players/dashboard` в React подключается к API #902. В текущей поставке действующий маршрут сайта остаётся на Thymeleaf, а React проверяется в закрытом контуре. Ссылка из письма продолжает открывать действующий защищённый экран ответа, проверенный на турнире №180.

Будущие мероприятия и история отображают данные собственной заявки, очередь, партнёра, отметку оплаты и причину отмены. Доступность кнопок определяет API. Отказ, отмена и смена видимости контактов используют CSRF и обновляют карточку с сервера после запроса. Неполученный ответ не считается успешным до сверки состояния.
