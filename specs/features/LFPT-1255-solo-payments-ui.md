# LFPT-1255. Одиночные заявки в обычной странице оплат

Статус: approved. Зависит от серверной задачи #1254 / PR #1256. План согласован пользователем 22.11.2026. Новые роли и назначения координаторов не вводятся.

## Интерфейс

На `/admin/tournaments/{id}/payments` для парной регистрации появляется блок «Игроки без пары» и кнопка «Добавить игрока» рядом со штатным добавлением пары. Показываются уровень, состояние поиска/добавления партнёра, сохранённое основное место либо отсутствие парного места/резерв, индивидуальная явка и оплаты без сложения валют.

Действия: добавить партнёра из базы, гостя или второй одиночной заявки; объединить две заявки; снять игрока; перейти к его строке оплаты и присутствия. Поиск не скрывает уже записанных участников: существующая заявка открывается вместо дубля, готовая пара показывается перед действием.

Превью показывает исходных участников, их оплаты/явку, итоговый статус и явное предупреждение для ручного допуска по уровню. При снятии объясняет сохранение профиля и финансовой истории, отсутствие автоматического возврата. Журнал и снятые заявки доступны в сворачиваемом блоке.

Несохранённые отметки таблицы не теряются: перед изменением состава предлагается сначала сохранить их. При ошибке введённые поля остаются. На время запроса действия блокируются; повтор после потери ответа сохраняет UUID и полезную нагрузку. Сервер остаётся источником проверки прав, вместимости и составов.

## Проверка

Дополнение пользователя: блок по умолчанию свёрнут, в заголовке видно число одиночных заявок. Выбор сохраняется для турнира в текущей вкладке, в том числе после обновления страницы. При недоступном хранилище обычное сворачивание продолжает работать. Используется стандартный details/summary с клавиатурным управлением. Кнопка добавления игрока рядом с добавлением пары доступна при свёрнутом блоке. Ошибка загрузки раскрывает сообщение. Регистрации, оплаты и явка от сворачивания не меняются.

- RU/ES/EN; узкий мобильный экран и компьютер; клавиатура, перенос подписей, отсутствие переполнения новых блоков.
- Тесты интерфейса: обе валюты и независимая явка в превью, безопасный вывод имён, защита несохранённых оплат, двойное нажатие, идентичный повтор после потери связи, сохранение гостевых полей при ошибке.
- Изолированный браузерный сценарий под клубным аккаунтом: объединение двух оплаченных заявок в заполненном турнире, гость без email, сохранение оплаты и снятие, поиск профиля и дополнение сохранённой основы. Производственные данные не затрагиваются.
