# Привязка игрока к сыгранному матчу Team Playoff

Организатор открывает имя второго игрока в карточке завершённого матча, если в протоколе есть имя и ещё отсутствует ID. На странице привязки видны состав и счёт. Организатор может выбрать активный профиль из поиска или создать гостевой профиль с указанным именем.

Сервер проверяет доступ к матчу, завершённость, наличие счёта и актуальность выбранного места. Сохранение заполняет только пустой ID в выбранном матче и фиксируется в журнале проведения. Создание гостя и привязка выполняются в одной транзакции. При совпадении полного имени система предлагает выбрать существующую карточку.

Сценарий предназначен для результатов, сохранённых на сайте. Подтверждённые составы архивных сеток участвуют в расчёте Elo из архива.
