# LFPT-1119. Полная отмена пары

## Статус
in_progress

Подтверждение полной отмены определяет активный состав по общему ID бронирования. Для исторических заявок без этого ID используется согласованная прямая или обратная связь. При отсутствии обеих ссылок допускается общий ID основного игрока, если он принадлежит одному из участников. При нескольких подходящих заявках сервер отклоняет отмену.

Расчёт и подтверждение используют одинаковый состав. Тесты покрывают основную сетку и резерв, действие от каждого игрока, повтор подтверждения и сохранение истории. Отдельный выход участника остаётся самостоятельной операцией.
