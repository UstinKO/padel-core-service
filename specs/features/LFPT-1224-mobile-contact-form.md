# LFPT-1224 — Мобильная форма контактов

Статус: approved. Согласовано 19.11.2026. Зависимость — PR #1225 (LFPT-1223).

В модальном окне перед записью телефон обязателен. Выбор страны содержит поддерживаемые libphonenumber страны, начальная AR, название переведено через Intl.DisplayNames. Пример соответствует выбранной стране. Местный или международный номер нормализуется E.164. Telegram необязателен, @ добавляется автоматически. Ошибки показываются сразу при вводе и повторно при отправке. Clarity получает только код причины без контактов. Старое событие contact_invalid сохраняется в allowlist для совместимости, новые случаи имеют конкретные коды. При сбое проверки контактов продолжения без проверки нет.

Включено на карточке и в кабинете. Учитываются клавиатура телефона, прокрутка окна, фокус, Escape и Tab. Языки ES/RU/EN. Проверка браузером на ширине 390px и тесты нормализации. Библиотека 1.13.17 закреплена локально с лицензией MIT.

Проверки: `node --test src/test/js/contact-fields.test.cjs`, Maven verify, docs-drift, check-agent-migration, 48 тестов relay. Мобильная проверка во встроенном браузере на 390×844, синтетический игрок с Telegram и без телефона. Пустой телефон блокирует продолжение, короткий номер показывает ошибку при вводе, страна меняет пример, Telegram автоматически получает @. Сохранение без Telegram открывает форму пары, после обновления повторного запроса телефона нет. Боевая аналитика выключена на локальном стенде.

## Полный путь нового игрока, согласовано 19.11.2026

Та же локальная библиотека и список стран переиспользуются формой создания аккаунта. Телефон обязателен, уровень обязателен, Telegram необязателен. Пример зависит от страны, в отправку идёт E.164, @ подставляется автоматически. Контекст tournamentId сохраняется в ссылке создания аккаунта, переключении языка, Google, обратном входе и скрытом поле POST, включая ошибки формы. После создания аккаунта сервер возвращает якорь продолжения на выбранный турнир. Открытие формы на карточке зависит от PR #1181, его код здесь не дублируется.

## Внешний вид по текущему сайту, последнее уточнение 19.11.2026

За основу сохранены исходные интервалы, заголовок, Google, порядок полей, постоянно видимый необязательный Telegram и постоянная подсказка пароля. В строке телефона добавлен только короткий код (+54) со стрелкой. Нативный select открывает список кодов со странами, а закрытый вид показывает только код. Видимая надпись «Страна номера» отсутствует, доступное имя — «Код страны». Нормализация, ошибки, обязательные телефон/уровень, необязательный Telegram и возврат к выбранному турниру сохранены. Подсказка номера при фокусе не смещает поля.

## Форматирование телефона при вводе, согласовано 20.11.2026

В форме аккаунта и окне контактов цифры автоматически разделяются по правилам выбранной страны: пробелы, скобки и дефисы добавляет локальный AsYouType. Вставка уже оформленного местного или международного номера поддерживается. Текст и добавочные номера не превращаются молча в другой телефон — остаётся ошибка проверки. При редактировании в середине сохраняются курсор и выделение; Backspace/Delete около разделителя удаляют соседнюю цифру без застревания. Поле очищается полностью, формат пересчитывается при смене страны. После выхода из поля местный номер остаётся местным, международный сохраняет +код. Отправляется прежний E.164, обязательность и серверные проверки не меняются.
