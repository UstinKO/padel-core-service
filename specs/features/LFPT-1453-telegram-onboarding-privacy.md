# LFPT-1453: Страница подключения без сторонней аналитики

Исправление после #1428/#1429. На внешнем адресе Cloudflare добавляет beacon поверх исходного HTML, хотя шаблон подключения не содержит аналитики. Утечка секрета не установлена; массовая приёмка пока не завершена.

Сервер возвращает `Cache-Control: no-store, no-transform`, `Referrer-Policy: no-referrer` и политику CSP со скриптами/соединениями только своего origin. `no-transform` запрещает посреднику дополнять HTML; CSP блокирует сторонний скрипт, даже если он появился в ответе. Общий вход, невалидный запрос, авторизованный обзор и перенаправление ко входу сохраняют защиту. Сохранение контекста тоже не кэшируется. Настройки кеширования других страниц и глобальная аналитика не меняются.

Проверка: серверные заголовки в разных состояниях, реальный браузер с имитацией вставленного стороннего скрипта и контрольным ответом без CSP; затем обычный путь подключения на ES/RU/EN. Внешний скрипт подменяется локальным тестом, реальная аналитика и сообщения не отправляются. Полный verify, CI и внешняя проверка после отдельного выпуска обязательны. Production-переключатель не изменяется без подтверждения пользователя.

Основание: [Cloudflare Web Analytics — no-transform](https://developers.cloudflare.com/web-analytics/get-started/#sites-proxied-through-cloudflare).
