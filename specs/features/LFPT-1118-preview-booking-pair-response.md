# LFPT-1118. Серверная подготовка записи UI v2 и ответ на предложение пары

На тестовом стенде игрок открывает карточку конкретного турнира и профиль в React. Допуск ограничен профилем `preview` и точными маршрутами. Каркас админки и остальные маршруты остаются закрытыми. Публичные маршруты production не переключаются.

Имеющаяся ссылка из письма ведёт на страницу ответа. В письме описаны оба возможных результата принятия. Успешный ответ API принятия дополнительно отдаёт фактический статус заявки. API отказа сохраняет одиночные заявки и переиспользуется в #909. Существующие клиенты сохраняют текущие поля ответа и маршрут. Правила регистрации и отмены сохраняются.

После сохранения профиля индивидуальная запись проверяет актуальный контакт по ID игрока. Содержание существующей сессии может отставать от сохранённого профиля.
