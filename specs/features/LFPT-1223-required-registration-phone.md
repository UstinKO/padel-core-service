# LFPT-1223 — Обязательный телефон перед записью

Статус: approved. Пользователь подтвердил 19.11.2026.

Телефон игрока обязателен, Telegram дополнительный. Новые контакты принимают местный номер с ISO-страной или международный, нормализуются E.164. Проверяется возможная длина номера, не владение. Telegram принимает ввод без @. Ошибка возвращает отдельный код и поле, не сохраняет часть контакта. Старые профили с телефоном остаются совместимы, Telegram-only требует телефон. Гостевые/администраторские сценарии и контакт партнёра не изменяются. Клиентская форма — отдельная задача LFPT-1224.

Проверки: нормализация AR/RU/международного номера, короткий/длинный/недопустимый ввод, телефон обязателен при Telegram, отсутствие частичного обновления, локализация ES/RU/EN.
