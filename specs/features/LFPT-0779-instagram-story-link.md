# LFPT-0779: Fix ссылка /ig-story — добавить публичный редирект с метками сторис

## Статус

Реализация подготовлена локально; проверка Java и выпуск не выполнены.

## Источник и проблема

Issue #779. Пользователь разместил `https://1-padel.com/ig-story` в Instagram.
На работающем сайте 31.10.2026 адрес открывает `/login`: маршрут отсутствует
в контроллере маркетинговых редиректов и в публичном списке Spring Security.

## Связь с MASTER

Изменение публичного маркетингового адреса. Правила турниров, регистрации,
ролей и согласия на аналитику не меняются.

## Поведение

Анонимный `GET /ig-story` возвращает `302` с фиксированным `Location`:

`https://1-padel.com/?utm_source=instagram&utm_medium=social&utm_campaign=instagram_stories&utm_content=shared_story`

Это постоянная общая ссылка для собственных сторис организатора и репостов
партнёров. Атрибуция отдельных партнёров не требуется. Цель — существующий
публичный список актуальных турниров на главной странице.
Входящие query-параметры не влияют на цель. Существующие редиректы сохраняются.
Новые события GA4, настройки cookies, БД и пользовательские строки не нужны.

## Приёмка и проверки

- Анонимный запрос проходит настоящую цепочку Spring Security и ведёт на главную с четырьмя UTM-параметрами.
- `url` и `utm_source` во входящем запросе не подменяют фиксированный адрес.
- Существующие проверки `/ig-bio` и `/oct-ig` проходят.
- Выполнить `./mvnw verify` на отдельной тестовой БД и проверку документации.
- После согласованного деплоя открыть `/ig-story` без авторизации и подтвердить финальный адрес.
- В GA4 различать кампании `instagram_stories` и `instagram_profile`.
