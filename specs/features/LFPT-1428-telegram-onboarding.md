# LFPT-1428: Общий вход в Telegram

## Согласованный путь
Одна общая ссылка бота для чата/личных приглашений. Start → персональная временная ссылка сайта → обычный или Google-вход → подтверждение текущего профиля → окончательное подтверждение в исходном личном Telegram. Организатор не создаёт ссылки каждому.

## Инварианты
- Telegram удостоверяется стабильным ID из личного update; профиль — текущей серверной сессией активного обычного игрока. Username, телефон и browser playerId не удостоверяют связь.
- Ссылка содержит случайный секрет 192 бит; БД хранит SHA-256, срок 10 минут, один запрос на Telegram. Общая ссылка не содержит секрета.
- Временный секрет передаётся fragment-частью ссылки и затем CSRF-защищённым POST сохраняется в серверной сессии. HTTP GET, Referer и destination входа не содержат секрет; страница подключения без аналитики.
- GET не связывает профиль. POST с CSRF фиксирует единственного кандидата и отправляет запрос согласия в исходный Telegram; пересылка ссылки не даёт завершить привязку. Callback проверяет исходный user/chat, актуальный запрос, игрока, срок и ограничения.
- Конфликт существующих связей не перезаписывается; повтор безопасен. /stop, отключение и WhatsApp аннулируют незавершённые запросы. После /stop нужна новая явная процедура.
- Атомарность с персональными ссылками/отключением — прежняя транзакционная блокировка связей. Отправки используют долговечные ключи дедупликации; неизвестный ответ автоматически не повторяется.
- Новый флаг telegram.players.onboarding-enabled=false включается только после отдельного выпуска сервера и интерфейса. Автоматика и независимый пилот чеков не меняются.
- RU/ES/EN; начальный язык из Telegram, затем язык сайта. Email/телефон не передаются; секреты/ID не показываются в UI и логах; no-store, Referrer-Policy no-referrer.

## Разделение
Сервер #1428; страница и общая ссылка в редакторе — #1429. Рейтинг, кабинет, регистрационные/финансовые правила и шаблоны рассылки не меняются. Новый аккаунт создаётся существующим способом; при потере перехода игрок повторно открывает личную ссылку бота. Автоматическое создание/слияние аккаунтов не входит.

## Приёмка
Изолированная БД и подмена Telegram: два подключения; чужое подтверждение; пересылка/другой профиль; срок; конкуренция; повтор; конфликт; /stop/WhatsApp; пилот/выключение; персональные ссылки. Настоящий браузер ES/RU/EN, 320/390/1440: вход и подтверждение без автоматического POST, ошибка/потеря сессии и контекст. Обязательные проверки AGENTS, без реальных рассылок и production-изменений.
