# LFPT-1460: Общая ссылка и короткое подключение Telegram

Зависимость: сервер #1459. Согласованный путь: общая ссылка `/telegram/join` → обычный/Google-вход при необходимости → одна кнопка → Start в боте. Это новый основной адрес приглашения в общий чат, без персональных данных. Предыдущий вход из бота и уже подключённые игроки сохраняются.

Страница показывает собственное имя и добровольный выбор получать уведомления/приглашения; объясняет отключение в профиле или /stop. Форма POST с CSRF сразу переходит по серверному 303 в бот, работает без JS; дополнительный JS блокирует повторный submit и восстанавливает кнопку при возврате из кэша браузера. Токена нет в DOM до действия, GET и смена языка ничего не меняют. Referrer-Policy same-origin сохраняет Origin для нативной формы и не передаёт адрес внешнему боту. Состояния READY/CONNECTED/UNAVAILABLE/ACCOUNT_REQUIRED и ошибка переведены ES/RU/EN. Общая ссылка ведёт на сайт, поэтому не требуется начальный Start и повторное подтверждение после привязки.

Редактор рассылок получает новый отдельный API site-invitation, показывает HTTPS URL с точным `/telegram/join`, без credentials/query/fragment. Копирование имеет ручной fallback; аудитория, текст и отправка кампании не меняются. Старый API приглашения остаётся совместимым. Платная подписка и изменения Cloudflare не требуются.

Приёмка: Chromium с настоящим Spring и QA PostgreSQL, ES/RU/EN и ширины 1440/390/320; чистый login/Google destination, смена языка, одна нативная отправка при двух активациях, прямой переход к тестовому боту, личный Start через настоящий poller связывает профиль без callback. Уже подключённый профиль не получает форму; недоступность, другая роль, CSRF и копирование проверяются отдельно. Старый браузерный тест сохраняется. Full verify, проверки документации и relay. Приглашение готовится текстом, реальная отправка игрокам не выполняется.

Выпуск: сервер #1459 → frontend #1460, с актуализацией base/CI каждого PR перед мержем. Отдельное разрешение владельца требуется на выпуск; до него новую ссылку не публиковать в чате.
