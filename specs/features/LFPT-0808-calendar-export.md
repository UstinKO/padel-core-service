# LFPT-0808 — единое календарное событие

Статус: approved. План согласован пользователем 2026-11-02. Задачи: #808 (бэк), #809 (фронт).

Разовое добавление мероприятия через Google TEMPLATE и UTF-8 iCalendar. Один источник названия (формат + категория + парное участие + 1-Padel), начала, окончания, места и локализованного описания. Собственные имена не переводятся. Только публичная ссылка без query/hash; app.base-url определяет актуальный домен. Собранный текст не содержит контактов/участников/управляющих ссылок, свободное описание организатора не экспортируется автоматически: краткое описание составляется из безопасных полей формата и категории.

Настройки: durationMinutes > 0 (nullable для старых мероприятий), timeZone — IANA, по умолчанию America/Argentina/Buenos_Aires для существующих записей. Старый duracion используется только при полном однозначном соответствии единицам часов/минут/дней RU/ES/EN или H:MM. Нет произвольного окончания. Если данные не позволяют вычислить окончание, экспорт недоступен с пояснением.

Начало интерпретируется в зоне мероприятия, UTC передаётся в Google и ICS; несуществующее/неоднозначное локальное время при DST отклоняется. UID tournament-ID@1-padel.com стабилен по языкам/изменениям. CRLF, экранирование TEXT, folding по 75 октетам без разрыва UTF-8. Никаких ATTENDEE/ORGANIZER/VALARM, синхронизации и обещаний устранения дублей.

Доступ: getActiveTournamentById как на /torneo/{id}; SOLO_POR_ENLACE не появляется в списках, доступ по прямой ссылке сохраняется. Все ответы no-store.

Приёмка: единые Google/ICS данные, все форматы и языки, разные зоны, стабильный UID, текст/Unicode/folding, HTTP статусы и заголовки, отсутствие мутаций. Полный Maven verify и документационные проверки. Физические iPhone/Mac и встроенные WhatsApp/Telegram требуют ручного прогона; скачивание не считается сохранением.
