# LFPT-0994: Подтверждение гостевого профиля — интерфейс

## Статус
testing

## Источник
[GitHub #994](https://github.com/UstinKO/padel-core-service/issues/994), зависит от #901.

## Сценарии

- При занятом телефоне на странице регистрации появляется ссылка в официальный WhatsApp 1Padel.
- В профиле игрока с аккаунтом можно указать WhatsApp, получить номер заявки и отправить его через WhatsApp.
- В списке игроков организатор вводит номер заявки, сверяет почту целевого аккаунта с обратившимся игроком и указывает фактический номер отправителя.
- В карточке активного гостя организатор вводит подтверждённый номер и email для активации исходной записи. После активации игрок самостоятельно запускает восстановление пароля.
- Ошибка отображается в форме. При пересекающейся истории обе записи сохраняются на сервере. Экраны и сообщения доступны на ES, RU и EN.

## Проверка
Проверить регистрацию с занятым номером, создание заявки, отказ для другого номера и успешное подтверждение. Проверить формы на телефоне и компьютере, отсутствие переполнения, подписи и доступность клавиатурой.

## Результат локальной проверки

Chrome с настольным и мобильным viewport. Проверены ссылка WhatsApp при занятом телефоне, номер заявки в ссылке из профиля, отказ при неверном номере отправителя, ручная привязка, конфликт двух записей на один турнир и активация исходного гостевого профиля. Сверка PostgreSQL подтвердила сохранение ID и статуса резерва. Интерфейс проверен на ES и RU.
