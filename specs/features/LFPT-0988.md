# LFPT-0988: сохранение имени в карточке игрока

Суперадминистратор может исправить имя и фамилию существующего игрока по его ID.

- `POST /admin/players/{id}/name` принимает `firstName` и `lastName` из формы с CSRF-токеном.
- Имя обязательно. Фамилия может быть пустой у игрока с одним именем. Длина каждого поля после обработки пробелов ограничена 100 символами.
- Запрос сохраняет только имя и фамилию. Права на вход, контакты, заявки и история матчей остаются связаны с прежним ID.
- После сохранения или ошибки валидации запрос перенаправляет в карточку. Если игрок не найден, сервер возвращает 404. Остальным ролям действие недоступно.
