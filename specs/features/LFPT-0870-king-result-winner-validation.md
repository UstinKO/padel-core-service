# LFPT-0870: Fix результат «Короля корта» — проверять пару победителей по режиму выбора

## Статус

testing

## Источник

[#870](https://github.com/UstinKO/padel-core-service/issues/870). Интерфейс описан в [#871](https://github.com/UstinKO/padel-core-service/issues/871).

## Решение

Существующие маршруты создания и исправления результата принимают необязательное поле `manualWinners`. В режиме по распределению сервер проверяет пару по сохранённым командам конкретного корта и раунда. Ручной режим и прежние клиенты без поля могут указать фактическую пару из двух разных участников матча. Во всех случаях полный список победителей и проигравших должен совпасть с составом матча.

Используется существующий пересчёт результата. В истории партнёрств для следующих раундов учитываются фактически сыгравшие пары. Правила перемещения, ограничения правки прошлых раундов, игровые очки, бонусы и независимые корректировки сохраняются.

## Приёмка

- [ ] Назначенная пара принимается в автоматическом режиме. Пара из разных команд отклоняется автоматически и принимается вручную.
- [ ] Неполный, повторный или чужой участник отклоняется.
- [ ] Правка обновляет один результат, бонусы и статистику; независимые дополнительные очки сохраняются.
