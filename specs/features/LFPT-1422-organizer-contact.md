# LFPT-1422 — проверенный контакт организатора

Источник: #1422. Статус: implementation. Интерфейс: #1423.

## Контракт

У мероприятия отдельно хранятся имя организатора, ISO-страна и телефон E.164. Старое значение `contactoOrganizador` и его исходный снимок совместимы с прежними данными. Имя контакта не меняет ownerId и организацию. Ни номера игроков, ни права на события не меняются.

Одна чистая политика разбирает телефон через Google libphonenumber, проверяет допустимость номера и формирует `https://wa.me/<digits>`. Принимаются международный номер, национальный номер выбранной страны, однозначные `wa.me/<number>` и `api.whatsapp.com/send?phone=<number>`. Посторонние домены, короткие бизнес-ссылки без номера, несколько номеров, расширения и текст в новом телефонном поле отклоняются. Международная вставка определяет страну по номеру. Для AR преобразования национальных 0/15 выполняет библиотека, префикс 9 повторно не добавляется. Наличие WhatsApp не проверяется и не обещается.

Старые значения разрешаются при чтении без записи в production. Имя и один явный международный номер разбираются раздельно. Неоднозначное значение сохраняется исходным, получает признак исправления и не порождает активный URL. Первое осознанное исправление сохраняет исходный контакт отдельно. Номер платформы не используется как подмена контакта события.

Валидация работает в HTML-форме и сервисных операциях создания/редактирования. Предпросмотр контакта доступен только служебным ролям; при переданном ID проверяются права именно на это событие. Отправки сообщений, проверок WhatsApp API, фоновых миграций и массового редактирования нет.

## Проверки

Unit: AR, другие страны, национальные префиксы, URL, неправильные/неоднозначные значения, сохранение raw. PostgreSQL: миграция, создание/редактирование/копирование, права и неизменность чужих событий. Учебные данные preview используют корректный пример телефона; отдельный регрессионный тест проверяет их отправку через старый и новый контракт формы. UI и переходы проверяются в зависимой задаче. Правила регистрации и SUMA не меняются.
