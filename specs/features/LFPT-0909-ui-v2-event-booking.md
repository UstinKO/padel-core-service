# LFPT-0909. Запись на мероприятие и парные сценарии UI v2

В карточке UI v2 игрок может записаться индивидуально, выбрать существующего или нового партнёра, оставить неполную заявку и предложить пару. Используются действующие серверные правила #759, #760, #900 и #902. Позиция резерва отображается, когда её возвращает сервер. Неполная заявка показывает выбранный режим.

Условия парного Americano подтверждаются действующим серверным токеном. Если ответ на запись потерян, интерфейс перечитывает действующую заявку; автоматической повторной отправки нет. Отказ по ссылке из письма сохраняет одиночные заявки; принятие показывает итоговый статус из #1118.

#940 и #941 сохраняют область действующих форм. Привязка гостевого профиля и общая приёмка #913 не меняются. Проверка проводится на закрытой копии под обычным игроком.
