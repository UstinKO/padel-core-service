# LFPT-0894: Feature комплект публикации — сохранить готовые карточки турнира

## Статус
in-progress

## Источник
[GitHub #894](https://github.com/UstinKO/padel-core-service/issues/894). Основа — #890 и #891, интерфейс — #895.

## Контекст и связь с MASTER.md
Один координатор сохраняет комплект, другой администратор с правами на тот же турнир скачивает его позже. Применяется существующее разграничение доступа. Состояние и критерий завершения индивидуального Americano восстанавливаются вместе с историей проведения.

## Требования
- Одно общее фото с двумя текстами доступно для всех состоявшихся мероприятий, включая Cancha Abierta и тренировку с игрой. Для событий без известной длительности общий комплект доступен со следующего дня по местному времени. События в черновике и отменённые события исключены.
- Подтверждённые результаты дают специальный режим для Team Playoff, King of Court и индивидуального Americano. Для последнего используется сохранённый порядок итога. Если итог неоднозначен или порядок не был сохранён, доступен общий режим.
- Один приватный комплект JPG и текстов ES/RU на турнир. Новая версия атомарно заменяет старую. Устаревший запрос возвращает конфликт. Метаданные выдаются отдельно. Групповые JPG принимаются в пропорциях исходного кадра с максимальной стороной 2048 пикселей. Для комплекта Team Playoff принимаются изображения 1080 × 1350.

## Изменения в системе
Миграция v1.70 добавляет пакет и критерий Americano. HTTP-контракт и права описаны в docs/endpoints/social-drafts.md. Публичная галерея и автопубликация относятся к другим этапам.

## Приёмка
- [ ] Два администратора одного турнира могут сохранить и скачать комплект, в том числе после перезапуска.
- [ ] Посторонний организатор не получает файлы даже по прямой ссылке.
- [ ] Невалидные файлы и устаревшие версии не затирают пакет.
- [ ] Индивидуальный Americano сохраняет выбранный критерий. Для старого Americano и событий без спортивного финала работает общий режим.
