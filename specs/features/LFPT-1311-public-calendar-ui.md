# LFPT-1311 — Публичный календарь: интерфейс

Статус: implemented
Зависит от серверной #1310, PR #1313.

Только `/torneos`: карточки по умолчанию, запоминаемый вид, общие фильтры и URL. На компьютере компактный месяц и полный список дня, на телефоне даты со счётчиками и список ниже. Фильтр уровня виден, дополнительные фильтры сворачиваются. Существующая страница мероприятия и процесс записи сохраняются. Личные статусы в памяти текущей сессии; публичная ссылка содержит только общие параметры.

Даты переиспользуют проверенную арифметику административного календаря. Только начальная локальная дата события, без конвертации часов в зону устройства. Клуб и организация отдельными полями. Ошибка API не выглядит пустым результатом. Возврат ограничен безопасным маршрутом /torneos.

## Приёмка
- [x] 4/5/6 недель, переход года, сегодня, соседние даты.
- [x] 0/1/3/5/65 событий, фильтры, полный список и одинаковые старты.
- [x] Возврат, общая ссылка, сохранение фильтров и вида.
- [x] Публичность, свои статусы пары/резерва/одиночной заявки, смена аккаунта.
- [x] RU/ES/EN, компьютер и 320–390 px, без горизонтальной прокрутки.
- [x] Node, Maven verify и реальный браузер на отдельной PostgreSQL.

## Проверка
Полный Maven verify на отдельной PostgreSQL: 1330 тестов bootstrap, 0 ошибок, 4 пропущены. Node: 20 проверок публичной и общей административной арифметики дат; из них 11 новых сценариев. docs-drift, check-agent-migration и 48 тестов конвейера успешны.

Отдельный локальный стенд, только синтетические данные: 76 публичных событий периода, 65 на одной дате; 0/1/3/5 событий, скрытые площадка/организация не раскрываются. Реальный браузер: 1440, 390, 320 px; равная высота дат, нет горизонтальной прокрутки, доступен полный день. Проверены RU/ES/EN, C7 → C8/C7, C3 → C4/C3, SUMA_14, TODOS + Clinic + Mixto + организация, смена вида и возврат из события, переход декабря в январь и февраль (28 дней), «Сегодня» в ноябре (42 дня).

Два учебных игрока: основной участник и партнёр видят пару; основной участник — резерв и SOLO_SEARCH, партнёр — SOLO_ADD_LATER. «Мои записи» даёт 3 события первого игрока, не попадает в URL; после выхода отметки и переключатель исчезают, смена аккаунта не сохраняет чужой резерв. Ошибка источника показывается явно с повторной загрузкой.

Рабочий сайт и реальные пользователи не изменялись. Выпуск — отдельным поручением после приёмки.

Оформление выходных: суббота и воскресенье выделены мягким тёплым фоном, подписями и номерами дат в фирменной гамме. Выбранная дата сохраняет оранжевую рамку, сегодняшний день — тёмный маркер, соседние месяцы — приглушённый вид.
