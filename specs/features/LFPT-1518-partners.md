# LFPT-1518 — Публичная страница для коммерческих партнёров

На главной странице в общей навигации доступна ссылка «Партнёрам» (ES Para marcas, EN For brands). Маршрут `/partners` без авторизации открывает испанскую версию. Посетитель может перейти на английскую и русскую версии, просмотреть фотографии и открыть контакт WhatsApp. Страница и её локализации работают без JavaScript. При включённом уменьшении движения галерея доступна через ручную прокрутку.

Публичный доступ распространяется на маршрут, страницы локализаций, CSS и WebP-фотографии. Статика включена в серверную сборку в `src/main/resources/static/partners/`.
