# LFPT-1083. Пилот кабинета для выбранных игроков

Зависит от LFPT-1034 / PR #1035. Подготовка по запросу пользователя от 13 ноября 2026 года; выпуск на основной сайт не разрешён.

## Поведение

При включённом пилоте новый кабинет и связанная таблица Elo доступны только вошедшему игроку из серверного списка ID. Список выбран пользователем и содержит 23 уникальных игрока. Связанные ID №327 и №226 дают доступ к одной строке Макса; это не два участника. Список, результаты и соответствия хранятся во внешней конфигурации, не в браузере.

Остальные игроки, гости и организаторы видят прежние кабинет/рейтинг. Параметры запроса, cookie с произвольным ID и заголовки не определяют участника: используется только проверенная Spring Security личность с ролью PLAYER. Новая разметка, данные, CSS и JS не включаются в их HTML. Персонализированные ответы не кешируются общим кешем (`private, no-store`, `Vary: Cookie, Authorization`).

Elo и места остаются рассчитанными по всем подтверждённым матчам всех игроков. Список ограничивает только доступ к интерфейсу. Регистрация, аккаунты, результаты, старый рейтинг и права не меняются. API мобильного приложения не меняется.

## Настройки и источники

`app.rating.pilot.enabled=false` по умолчанию. `app.rating.pilot.player-ids` — набор основных ID; пустой набор не даёт доступ никому. Отрицательные/нулевые ID недопустимы.

В изолированном профиле `preview` включённый пилот ограничивает существующий пересчитываемый рейтинг; выключенный пилот возвращает прежние страницы всем пользователям. Прежний неограниченный предпросмотр рейтинга отключён. Это не используется как способ выпуска на боевую базу.

В обычном профиле при выключенном пилоте новый кабинет отсутствует. При включении `app.rating.pilot.snapshot` указывает на внешний JSON: `snapshot` (полный проверенный срез), `startStep`, `aliases`. Это только чтение файла, без запуска preview, создания тестовых аккаунтов или таблиц исправлений. Некорректный срез останавливает запуск включённого пилота. Поддерживается 1500/C8 и шаг 40 согласно срезу.

По умолчанию пилот в обычном профиле показывает проверенный срез на указанную дату. Опциональный автоматический пересчёт с отдельным источником и сверенной границей архива описан в [LFPT-1086](LFPT-1086-rating-pilot-refresh.md). Переключение флага/списка/файла применяется после перезапуска. Отключение возвращает старые страницы без изменения результатов.

## Проверка

- Весь согласованный список, обе карточки Макса, невыбранные игроки каждой категории.
- Форма входа и OAuth2; неаутентифицированный principal, гость, совпадающий ID организатора не дают доступ.
- Подмена ID через query/cookie/header не меняет решение.
- Пустой список, выключенный пилот, некорректный срез.
- В разрешённом рейтинге все 353 игрока; Elo и места совпадают с контрольным срезом.
- В браузере выбранный игрок получает новый кабинет, посторонний — прежний HTML без новых ресурсов и данных; выход из аккаунта возвращает прежнюю таблицу.
- Обычный профиль тестируется на отдельной локальной БД, без SMTP, планировщиков и доступа к боевой базе.
