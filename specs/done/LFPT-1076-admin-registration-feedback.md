# LFPT-1076. Форма повторной записи

Ручная запись сохраняет выбранные профили и введённые поля при отказе. Повтор неизменённого гостевого запроса передаёт тот же идентификатор. Сообщение и код запроса выводятся как текст. После успеха обновляются счётчики и открытый список участников. Админка показывает количество подтверждённых пар по списку, который уже объединён по парам.
