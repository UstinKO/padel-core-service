# LFPT-0818 — удобство отчёта источников записей

Статус: approved, 2026-11-03. План согласован пользователем.

Компактная навигация только этого экрана, три основные карточки, дополнительные
фильтры и подробная сводка в раскрываемых секциях. Быстрые периоды по датам
Буэнос-Айреса: текущий месяц, предыдущий месяц, последние 30 дней включительно.
Таблица с объединёнными описательными полями, короткими заголовками и закреплённой
шапкой внутри области прокрутки. Все фильтры и показатели сохраняются, API и
расчёты не меняются. Покрытие новым учётом не приравнивается к известному источнику.
ES/RU/EN, клавиатура и мобильная ширина. Проверить фильтры, ошибки и пагинацию.
