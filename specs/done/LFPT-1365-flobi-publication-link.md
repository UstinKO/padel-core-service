# LFPT-1365: Ссылка для публикации во Flobi

## Статус и источник
Реализация по поручению владельца: добавить третий вариант Flobi к Telegram и
Instagram в существующее окно публикации. Issue #1365; доработка #1247/#1249.

## Поведение
В общем диалоге `/admin/tournaments` доступен Flobi. Копирование и обратная связь
используют действующий механизм; выбор другого канала сохраняет ID мероприятия.

| Размещение | utm_source | utm_medium | utm_campaign | utm_content |
|---|---|---|---|---|
| Flobi | flobi | referral | flobi_tournaments | torneo_ID |

Кампания следует существующей схеме «площадка_размещение». Прямая ссылка строится
из канонического siteBaseUrl и `/torneo/ID`; query и якорь базового адреса или
админки не переносятся, каждая UTM-метка встречается ровно один раз. Telegram
и Instagram сохраняют прежние кампании и medium=social. Повторное открытие
возвращает выбор Telegram. Роли, видимость и доступность кнопки не меняются.

Flobi — одинаковое название на RU/ES/EN; остальные подписи остаются локализованными.
Три варианта помещаются в строку на компьютере, на телефоне используются
существующие вертикальные кнопки. URL не выходит за границы диалога.

## Проверка
- Реальный Thymeleaf и браузер: RU/ES/EN, 1440/390/320 px, два ID события.
- Буфер обмена, отказ Clipboard API, переключение и повторное открытие.
- Базовый URL с query/якорем и повторными UTM не даёт повторных меток.
- Канонический маршрут и переход со сменой языка сохраняют query; GA4 config
  получает page_location/page_path с flobi/referral. Тесты блокируют внешние SDK.
- Maven verify, docs-drift, agent-migration, relay, diff-check.

## Границы и выпуск
Только frontend; новых Java API, миграций или настроек GA4 нет. Нового события
аналитики при копировании нет. Сама UTM-ссылка не гарантирует учёт каждого клика.
До отдельного выпуска нельзя подтвердить живое получение Flobi в production GA4.
Изолированные проверки не отправляют тестовые просмотры в рабочую аналитику.
Подготовка PR входит в поручение; мерж и деплой выполняются отдельным поручением.

## Результаты проверки
24.11.2026: Maven verify на отдельной PostgreSQL — 1495 тестов во всех модулях,
0 ошибок/сбоев, 4 штатных пропуска. После уточнения тестовой HTML-обвязки повторно
пройдены 12 проверок настоящего Thymeleaf-фрагмента и все 11 браузерных сценариев.
RU/ES/EN, 1440/390/320 px, три канала, два ID, настоящий буфер обмена,
отказ Clipboard API, повторное открытие и отсутствие дублированных UTM проверены.
Общий GA4-тег получает полный page_location/page_path с Flobi-метками; внешние
SDK в автоматических тестах не загружались. Браузерная проверка добавлена в CI.

Визуально проверено действующее окно с общими стилями админки на 1440 и 390 px.
Тестовая обвязка не загружает внешние шрифты и иконки; production-подключения
не меняются. Физические iPhone/Android не проверялись.

Read-only GET рабочего `/torneo/196` с Flobi-метками, также с lang=es: HTTP 200,
назначение и query сохранены, дополнительного перенаправления нет. Проверочный
визит с analytics_test=on не дал подтверждённой строки flobi/referral в текущем
Realtime; это не доказательство отсутствия перехода. Живая атрибуция остаётся
проверкой выпуска, источники/фильтры GA4 этой задачей не менялись.

docs-drift и agent-migration — 0 расхождений; 48 relay-тестов, JS syntax и
git diff --check прошли. Первая проверка relay была ограничена запретом среды
на временные сокеты/ps; повтор с нужными правами прошёл.
