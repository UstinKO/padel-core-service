# LFPT-0823 — названия открытых форматов в отчёте

Статус: approved, 2026-11-03. Запрос пользователя.

Для фактических типов CANCHA_ABIERTA и PADEL_CLINIC отчёт источников показывает
локализованное название формата из существующего словаря ES/RU/EN.
Старое поле nombre, например Mixto · TODOS, не изменяется. Прочие названия,
расчёты, фильтры и доступ сохраняются. Проверка: оба типа, три локали,
неизменность сохранённого имени и обычного турнира.
