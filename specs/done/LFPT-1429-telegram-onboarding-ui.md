# LFPT-1429: Интерфейс общего подключения Telegram

Зависит от серверной #1428. Сохраняется текущий Thymeleaf-интерфейс и оранжевый стиль. Страница `/telegram/connect` без аналитики получает временный секрет из fragment, убирает его из адреса и сохраняет в серверной сессии через CSRF. Вход и Google используют безопасный destination без секрета.

Игрок видит свой профиль и согласие, явно продолжает; затем открывает бота для окончательного подтверждения. READY/PENDING/CONNECTED/INVALID локализованы ES/RU/EN. Загрузка страницы не подтверждает профиль. Двойной клик блокируется; неизвестный ответ не повторяет POST, доступна ручная проверка. Потеря сессии требует нового входа и повторного открытия личной ссылки.

В редакторе появляется общая ссылка бота без персональных данных, её копирование и ручной вариант при отказе clipboard. Ручная рассылка не запускается, выбор адресатов/текст не меняются.

Приёмка: настоящий Chromium, ES/RU/EN, 320/390/1440; вход и Google destination, явный запрос и его повторное открытие, завершение подменённым Telegram, потеря ответа после настоящего POST, истечение сессии, невалидная ссылка, общая ссылка и clipboard. Данные синтетические, production и реальные сообщения не используются.
