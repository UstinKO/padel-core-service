# LFPT-1262 — сервер календаря мероприятий

План подтверждён 22.11.2026. Интерфейс — #1263. Новая модель событий, назначение координаторов и изменение прав не входят.

`GET /api/admin/events/calendar?month=YYYY-MM&clubId=&format=&gender=&level=&status=`.
Только существующие служебные роли. SUPER_ADMIN/ADMIN — все мероприятия; OWNER/ORGANIZER/CLUB_ADMIN — собственные. Чужие события на той же площадке недоступны. Фильтр клуба включает доступные события и назначенные площадки клуба, не раскрывает чужие клубы и счётчики. Ответ no-store, содержит минимальные сведения без контактов и оплат.

Месяц по умолчанию и сегодняшний день — Buenos Aires. Начало события передаётся отдельными локальными датой/временем с его IANA-зоной, известное окончание рассчитывается существующим EventSchedule; неизвестное не придумывается. Длительные события, переходящие границу месяца, включаются. Отменённые скрыты без явного фильтра. Прошедшая дата не меняет статус.

Все доступные события месяца без пагинационного обрезания, порядок дата/время/ID. periodCount до фильтров отличает пустой месяц от пустой фильтрации. Несуществующий/чужой клуб не расширяет выборку. Новые данные не записываются.

Проверки: прямые запросы ролей, отсутствие доступа игрока/анонима, два владельца на одной площадке, две назначенные площадки, черновики/отмены/переносы, диапазон уровня, месяцы/год/високосный февраль и события через полночь. Тестовая БД отдельная.
