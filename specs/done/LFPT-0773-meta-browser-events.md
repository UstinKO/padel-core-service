## Требования
- Один общий скрипт через fragments/analytics::cookie-consent; подключение SDK после маркетингового согласия и включённой конфигурации.
- PageView только публичных контентных страниц; ViewContent только /torneo/{id}. Личный кабинет может выдавать серверные конверсии, но не PageView/ViewContent приватного раздела. Логин, регистрация аккаунта, токеновые/служебные страницы не инициализируют Pixel.
- Конверсии только из серверного журнала: EventRegistration / EventWaitlist / EventRegistrationPending с сохранённым eventID. Purchase в браузере отсутствует.
- Первый контекст сохраняется до запроса записи; сбой аналитики не отменяет запрос записи. UTM из исходного перехода сохраняются до очистки URL и при входе не теряются.
- Отказ/отзыв немедленно прекращает события. После отзыва уже загруженного SDK повторное согласие сохраняет новый контекст, но Pixel возобновляется только на следующей безопасной странице, чтобы не смешать старую идентичность.
- Нет noscript-пикселя, обходящего согласие. Отключена autoConfig; единственный advanced-matching параметр — согласованный хеш случайного external_id. Токены и контакты не передаются.
- SDK не загружается на страницах с неизвестными/чувствительными query или referrer. Валидные рекламные параметры сохраняются локально сервером, затем убираются из URL до загрузки Pixel.

## Сквозная проверка приложения
На собранном приложении с отдельной локальной PostgreSQL и одноразовыми аккаунтами проверены UTM → согласие → вход → подтверждённая запись/резерв → ручные CASH 400 ARS → итог 1000 ARS → повтор. Два денежных события 400/600 и один полностью оплаченный подтверждённый слот сверены с защищённым CSV: HTTP 200, UTM сохранены, контактов нет. CSV использует boolean t/f; оплаченный слот имеет fully_paid_slot=t. После перезапуска штатная очередь CAPI доставила оба новых Purchase physical_store по одной попытке; пользователь подтвердил и показал две покупки со статусом «Обработка завершена» в Meta Test Events → Офлайн. Миграция не переклассифицировала и не переотправила прежние события. Одноразовые аккаунты и отдельная база сквозного теста удалены после проверки.

Настоящий SDK загружен и формирует PageView/ViewContent/EventRegistration/EventWaitlist с серверными UUID; браузерные запросы перехвачены до Meta. Приём браузерного Pixel и качество сопоставления не заявляются. Безденежный контроль CAPI website отдельно подтверждён в интерфейсе Meta, но не заменяет проверку Pixel.

Итоговый clean verify после обновления backend/master: 607 тестов, 0 failures/errors/skipped. Chromium 11/11, docs-drift и agent-migration без расхождений. Контракт source, серверные секреты и ограничения Test Events — в backend-спецификации и docs/endpoints/meta-marketing.md.
