# LFPT-1025: Фильтры административного списка мероприятий

В `/admin/tournaments` можно совместить параметры `from`, `to`, `format` и `clubId`. Обе границы по локальной дате начала включены. Каждую границу можно оставить пустой. При обратном диапазоне модель содержит признак ошибки.

Клубный администратор ограничен своим клубом, владелец и организатор — доступными им мероприятиями по действующей проверке управления. Администраторы платформы могут фильтровать весь список. Количество результатов считается после применения всех фильтров.

Индивидуальный Americano и Americano с постоянными парами различаются по полям типа и формата участия. Тип для строки списка определяется из тех же полей. Исходное название мероприятия сохраняется в базе.

Интерфейс описан в задаче #1026.
