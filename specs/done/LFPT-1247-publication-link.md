# LFPT-1247: Ссылка для публикации мероприятия

## Статус
done

## Источник и согласование
Issue #1247. Владелец согласовал интерактивный макет и 21.11.2026 поручил добавить
кнопку в действующую админку, затем проверить интерфейс на телефоне.

## Поведение
На `/admin/tournaments` в таблице и мобильных карточках доступна кнопка
«Ссылка для публикации». Используется существующее право `canView`; кнопка
показывается для активного мероприятия, кроме черновика и отменённого.
Завершённое опубликованное мероприятие сохраняет возможность поделиться карточкой.
Доступ по прямой ссылке не переводит закрытое мероприятие в публичные списки.

Одно общее окно показывает формат/категорию, дату, время и клуб выбранного события.
По умолчанию выбран Telegram. Переключение на Instagram Stories меняет размещение,
но не ID события. Повторное открытие сбрасывает канал и результат копирования.

| Размещение | utm_source | utm_medium | utm_campaign |
|---|---|---|---|
| Telegram | telegram | social | telegram_posts |
| Instagram Stories | instagram | social | instagram_stories |

Назначение — `${siteBaseUrl}/torneo/ID`, `utm_content=torneo_ID`.
Канонический `siteBaseUrl` уже добавлен общим PageModelAdvice. Текущий query,
якорь, локаль, admin URL, данные участников и произвольное назначение не копируются.
Генерация и копирование локальны: нет запроса регистрации или события аналитики.
Метки согласованы с существующими постоянными ссылками; они не гарантируют
учёт каждого клика при отсутствии согласия/работающей аналитики.

«Скопировано» появляется только после успешного Clipboard API. При отсутствии
или отказе API ссылка выделяется, доступна инструкция ручного копирования.
Закрытие, Escape и возврат фокуса поддерживаются нативным dialog.
Во время копирования кнопка недоступна; устаревший ответ не меняет другое окно
или канал. RU/ES/EN; элементы управления доступны на 320/390 px.

## Границы и MASTER
Только Thymeleaf, CSS, JS и строки интерфейса. Роли, публикация мероприятия,
регистрации, оплаты, аналитические настройки и существующие редиректы не меняются.
Новых серверных маршрутов и миграций нет. Это отдельная frontend-задача;
переход админки на React и комплект публикации результатов не входят.
Мерж и production-деплой не поручены в этом запросе.

## Приёмка
- Реальный браузер: два мероприятия, оба размещения, копирование и отказ API,
  закрытие/Escape/возврат фокуса, RU/ES/EN, 320/390 px и desktop.
- Проверка реального рендера шаблона, прав и скрытых состояний.
- Полный Maven verify на отдельной PostgreSQL; docs-drift, agent-migration,
  relay и git diff --check. Ограничения физического устройства указать явно.

## Выполненная браузерная проверка
21.11.2026 настоящая страница Spring Boot проверена в Chromium при ширине
320, 390 и 1440 px на отдельной PostgreSQL с синтетическими данными.
Внешняя аналитика и отправка писем отключены только в локальном тестовом запуске.
Физический iPhone/Safari не проверялся.

- Таблица и мобильные карточки: два разных мероприятия, один общий dialog.
  У черновика, отменённого и удалённого события кнопки нет.
- Telegram и Stories сохраняют ID события; готовая ссылка использует канонический
  адрес. Чужие UTM из URL админки в неё не переносятся.
- Успешное копирование сверено с содержимым настоящего буфера обмена.
- Отказ и задержка Clipboard API проверены на локальном стенде с теми же
  отрендеренными элементами и неизменённым production JS. При отказе выделен
  полный адрес; запоздавший ответ не показывает успех для нового канала.
- Повторное открытие сбрасывает канал/сообщения; закрытие и Escape возвращают
  фокус, фон разблокируется. На 320 px текст и кнопка копирования доступны,
  горизонтального переполнения диалога нет. RU/ES/EN проверены в браузере.

Общий docs-drift воспроизводит 4 прежних расхождения и на чистом master b2a2ece:
две устаревшие версии схемы, описание is_test_tournament и /admin/tournaments/{id}/test-status.
Это соседняя уже включённая работа; текущая функция не меняет эти контракты.

Финальный чистый Java verify: 1133 теста, 0 failures/errors, 2 штатных пропуска.
11 новых проверок рендера и выбора фрагмента прошли. 48 relay-тестов,
agent-migration, JS syntax и diff-check прошли. React/Expo не менялись;
локальный Maven запускался с `-Dskip.frontend=true`, полный frontend проверяет CI.
