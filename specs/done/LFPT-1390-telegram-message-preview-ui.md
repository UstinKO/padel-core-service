# Интерфейс подготовки Telegram-сообщений

Согласованный первый этап от 25.11.2026; интерфейс #1390, сервер #1389 / PR #1391. Включение на production не поручено.

Страницы существующей админки сохраняют оранжевую палитру, Inter и действующую навигацию. Вход из оплат мероприятия и общей панели SUPER_ADMIN. Каталог и итоговый предпросмотр читаются из API; локальное состояние хранит только текущий несохранённый выбор/текст и не удостоверяет права.

Группы и точные категории объединяются, отдельные игроки выбираются поиском имени/фамилии; снятие галочки исключает игрока даже при выбранной группе. Сброс очищает выбор. Перед предпросмотром нет выбранных адресатов по умолчанию. SUPER_ADMIN видит пояснение о дополнительных адресатах общей базы; остальные получают только каталог своего мероприятия.

Предпросмотр показывает обычный текст, доступных и недоступных с причиной. Изменение текста/выбора скрывает и очищает прежний результат. Поздний ответ не восстанавливает устаревший предпросмотр. Неизвестный результат запроса не запускает отправку: API этапа вообще ничего не отправляет. Кнопок отправки/пробы себе нет; этап явно подписан. Весь пользовательский ввод — textContent; CSRF действующего сайта.

Единая подписка объясняется перед подключением: записи, напоминания и приглашения; /stop отключает до повторного подключения. Переключатели приглашений не добавляются. Функции рейтинга, кабинета, подтверждений и чеков сохраняются.

Приёмка: настоящий Spring HTTP и отдельная PostgreSQL с синтетическими владельцами/игроками, Playwright Chromium RU1440/ES390/EN320, выбор групп/категорий/отдельных/исключений, резерв/одиночные, безопасный текст и поздний ответ, права разных аккаунтов. Telegram/почта подменены. Шаблоны, очередь/история, проба себе, отправка и меню бота — следующие этапы.
