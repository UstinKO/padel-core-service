# Запрос на доработку

## Что нужно сделать
Сделать на рабочем сайте 1-padel.com короткую ссылку для профиля Instagram:

- `/ig-bio` → `https://1-padel.com/?utm_source=instagram&utm_medium=social&utm_campaign=instagram_profile`

Сделать перенаправление 302. Проверить, что адрес `/ig-bio` не занят, после перехода открывается главная страница и все UTM-метки остаются в адресе.

## Где это происходит
Публичный сайт, корневой путь `1-padel.com/ig-bio`.

## Зачем это нужно
Короткая ссылка для раздела "ссылка в био" профиля Instagram, с собственной UTM-меткой источника для аналитики переходов (аналогично уже сделанным `/oct-tg`, `/oct-wa`, `/oct-ig` из LFPT-0472).

## Кто это увидит/использует
- [x] Игроки (все, кто перейдёт по ссылке из Instagram-профиля)
- [ ] Организаторы/владельцы клубов
- [ ] Только я (суперадмин)

## Насколько срочно
- [x] Важно, но не горит — в ближайших неделях

## Примеры / референсы
Аналог уже реализованных `/oct-tg`, `/oct-wa`, `/oct-ig` (LFPT-0472, `MarketingRedirectController`) — обычный HTTP-редирект 302 на конечный URL с заранее заданными UTM-параметрами.

## Есть ли ограничения
- Проверить, что `/ig-bio` не занят другим маршрутом/страницей.
- Переход должен работать без авторизации (анонимные пользователи).
- После перехода в адресной строке браузера должны остаться все UTM-параметры целевого URL.
- Сообщить, что нужно задеплоить, и проверить ссылку после деплоя.
