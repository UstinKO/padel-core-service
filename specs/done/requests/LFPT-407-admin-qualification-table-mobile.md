# Запрос на доработку

> Этот файл заполняет заказчик/владелец продукта. Без технических терминов — просто опишите, что нужно и зачем. Технической проработкой (превращением этого в полную фиче-спеку) занимается agent-аналитик.

## Что нужно сделать
Адаптировать таблицу квалификации в админке под мобильную версию.

Сейчас у обычных пользователей таблица квалификации на телефоне отображается нормально и адаптирована под мобильный экран. В админке эта же таблица не адаптирована: она слишком широкая, часть колонок уходит за экран, из-за чего приходится постоянно прокручивать её вправо-влево.

Нужно сделать для администратора такую же мобильную адаптацию таблицы, как уже сделано в пользовательской версии.

Приоритетно на экране должны нормально помещаться: место → статус → пара → M1 → M2.

Можно уменьшить ширину колонок, отступы и размер текста, а имена переносить внутри ячейки.

## Где это происходит
Админ-панель, страница управления турниром Team Playoff (`/tournaments/team-playoff/admin/{id}`), раздел "Квалификация" — таблица рейтинга квалификации.

## Зачем это нужно
Главная задача — чтобы администратор во время турнира мог нормально смотреть таблицу с телефона без постоянной горизонтальной прокрутки.

## Примеры / референсы
Скриншот с телефона организатора (переслан через Telegram, `photos/file_8.jpg`, отправитель переслал от Evgeny_754): страница `/tournaments/team-playoff/admin/{id}`, секция "Квалификация", видны колонки `#`/Статус/Пара/M1/M2, дальше таблица обрезана под горизонтальный скролл.

Похожая доработка уже сделана для публичных страниц турниров в issue #364 (`tournaments/team-playoff/view.html` и др.) — можно использовать как образец подхода (уменьшение padding/font-size через `@media`).

## Есть ли ограничения
Не менять структуру таблицы (набор и порядок колонок), не трогать публичные страницы турниров (уже адаптированы) — доработка только для админской версии.
