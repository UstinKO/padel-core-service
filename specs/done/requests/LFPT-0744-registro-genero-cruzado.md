# Запрос на доработку

## Что нужно сделать

Разрешить женщинам регистрироваться на мужские турниры, а мужчинам — на женские, сохранив ограничение по уровню "±1 ступень" (#303). Пол игрока и различие обозначений C/D сами по себе не должны блокировать регистрацию — сейчас блокируют.

Для сравнения мужских (C) и женских (D) категорий использовать установленную для 1-Padel шкалу соответствия, а не считать одинаковые номера равными:

- D9 → расчётный эквивалент C10
- D8 → C9
- D7 → C8
- D6 → C7
- D5 → C6
- D4 → C5

Общее правило: `Cn` → расчётное значение `n`; `Dn` → расчётное значение `n + 1`.

Регистрация разрешена, если `abs(расчётный уровень игрока − расчётный уровень турнира) ≤ 1` — так же, как уже работает правило "одна ступень" внутри одного пола.

Не менять исходную категорию игрока в профиле, его рейтинг и отображаемый уровень — игрок D6 должен продолжать отображаться как D6. Не добавлять C10 в пользовательский список категорий — значение 10 используется только внутри расчёта, не округлять его до C9.

Примеры допуска:
- Турнир C7: C6/C7/C8 — разрешено, C9 — запрещено; D5(≈C6)/D6(≈C7)/D7(≈C8) — разрешено, D8(≈C9)/D9(≈C10) — запрещено.
- Турнир C9: C8/C9 — разрешено, C7 — запрещено; D7(≈C8)/D8(≈C9)/D9(≈C10) — разрешено (D9 попадает в допустимую соседнюю ступень), D6(≈C7) — запрещено.
- Обратное направление: игрок C7 → турнир D6 — разрешено (расчётные уровни совпадают); игрок C9 → турнир D6 — запрещено (разница 2 ступени).

Если регистрация недоступна из-за уровня — сообщение должно объяснять именно это, а не говорить о запрете по полу. Например: «Ваш уровень — D8. Регистрация на турнир C7 с вашим текущим уровнем недоступна по правилам допуска». В сообщении — фактическая категория игрока из профиля, не расчётный эквивалент.

Если у игрока нет указанного уровня — уже существует попап "Укажите свой уровень в личном кабинете" с кнопкой в профиль (сделано ранее, #632) — этот запрос его не меняет.

В парных турнирах партнёр тоже не должен получать отказ только из-за пола или префикса категории (C/D) — те же правила проверки, что и для себя.

Администратору/координатору — ручной допуск участника независимо от этой проверки должен продолжать работать как сейчас.

Не менять автоматически: пол игрока, категорию в профиле, категорию/обозначение турнира, существующие регистрации, ранее принятые решения администратора, историю турниров и результаты.
