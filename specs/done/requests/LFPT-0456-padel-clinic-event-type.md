## Что нужно сделать
Добавить новый тип мероприятия при создании события.

В выпадающий список «Тип турнира / мероприятия» добавить новый вариант:
- RU: Тренировка + игра
- ES: Clínica de pádel
- EN: Padel Clinic

Новый тип должен работать как отдельный event_type, аналогично King of Court, Americano, Americano Пары, Открытый корт.

На карточках и странице мероприятия название должно отображаться в зависимости от выбранного языка сайта.

Собственные названия клубов и другие контентные поля при этом не переводятся.

## Где это происходит
Форма создания/редактирования турнира в админ-панели (выпадающий список «Тип турнира»), карточки турниров на публичных страницах, страница конкретного турнира.

## Зачем это нужно
Организаторам нужен отдельный, узнаваемый тип мероприятия для групповых тренировок с игрой — отличный от уже существующих форматов.
