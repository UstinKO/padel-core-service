# Запрос на доработку

> Заполнено по мотивам клиентского сообщения в Telegram (отправитель — customer, переслано от Evgeny_754, `telegram_launch_message_id: 5347`).

## Что нужно сделать

Подключить индивидуальную отмену записи в 1Padel.App — симметрично уже существующей в приложении индивидуальной записи (LFPT-0660): игрок должен иметь возможность отменить свою запись на индивидуальное мероприятие прямо в приложении, не переходя на сайт.

В исходном сообщении была ссылка на уже подготовленный патч в стороннем репозитории заказчика (`eugenegwork-coder/1padel-app`, поверх PR #661) с инструкцией применить его к актуальной версии. Этот патч не был получен — см. раздел «Источник» фиче-спеки: встроенный защитный механизм сессии заблокировал загрузку кода из внешнего, не принадлежащего проекту репозитория. Реализация ниже сделана самостоятельно, по функциональному описанию из сообщения.

## Где это происходит

Экран «Мои мероприятия» (`MyEventsScreen`) в веб-клиенте 1Padel.App (`/app/`) — там же, где сейчас видна активная запись игрока.

## Зачем это нужно

Чтобы отменить запись, игрок сейчас вынужден переходить на сайт — это лишний шаг для того же действия, которое уже доступно внутри приложения для самой записи.

## Примеры / референсы

Симметрично LFPT-0660 (индивидуальная запись в приложении, PR #661).

## Есть ли ограничения

- Парная (`DOBLES`) отмена участия через приложение — не входит, остаётся на сайте (выбор «отменить только себя / всю пару / заменить» сложнее и не запрошен).
- Условия мероприятий и финансовую политику сайта (штрафы, дедлайны) не менять — только дать доступ к уже существующему действию из приложения.
- Настоящие записи реальных игроков не трогать при проверке — только специально созданный тестовый аккаунт/мероприятие.
