# Запрос на доработку

> Источник: Telegram, тема «AI Разработка» (`[отправитель: customer]`, `telegram_launch_message_id: 5076`). GitHub issue [#567](https://github.com/UstinKO/padel-core-service/issues/567).

## Что нужно сделать
В ревью нашли дефект формы: после выбора игрока кнопка «×» убирает его карточку, но поле поиска не возвращается. Выбрать другого игрока обычным способом (через поиск) уже нельзя. В `clearSelection()` нужно снова показывать `searchWrap` после сброса выбора — этот случай (возможность сбросить выбор и снова ввести поисковый запрос) уже указан в критериях спеки LFPT-0562, но не выполняется на практике. Рекомендация — исправить до публичного анонса фичи.

## Где это происходит
Форма «Agregar equipo» на странице Team Playoff (`/tournaments/team-playoff/admin/{tournamentId}`) — блок поиска/выбора игрока для каждого из двух слотов команды. Фича добавлена в LFPT-0562 (issue #562, PR #564), ещё не анонсирована публично.

## Зачем это нужно
Без исправления координатор клуба, случайно или осознанно сбросивший выбор игрока в форме добавления команды «на месте», не может продолжить работу с этим слотом через поиск — застревает, вынужден перезагружать страницу и начинать заново.

## Кто это увидит/использует
- [x] Организаторы/владельцы клубов (координаторы, добавляющие команды «с улицы» через админку Team Playoff)

## Насколько срочно
- [x] Важно, но не горит — исправить до публичного анонса фичи LFPT-0562

## Примеры / референсы
Диагностика от заказчика: баг в `clearSelection()` — отсутствует возврат `searchWrap` в видимое состояние (симметрично тому, как `selectPlayer()` его скрывает).

## Есть ли ограничения
Не менять поведение переключателя «Новый игрок» (`toggleBtn`) и остальную часть формы «Agregar equipo» — исправление точечное, только для сценария сброса выбора через «×».
