# Запрос на доработку

## Что нужно сделать
Сделать на рабочем сайте 1-padel.com три короткие ссылки для октябрьского календаря:

- `/oct-tg` → `https://1-padel.com/?utm_source=telegram&utm_medium=social&utm_campaign=calendar_october`
- `/oct-wa` → `https://1-padel.com/?utm_source=whatsapp&utm_medium=message&utm_campaign=calendar_october`
- `/oct-ig` → `https://1-padel.com/?utm_source=instagram&utm_medium=social&utm_campaign=calendar_october`

Настроить перенаправления так, чтобы после перехода все UTM-параметры оставались в адресе.

## Где это происходит
Публичный сайт, корневые пути `1-padel.com/oct-tg`, `1-padel.com/oct-wa`, `1-padel.com/oct-ig`.

## Зачем это нужно
Короткие, запоминающиеся ссылки для рассылки октябрьского календаря турниров по трём каналам (Telegram, WhatsApp, Instagram) с раздельной UTM-разметкой источника для аналитики.

## Примеры / референсы
Нет, формат — обычный HTTP-редирект 301/302 на конечный URL с заранее заданными UTM-параметрами.
