# Запрос на доработку

## Что нужно сделать
В одном из писем пользователю приходит кнопка/ссылка «Ver página del torneo», но при нажатии открывается старый домен `epadel.org` — пользователь получает ошибку и не может открыть страницу.

Нужен полный аудит всех email-уведомлений, которые отправляет система, и проверка всех ссылок на сайт:

1. Найти все email-шаблоны, которые отправляет 1-Padel, включая как минимум: подтверждение регистрации; регистрация в резерв/список ожидания; перевод из резерва в основной состав; отмена участия; перевод участника в резерв; напоминание перед турниром; письмо для индивидуального турнира; письмо для парного турнира; Cancha Abierta; поиск партнёра; уведомление, что новый игрок ищет партнёра; подтверждение/восстановление пароля; любые другие системные письма со ссылками.
2. Для каждого письма проверить: на какой домен ведёт ссылка, корректно ли формируется URL, существует ли целевая страница, ведёт ли именно на нужный турнир/профиль/страницу.
3. Убрать старый домен `epadel.org` из всех пользовательских ссылок — везде должен быть `1-padel.com`.
4. Не хранить домен вручную внутри каждого шаблона — ссылки должны формироваться через единый системный base URL, чтобы при смене домена в будущем не нужно было вручную менять каждый email-шаблон.
5. Если письмо относится к конкретному турниру/мероприятию — ссылка должна вести на страницу именно этого турнира (с правильными `tournamentId`/`token` и другими нужными параметрами), а не просто на главную. Проверить это для всех языковых версий письма (ru/es/en), если они есть.
6. Проверить и кнопку, и текстовую ссылку, и ссылку внизу письма — не только основную кнопку.
7. После проверки — предоставить список: какие шаблоны проверены, какие содержали неправильные ссылки, какие старые URL найдены, что исправлено.

## Где это происходит
Email-уведомления, которые отправляет система (Thymeleaf-шаблоны `templates/email/**`) — все письма игрокам.

## Зачем это нужно
Пользователь не может открыть страницу турнира по ссылке из письма — ссылка ведёт на несуществующий/старый домен. Это влияет на доверие к сервису и мешает игрокам попадать на нужную страницу.
