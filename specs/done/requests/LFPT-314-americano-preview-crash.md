# Запрос на доработку

## Что нужно сделать
Есть страница/ссылка в разделе Americano-турниров (превью инициализации турнира), которая при заходе выдаёт ошибку сервера вместо страницы. Нужно, чтобы вместо ошибки пользователь видел рабочую страницу — например, ту же страницу настройки турнира, что уже используется в других местах.

## Где это происходит
Раздел администрирования Americano-турниров, страница предпросмотра/инициализации для турнира, который ещё не запущен (`/tournaments/americano/admin/{id}/preview`).

## Зачем это нужно
Любая ошибка сервера (500 / белый экран) на админ-панели — плохой опыт для организатора и потенциальный источник тикетов в поддержку, даже если сама ссылка используется редко. Раз баг обнаружен и задокументирован — стоит закрыть его, а не оставлять как известный риск.

## Примеры / референсы
GitHub issue: https://github.com/UstinKO/padel-core-service/issues/314. В `.claude/CLAUDE.md` этот баг уже описан в разделе "Americano Admin Pages" как известное ограничение.

## Есть ли ограничения
Страница, судя по всему, нигде не используется как реальная ссылка в интерфейсе (не нашли на неё переходов из других экранов) — если это подтвердится при анализе, простое исправление (например, перенаправление на уже работающую страницу настройки турнира) предпочтительнее, чем создание нового полноценного экрана с нуля.
