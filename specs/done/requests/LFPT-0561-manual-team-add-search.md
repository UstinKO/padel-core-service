# Запрос на доработку

> Этот файл заполняет заказчик/владелец продукта. Без технических терминов — просто опишите, что нужно и зачем. Технической проработкой (превращением этого в полную фиче-спеку) занимается agent-аналитик.

## Что нужно сделать
Переработать ручное добавление команды в парный турнир (раздел управления турниром → «Добавить команду»).

Сейчас нужно вручную вводить ID игрока. Заменить основной сценарий ввода ID на поиск игроков.

Для каждого игрока команды:

1. Должна быть возможность найти существующего пользователя по:
   - имени / фамилии;
   - номеру телефона;
   желательно дополнительно:
   - email.
2. При вводе данных показывать найденных пользователей из базы и позволять выбрать нужного.
3. Если пользователь найден: использовать существующий профиль, не создавая дубль.
4. Если игрок не найден: дать возможность прямо из этой формы быстро создать нового игрока. Для нового игрока запрашивать те же основные данные, которые используются при обычной регистрации: имя, фамилия, номер телефона, другие действительно обязательные поля, если они необходимы системе.
5. Для пары должны поддерживаться все сценарии:
   - оба игрока уже существуют в базе;
   - первый существует, второй новый;
   - первый новый, второй существует;
   - оба игрока новые.
6. После сохранения команды:
   - команда появляется среди участников турнира;
   - оба игрока попадают в систему турнира;
   - команда автоматически появляется в разделе «Оплаты и посещаемость»;
   - дальше с ней можно работать так же, как с командой, зарегистрировавшейся через сайт.
7. Не создавать дубли пользователей при совпадении существующего номера телефона / существующего аккаунта.

## Где это происходит
Раздел управления турниром → «Добавить команду».

## Зачем это нужно
Сотрудники клуба не знают ID игроков, сами игроки тоже не знают свой ID. Команду часто нужно добавить прямо на месте, если она не смогла зарегистрироваться через сайт. Клуб должен за 20–30 секунд добавить пришедшую на месте команду без знания внутренних ID системы.
