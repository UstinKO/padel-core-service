# Запрос на доработку

## Что нужно сделать
Проверил LFPT-0688 на iPhone. Регистрация пары работает: пара появляется в списке оплат и посещаемости, поле Telegram вместо email тоже есть. Эти части менять не нужно.

Остались два недочёта:

1. Верхний поиск зарегистрированного партнёра показывает результаты. Но при ручном вводе имени, фамилии или телефона подсказки рядом с активным полем не появляются. Воспроизведите на мобильном Safari, вводя данные игрока, который точно находится через верхний поиск. Проверьте получение результатов и их отображение при открытой клавиатуре, прокрутке формы и переключении полей. Найденного игрока должно быть можно выбрать прямо из подсказки, не создавая дубль. Если совпадений нет, пустой список — нормальное поведение.

2. Окно регистрации на iPhone слишком узкое: по бокам остаётся много пустого места, заголовок «Registrar pareja para…» сжимается в несколько строк, название турнира почти не видно. Расширьте окно почти до краёв экрана с небольшими полями. Проверьте, чтобы текст, поля и кнопки помещались без горизонтальной прокрутки, а при открытой клавиатуре активное поле и подсказки оставались видны. В CSS проверьте позднее правило `.modal-dialog { width: 90%; }`, которое перекрывает мобильную ширину.

## Где это происходит
Модалка парной регистрации («Tengo compañero») на странице турнира (`tournament-details.html`) — та же модалка, которой касалась LFPT-0688.

## Зачем это нужно
На реальном iPhone форма парной регистрации неудобна: подсказки партнёра не помогают избежать дублей, а узкое окно мешает читать название турнира и заполнять поля.
