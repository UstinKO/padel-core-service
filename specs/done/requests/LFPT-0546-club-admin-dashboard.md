# Запрос на доработку

## Что нужно сделать
Адаптировать главную админ-панель (`GET /admin`) для учётной записи клуба (`ROLE_CLUB_ADMIN`).

Сейчас после входа клубная учётная запись видит глобальную статистику всей платформы:
- общее количество игроков;
- количество администраторов;
- все активные турниры;
- общий лист ожидания;
- последние турниры всей платформы.

Для клуба такая информация частично не нужна и вводит в заблуждение.

1. **Блок «Администраторы»** — не показывать клубной учётной записи количество администраторов всей платформы.
2. **«Активные турниры»** — показывать количество только тех активных турниров, которые принадлежат этому клубу / созданы клубной учётной записью. Если у клуба нет активных турниров — показывать 0.
3. **«Лист ожидания»** — показывать количество участников в листах ожидания только мероприятий этого клуба.
4. **«Последние турниры»** — показывать только последние турниры этого клуба, а не общий список турниров 1-Padel.
5. **«Всего игроков» / «Последние игроки»** — на первом этапе можно оставить текущую логику без изменений. Отдельно вопрос доступа клуба ко всей базе игроков будет решаться позже.

Важно: фильтрация должна происходить на backend, а не только визуально на frontend.

## Где это происходит
Главная админ-панель, `GET /admin` (`admin/panel.html`, `AdminController.adminPanel()`).

## Зачем это нужно
После входа клуб должен видеть свою рабочую информацию, а не статистику всей платформы 1-Padel.
