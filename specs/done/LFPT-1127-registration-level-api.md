# LFPT-1127: Fix уровень в записи на турнир — добавить сохранение с карточки

Источник — [#1127](https://github.com/UstinKO/padel-core-service/issues/1127). Интерфейс — #1128.

Карточка открытого для игрока турнира получает признак отсутствующего обязательного уровня из действующего правила допуска и текущего профиля. `PATCH /api/players/me/level` принимает JSON с `nivelJugador`, проверяет допустимость уровня игрока и обновляет только уровень и дату изменения активного профиля текущего игрока. Ответ при сохранении — 204, при недопустимом уровне игрока — 422. Для запроса действуют аутентификация и CSRF. Сохранение не создаёт запись на турнир. Серверная проверка допуска при записи и исключения из неё сохраняются.
