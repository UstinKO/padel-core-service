# LFPT-0716: Fix парная регистрация 1Padel.App — убрать неприменимый текст о штрафе −10 за опоздание

## Статус
done

## Источник
[GitHub issue #716](https://github.com/UstinKO/padel-core-service/issues/716) — техническая находка архитектора при анализе клиентского запроса [LFPT-0713](../requests/LFPT-0713-poisk-partnera-otmena-americano-usloviya.md), без отдельного клиентского запроса (прямая техническая постановка).

## Контекст / зачем

На экране парной регистрации мобильного приложения `1Padel.App` (`PairBookingScreen.tsx`) безусловно показывается строка о «стартовом штрафе −10 очков» за опоздание. Это условие технически никогда не применяется к парной регистрации: `TournamentService.setLateArrival` (`service/TournamentService.java:1570`) применяет штраф только к `TournamentType.AMERICANO` (индивидуальный) и `TournamentType.KING_OF_COURT`, и явно бросает исключение для любого другого типа турнира — а парная регистрация (`/api/tournaments/double/**`) существует только там, где это условие неприменимо. Игрок видит обязательство, которое реально никогда не наступит — вводящий в заблуждение текст.

Для сравнения, экран индивидуальной регистрации (`IndividualBookingScreen.tsx:79`) уже корректно показывает эту же строку только при `['KING_OF_COURT', 'AMERICANO'].includes(event.type)`.

## Связь с MASTER.md
Не затрагивает инварианты `specs/MASTER.md` — чисто текстовая/UI-правка, не меняет бизнес-правила.

## Требования

### Функциональные
- Убрать показ текста про штраф −10 очков на экране парной регистрации (`PairBookingScreen.tsx`) для любого турнира с парной записью.
- Не менять поведение на экране индивидуальной регистрации (`IndividualBookingScreen.tsx`) — там текст показывается корректно.

### Нефункциональные
- i18n: текст убирается сразу для всех трёх языков (ru/es/en) из `mobile-app/src/pairCopy.ts` — новых строк не добавляется.

## Вне скоупа
