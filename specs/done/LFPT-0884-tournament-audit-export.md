# LFPT-0884. Выгрузка турниров для сверки

Суперадминистратор скачивает файл JSON со счетами, статусами, связями по ID и версиями матчей. Выгрузка помогает сравнить текущие и прежние составы, проверить сигналы дублей и найти пары, где у партнёра отсутствует ID.

Файл включает технические поля турниров, регистраций и матчей, а также признаки гостевых записей и возможных совпадений. Подбор кандидатов и проверка совпадений происходят внутри запроса. Имена, контакты, учётные данные, финансовые поля и свободный текст в файл не попадают.

Сервер отдаёт файл по `GET /admin/export/tournament-audit` только суперадминистратору. Запрос выполняется в транзакции только для чтения с ограничением в 30 секунд. Схема данных и результаты турниров сохраняются без изменений.
