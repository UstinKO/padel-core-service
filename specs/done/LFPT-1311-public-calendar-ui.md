# LFPT-1311 — Публичный календарь: интерфейс

Статус: implemented
Зависит от серверной #1310, PR #1313. Интерфейс — PR #1314.

## Согласованный результат
Карточки остаются на главной. Небольшая кнопка со значком календаря рядом с расписанием открывает `/torneos` — только календарь, без переключателя видов и второго каталога. Шапка «Календарь мероприятий» компактная, слева. Уточнение структуры согласовано в чате 24.11.2026 и заменяет первоначальный вариант переключателя на странице турниров.

Быстрые фильтры: «Все / Турниры / Тренировки / Cancha Abierta». Турниры объединяют King of Court и оба Americano. Уровень виден, дополнительные фильтры раскрываются по кнопке на всех экранах; выбранные условия показываются съёмными плашками. Подгруппа Americano сохраняется при переходе с главной, чтобы не добавлять King of Court к выбранному Americano. Эти группы фильтруют безопасный публичный набор; в API отправляются только существующие точные EventFormat.

Иконка главной переносит уровень, пол и совместимый формат. При выборе Americano учитывается заданная модальность; без неё сохраняются оба Americano. Модальность сама по себе не является новым отдельным фильтром календаря. Существующие карточки, их список и процесс записи на главной не меняются.

Общие параметры месяца/дня/уровня/формата/клуба/организации/пола/статуса/языка сохраняются в URL, старое view=cards нормализуется в calendar. Личные статусы — только в памяти текущего аккаунта, «Мои записи» не входят в общую ссылку. Возврат ограничен безопасным маршрутом /torneos. Даты используют общую арифметику календаря, без конвертации локального времени события в зону устройства.

На компьютере — одинаковые ячейки, три строки и «Ещё N», справа или снизу полный список дня. На телефоне — даты/счётчики и список ниже. Выходные имеют мягкий тёплый фон, выбранная дата — оранжевую рамку, сегодняшний день — тёмный маркер, соседние месяцы приглушены.

## Приёмка

- [x] Полный публичный набор и безопасные собственные статусы, два игрока пары, резерв, одиночные заявки, выход и смена аккаунта.
- [x] Node: переход с главной, группы форматов, запрос API, диапазоны дат и безопасные ссылки.
- [x] Уточнённый календарь без каталога, компактные фильтры и кнопка главной в реальном браузере на компьютере и 320–390 px.
- [x] Итоговый verify после уточнения макета, RU/ES/EN, возврат и съёмные условия.
