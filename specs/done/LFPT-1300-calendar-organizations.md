# LFPT-1300 — организации административного календаря

План согласован 23.11.2026, интерфейс #1301. Отдельное nullable organizationName (120 символов) у Owner; имя/фамилия и клуб сохраняются. Миграция не придумывает названия старым аккаунтам. Пустая строка означает отсутствие организации, не подменяется именем человека или площадки.

Событие календаря содержит organizer: {id, name} по сохранённому ownerId; отсутствующий владелец даёт null. Список organizers состоит только из владельцев уже доступных мероприятий, до фильтров. organizerId сочетается с остальными фильтрами и никогда не расширяет доступ. Месяц загружается целиком, без пагинации. Даты, статусы и действующая модель прав сохраняются.

GET /api/admin/organizers/organizations возвращает accountId текущего аккаунта и accounts {id, accountName, organizationName}: SUPER_ADMIN — все аккаунты, остальные служебные роли — только свой. PUT /api/admin/organizers/{id}/organization меняет только название; SUPER_ADMIN — любой аккаунт, остальные — только свой. PLAYER/аноним не имеют доступа; мутация требует обычный CSRF. Контакты/пароли не возвращаются.

Проверки: сохранение и очистка названия, длина, CSRF и чужой id; клуб и организатор в одном месте; фильтр чужого организатора, отсутствие контактов, 35+ событий, совместные фильтры, nullable названия и отсутствие владельца. Production не меняется.
