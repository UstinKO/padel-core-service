# Форма создания гостя в списке игроков

Суперадмин открывает «Создать гостя» в разделе «Игроки», указывает имя и при наличии фамилию. После сохранения открывается новая карточка. При ошибке форма открывается повторно, сохраняя введённые данные.

Форма использует создание гостевой карточки из задачи LFPT-0982.
