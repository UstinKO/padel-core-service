# LFPT-1301 — компактный административный календарь

План согласован 23.11.2026, зависит от #1300. Первая строка время и категория, рядом женский/микст по фактическому gender (не по букве C/D). Затем точный формат, клуб, организация. Открытая регистрация без отдельной строки; остальные статусы из реального enum остаются компактной текстовой меткой. Статуса «идёт» в enum нет, по дате не придумывается.

Все события дня видны в сетке компьютера без «Ещё N», ограничения высоты, обрезания или вложенной прокрутки. CSS grid растит неделю по содержимому самого наполненного дня. На телефоне — навигация месяца, количество событий и полный список выбранного дня. Длинные названия переносятся без наведения. Фирменные цвета сохраняются.

organizerId совместим со списком и календарём, фильтрами клуба/формата/пола/уровня/статуса и контекстом возврата. В сворачиваемом блоке календаря редактируется название организации отдельно от имени аккаунта. Данные берутся из API; CSRF общий. SUPER_ADMIN видит аккаунты для переименования, другие — только свой. В фильтре исключительно владельцы доступных мероприятий.

Проверка: 5/12 декабря по три события, 35+ событий, один клуб с разными организаторами, пустое название, длинные подписи, RU/ES/EN, компьютер/телефон, возврат/refresh и серверные ограничения доступа. Только отдельная тестовая среда; production не меняется.
