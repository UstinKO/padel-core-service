# LFPT-1143. Сохранённая очередь на публичной странице Team Playoff

## Статус

done

Квалификационная таблица, раунды и очередь читаются в одном согласованном состоянии. Публичная страница получает очередь в порядке, который использует доска кортов координатора. В очереди отображаются записи матчей с назначенными соперниками. Команды без соперника имеют состояние ожидания в квалификационной таблице.

Назначение корта, удаление и повторное добавление используют действующие операции. Интерфейс описан в #1144.
