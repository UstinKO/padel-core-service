# LFPT-0910. Ответ на запрос об участии

Первая часть #910 подключает согласованный сценарий #760 в действующем кабинете и на странице ссылки из письма. Переключение кабинета на React, история, оплата и остальные сценарии #910 остаются в общей задаче.

- Кабинет показывает запросы игрока и доступные ему запросы за гостевых партнёров. Каждая карточка содержит имя участника, турнир и актуальный ответ.
- Действия определяются полями `canRespond` и `canDecline` серверного API. Для отказа требуется отдельное подтверждение с пояснением об условиях турнира.
- При неясном результате отправки кабинет запрашивает текущий статус. Повторная отправка требует нового действия игрока.
- Письмо ведёт на страницу предварительного просмотра. После входа игрок возвращается к запросу. Открытие ссылки не записывает ответ. Истёкшая ссылка предлагает ответить из кабинета.
- Интерфейс доступен на ES, RU и EN. Сквозная проверка использует отдельный локальный PostgreSQL и тестовое письмо.
