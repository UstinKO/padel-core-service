# LFPT-1503 — Интерфейс экспорта результатов

Зависит от #1502. Согласовано 27.11.2026. Только главный администратор получает кнопку в основной карточке любого мероприятия, включая завершённое или деактивированное. Название ES — Exportar resultados, RU — Экспорт результатов, EN — Export results. Название партнёра не используется.

Окно показывает количество участников и матчей, итоговый/предварительный характер и понятные предупреждения. По умолчанию Excel и отсутствие телефонов. CSV скачивает ZIP с тремя файлами. Контакты требуют отдельной галочки, предупреждения и явного подтверждения необходимости. При каждом новом открытии контактный режим выключен. Сервер остаётся источником прав и данных.

Открытие/закрытие — только просмотр, без отправки формы мероприятия, оплаты или счёта. Предпросмотр не создаёт экспорт. Только явное «Скачать результаты» отправляет POST с CSRF. После формирования виден результат; ошибка/истёкшая сессия не скачивается как ложный файл. При закрытии незавершённый запрос отменяется. Чужие введённые значения не читаются/не меняются; фокус возвращается на кнопку. Нативный dialog, Escape, 44px, компактное окно на ширинах 390/320 без горизонтальной прокрутки. RU/ES/EN. Проверка на изолированной PostgreSQL через настоящие страницы и загрузку файлов.

Отдельный PR, выпуск после сервера и только по поручению владельца.
