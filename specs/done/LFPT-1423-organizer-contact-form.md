# LFPT-1423 — форма контакта организатора

Источник: #1423. Зависимость: сервер #1422. Статус: implementation.

Общая HTML-форма всех форматов разделяет имя, страну и WhatsApp. AR — первая страна. type=tel/inputmode=tel, национальный пример из серверных метаданных; полный международный номер и поддерживаемая ссылка проходят один серверный предпросмотр с CSRF. Итоговый номер, проверочная ссылка и оговорка о проверке только формата. При изменении старый URL немедленно убирается; ответы старых запросов не подменяют новые. Отказ сервера остаётся около поля и сохраняет остальные значения.

Редактирование и копирование получают те же поля. Неоднозначный legacy-контакт показан служебному пользователю исходным с просьбой исправить. Публичная страница не показывает активный неверный URL. Админская и публичная кнопки используют единое серверное представление без общего номера платформы.

ES/RU/EN; реальные браузерные проверки на 320/390/1440, создание/редактирование/копия всех форматов, чужие события, локальный стенд без сообщений и production-записей. Физические iPhone/Android отдельно от эмуляции. Окно правил допуска и ограничения микстов не входят в эту задачу.
