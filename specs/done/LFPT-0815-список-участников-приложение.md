# LFPT-0815: Список участников в 1Padel.App

Статус: реализовано. Зависит от серверного контракта в #814.

## Цель

Игрок видит опубликованный состав мероприятия в его деталях в 1Padel.App на `/app/`, не переходя на сайт для обычного просмотра.

## Правила

- Источник — необязательное поле `participants` публичного ответа деталей `GET /api/public/tournaments/{id}`. Ответ расписания не содержит состав.
- `confirmed` показывается как основной состав; `waitlist` — как резерв, только если сервер его публикует. Порядок сервера сохраняется. Имена партнёров показываются в одной строке состава; одиночная заявка с поиском партнёра отмечается отдельно.
- Пустые массивы означают отсутствие опубликованных участников. Отсутствующее или некорректное поле означает недоступность списка и сопровождается ссылкой на страницу мероприятия.
- После закрытия формы записи список и детали перечитываются. Просмотр не создаёт и не меняет регистрации.
- Интерфейс доступен на русском, испанском и английском. Клиент использует только публичные имена и не показывает контакты.

## Проверка

- Проверить разбор полного, пустого, отсутствующего и некорректного списка; порядок пар и резерва.
- Проверить `pnpm test`, `pnpm typecheck` и `pnpm build:site`; выпустить пересобранный `/app/` после API.
- Проверить в браузере актуальный `/app/` и ответ публичного API без создания реальных заявок.
