# LFPT-1068: Регистрация пары с выбранным профилем

При записи пары или добавлении партнёра заявка с `existingUserId` использует актуальный активный профиль. Поля ручного ввода проверяются для заявки без ID. Отсутствующий выбранный профиль отклоняется с кодом `PARTNER_NOT_FOUND`.

Проверки уровня заявителя и партнёра используют действующую политику турниров. Код `PARTNER_LEVEL_REQUIRED` подсказывает, что заполнить профиль должен партнёр. Повторная запись возвращает отдельный код для заявителя или партнёра. Техническая ошибка содержит безопасный текст и идентификатор запроса при его наличии.

Интерфейс описан в задаче #1069.
