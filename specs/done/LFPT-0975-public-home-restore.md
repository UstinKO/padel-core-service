# LFPT-0975: Fix публичная главная — вернуть прежний интерфейс и сохранить закрытый UI v2

## Статус
done

## Источник
[GitHub #975](https://github.com/UstinKO/padel-core-service/issues/975). Регрессия после #969 / PR #970.

## Контекст и связь с MASTER
Публичный Thymeleaf index был заменён макетом 0.7 без отдельного разрешения переключить боевую страницу. Это нарушает ADR-0013: до акцепта новый UI доступен в закрытом preview, а публичный адрес сохраняет прежний интерфейс. MASTER и бизнес-правила не меняются.

## Изменения
- Восстановить `templates/index.html` и `static/js/home.js` из состояния до PR #970 (`45f0d3d^`), удалить неиспользуемый `static/css/home.css`.
- Сохранить текущие API, переводы, регистрацию, оплату, аналитику, Expo и React preview. Проверка роли SUPER_ADMIN для `/preview/**` и пустой `app.spa.routes` сохраняются.
- Усилить регрессию: проверять фактически отрендеренный прежний шаблон публичной главной для гостя/PLAYER, а не только HTTP 200 или отсутствие SPA forward.
- Документация: отметить возврат в исторической спеке #969, уточнить ограничение публичных изменений в ADR-0013.

## Критерии приёмки
- [ ] Гость/PLAYER получают прежнюю главную, без маркеров публичного макета 0.7 и подключения home.css.
- [ ] Реальные опубликованные карточки, фильтры, сброс и ссылки работают на ES/RU/EN и desktop/mobile.
- [ ] `/preview/**` закрыт для гостя/PLAYER и доступен SUPER_ADMIN; корень не становится SPA.
- [ ] Полный verify, браузерная проверка, docs-drift и CI проходят.
- [ ] Один итоговый коммит и PR с Closes #975.

## Границы и открытые вопросы
Миграций и новых бизнес-правил нет. Закрытый React UI сохраняется. Публикация новой версии публичного дизайна возможна только отдельным решением пользователя после приёмки. Merge/deploy production не выполняется самостоятельно; данное исправление заканчивается проверенным PR. Бизнес-вопросов для этого возврата нет.

## Проверка реализации

- index.html и home.js побайтно совпадают с версией до #970; home.css удалён, новые React-экраны и их серверные ограничения не менялись.
- Полный ./mvnw verify: 924 теста, 0 ошибок, 1 пропуск; отдельная тестовая PostgreSQL. Регрессия проверяет фактически отрендеренную главную для гостя/PLAYER.
- Chromium и WebKit: ES/RU/EN, 1440/390 px, гость и PLAYER; прежняя структура, реальные карточки, фильтр формата, пустой результат, сброс и ссылки. SUPER_ADMIN открывает /preview/torneos; гость перенаправляется на вход, PLAYER — на штатную страницу отказа. На публичном корне старое оформление сохраняется и для SUPER_ADMIN.
- Собственный Java-процесс остановлен; синтетические мероприятия, клуб, игрок и администратор удалены. Production не использовался для тестов.
- 48 тестов relay, docs-drift, check-agent-migration, проверка синтаксиса JS и diff-check прошли.
