# LFPT-1355: Чеки на странице оплат

## Статус
done
approved

## Зависимость

Backend #1354, PR #1356. Используются только его защищённые API; production-маршруты SPA не переключаются.

## Сценарий

В действующем экране `/admin/tournaments/{id}/payments` появляется секция чеков и ссылки у участников.
Организатор видит автора, дату, статус и причину отклонения; фильтрует ожидающие проверки.
Фото открывается по запросу, PDF/исходник скачивается защищённым вложением.
Для принятия требуется явно указать сумму, валюту и способ оплаты; для отклонения — причину.
Загруженный файл сам по себе не считается оплатой. Старый цикл доступен как история без подтверждения новой записи.

Проверка оплаты изменяет существующую форму платежей на сервере. Поэтому при несохранённых изменениях формы принятие чека блокируется до их сохранения. После отправки решения о платеже старая форма блокируется до перезагрузки; это действует и при неопределённом сетевом результате. Успешное принятие перезагружает страницу с актуальными платежами. Отклонение сохраняет остальные несохранённые поля.

Тексты ES/RU/EN, оформление и кнопки существующей админки, адаптация под телефон, клавиатурный доступ, состояния загрузки/ошибки/пустого списка. Имена и причины выводятся через textContent.
Секция доступна только при включённом приёме чеков; флаг сам не включается фронтендом.
