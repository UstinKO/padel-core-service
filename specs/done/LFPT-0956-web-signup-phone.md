# LFPT-0956: Feature создание аккаунта на сайте — обязательный телефон

Статус: approved. Источник: #956 и согласованный макет.

Форма POST /players/registro проверяет наличие телефона после нормализации. Telegram необязателен. Если телефон отсутствует, аккаунт не создаётся. Веб-форма получает ошибку поля на ES/RU/EN и сохраняет непарольные данные. Пароли и значение CAPTCHA заново не выводятся.

Вход с Google, ранее созданные профили, API регистрации и проверка контакта перед записью на турнир используют действующие правила. Следующий шаг — интерфейс #957.
