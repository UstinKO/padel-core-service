# Подготовка сообщений Telegram: получатели и предпросмотр

Согласовано владельцем 25.11.2026. Сервер #1389, интерфейс #1390. Выпуск не разрешён.

Единая подписка после явного подключения: информация о записях, напоминания и приглашения. До подключения это объясняется. Отдельных переключателей приглашений нет; /stop прекращает сообщения до явного повторного подключения. Текущие подтверждения, правила отмены, платежи, чеки и ограничения пилота сохраняются.

Первый этап только читает аудиторию и возвращает предпросмотр обычного текста. Не отправляет сообщения, не создаёт запрос участия, не сохраняет черновики и не меняет записи. Общая аудитория и дополнительные адресаты вне мероприятия доступны только SUPER_ADMIN. Остальные управляющие используют действующие права своего мероприятия и только его активных участников. Прямая подстановка постороннего ID отклоняется.

Группы объединяются с точными категориями и явными ID; исключения применяются последними. Без выбранных групп/категорий/ID результат пуст. Группы: все активные участники, основа, резерв, без партнёра в парном формате, актуальный ожидающий ответ. Категория C8 не включает C7/C9 либо смешанные значения. Отменённые записи исключаются. Реальный партнёр, присутствующий только как связь основной регистрации, включается; гостевые профили не заменяются делегатом. Поиск имени и фамилии выполняется в уже разрешённом каталоге.

Предпросмотр повторно читает связи, предпочтения и пилот. Доступность не означает доставку: транспорт и отправка в этом этапе отсутствуют. Кандидаты содержат только ID игрока, имя, категорию, группы и причину доступности. Telegram ID, контакты и токены клиенту не передаются. Таблица связей гарантирует один Telegram на один профиль; каталог объединяет повторные регистрации по ID игрока.

Текст непустой, до 4096 UTF-16 единиц, отображается как текст без HTML. Интерфейс обесценивает старый предпросмотр после правки и игнорирует устаревший ответ. Шаблоны, проба себе, история кампаний, очередь, безопасные повторы, общая ссылка подключения и меню организатора — следующие этапы. #1213 остаётся владельцем общей координации Swarm.

Проверки: серверные права/CSRF/валидация, точные категории, объединение/исключения, актуальность цикла, отключение/WhatsApp/гости/пилот, отсутствие внешнего API; браузер RU/ES/EN 320/390/desktop и безопасный вывод текста. Только отдельная QA-БД с синтетическими данными.
