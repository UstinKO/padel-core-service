# LFPT-1075. Повторная запись из админки

Повторная запись сохраняет ID отменённой регистрации, историю отмен, оплаты и атрибуцию. Новая пара получает общий новый ID бронирования и две взаимные связи. Старые одноразовые ссылки и запросы участия теряют действие. Исторические оплаты сохраняют прежний ID бронирования.

Все маршруты ручной записи пары используют одну операцию с блокировкой турнира. Гостевые профили и обе строки пары сохраняются в одной транзакции. По совпадающему телефону используется активный профиль, а неоднозначный результат требует явного выбора. При повторной отправке той же заявки существующая пара возвращается без повторной записи. Отдельная повторная индивидуальная запись также сохраняет регистрационный ID. Права доступа остаются прежними.

Проверка на PostgreSQL охватывает восстановление с другим и тем же партнёром, гостя, маркетинговую связь, старые платежи, откат, повторную отправку и индивидуальную запись.
