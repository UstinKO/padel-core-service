# LFPT-1005: Fix production-деплой — находить загруженный образ по тегу выпуска

## Статус
done

## Источник
[GitHub #1005](https://github.com/UstinKO/padel-core-service/issues/1005). Выпуск #997 заблокирован на этапе подготовки образа.

## Решение
Docker на сервере видит загруженный образ по уникальному тегу выпуска, но не по ID, который вернул Docker на runner. Передаём тег в манифесте и проверяем, что он соответствует ревизии и префиксу SHA JAR. После загрузки существующая проверка сверяет байты JAR и метки образа. Снимок выпуска фиксирует локальный ID на production.

## Проверка
- Манифест архива сохраняет тот же уникальный тег, который передан в docker image save.
- Неподходящий тег отклоняется до извлечения JAR.
- Проверки текущего конвейера и production-выпуск #997 проходят перед выпуском интерфейса.
