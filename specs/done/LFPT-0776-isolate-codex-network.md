# LFPT-0776: Изоляция сети Codex-воркера

Источник: issue #776. Статус: согласовано.

## Требования

- Воркер использует отдельную сеть Docker; тестовая PostgreSQL доступна только в этой сети, её порт не публикуется на хосте.
- Статус выключателя конвейера доступен через Unix-сокет с проверкой UID. Секрет внутреннего API остаётся на хосте. Ошибка проверки приостанавливает запуск задач.
- Монитор обнаруживает остановку службы сокета. Запускаемые воркером тесты не публикуют приложение наружу и не отправляют данные в production Loki.
- Состояние очереди и тестовой базы сохраняется при переключении; старый relay не запускается.

## Проверка

Юнит-тесты relay, монитора и сокета, включая отказ сокета и проверку UID в Linux; проверка в работающей песочнице доступа к тестовой БД и отсутствия доступа к внутренним сервисам production; проверка настроек Docker, сокета, мониторинга и состояния очереди после переключения. Сквозной запуск задачи зависит от доступности и лимитов Codex.
