# Компактный блок «Участие и Telegram» на странице оплат

Источник: [#1434](https://github.com/UstinKO/padel-core-service/issues/1434). Самостоятельная доработка существующего Thymeleaf-интерфейса; серверные контракты, права и уведомления сохраняются.

## Поведение

При первом открытии блок свёрнут. В заголовке остаются название, стрелка, «Развернуть» и четыре действующих счётчика: основной состав, подтвердившие, без ответа и без Telegram. Заголовок целиком раскрывает блок с пояснением, прежними действиями и списком; подпись меняется на «Свернуть». Доступно управление клавиатурой.

Состояние хранится в localStorage этого браузера отдельно для ID текущего административного аккаунта и турнира. Отсутствующее, некорректное или недоступное хранилище означает первоначально свёрнутый блок. Недоступное хранилище не мешает переключению до ухода со страницы. В хранилище записывается только состояние раскрытия, без контактов, токенов, статусов участников или данных оплат.

Обновление счётчиков и списка не меняет состояние. Во время Telegram-запроса действия блокируются прежним механизмом, но сворачивание доступно. Загрузка, успешный результат и ошибка показываются в существующей live-области за пределами скрываемого содержимого, не раскрывая блок автоматически.

Переключение не отправляет запросов и не затрагивает DOM формы оплат. Суммы, валюта, оплата, посещаемость и другие несохранённые поля сохраняются. Действия Telegram выполняются только прежними отдельными кнопками; запрос сводки остаётся только у SUPER_ADMIN.

## Отображение и границы

Используются действующие цвета, шрифт и компонент страницы. На 320/390 px заголовок и счётчики переносятся без горизонтальной прокрутки блока, зона раскрытия не меньше 44 px. Подписи доступны на RU/ES/EN. Native details/summary обеспечивает сворачивание и без JavaScript; сохранение выбора и Telegram API требуют JavaScript.

Применяется ко всем аккаунтам с существующим доступом к странице; дополнительных прав, координаторов и серверных API не вводится. Рабочие оплаты и участники для проверки не изменяются.

## Приёмка

- Первый показ, сохранение обоих состояний после reload и возврата; изоляция аккаунтов и турниров.
- Видимая сводка при закрытом списке, все прежние действия при открытом.
- Несохранённый черновик формы, отсутствие отправки оплаты и сообщений при переключении.
- Обновление, успех/ошибка и сворачивание во время запроса без автоматического раскрытия.
- Клавиатура, RU/ES/EN, 1440/390/320 px, SUPER_ADMIN/ADMIN/ORGANIZER/CLUB_ADMIN и прежний отказ к чужому мероприятию.
