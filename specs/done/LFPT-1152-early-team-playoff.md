# LFPT-1152 / LFPT-1153 — Ранний плей-офф парного Americano

В квалификации полный сет заканчивается 6:0–6:5. Для сетки 1/8 проверяются все допустимые счета ещё назначенных квалификационных встреч. Критерии таблицы — победы в сетах, разница геймов, выигранные геймы. При полном равенстве порядок фиксируется по ID команды.

Раннее назначение доступно, если соперники останутся в одной паре при любом исходе и оба сыграли по два матча. Если состав оставшихся матчей ещё не определён или расчёт не может подтвердить результат в заданных пределах, координатор видит причину ожидания.

Назначение на корт или постановка в очередь фиксирует состав. Эти матчи входят в единую сетку, используют общую доску кортов и историю проведения. После квалификации оставшиеся пары дополняют ту же стадию, а в сетку 9–15 команд добавляются прямые четвертьфиналисты и переходы победителей.

Интерфейс координатора обновляет предложения после сохранения результата, показывает причину ожидания и показывает предполагаемый прямой проход по текущей таблице. Координатор может закрепить свою пару с явным подтверждением, если оба участника завершили квалификацию и ни один из них не может пройти напрямую в четвертьфинал. После квалификации сетка достраивается с учётом уже закреплённых пар. Публичная очередь показывает подтверждённые встречи с указанием стадии.

При ручном выборе ранней пары показывается предупреждение, если команды уже встречались. Выбирается другая пара. Координатор может изменить пары четвертьфиналов из очереди до назначения корта через обычный диалог обмена командами.

Когда известны два победителя четвертьфиналов, координатор может подтвердить ранний полуфинал, если эта пара ещё не встречалась. После завершения четвертьфиналов два оставшихся победителя занимают свободный полуфинал. Завершённые этапы в админке сворачиваются, результаты можно раскрыть повторно.
