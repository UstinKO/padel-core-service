# LFPT-1093. Возврат прежнего кабинета игрока

После согласования с владельцем маршрут `/players/dashboard` вновь обслуживает существующий шаблон кабинета. Для этого отключаем React-маршрут в production allowlist. Ссылка из письма сохраняет доступ к панели участия. React-кабинет остаётся доступным в закрытом контуре. База данных и API кабинета сохраняются.

Перед следующим дизайном кабинета сравнить состав карточек и согласовать перенос истории отмен, личного статуса оплаты, позиции в резерве и управления видимостью контактов после записи.
