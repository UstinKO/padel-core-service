# LFPT-0995: Feature события Clarity — измерять этапы записи на турнир и возвраты

Задача [#995](https://github.com/UstinKO/padel-core-service/issues/995).

На публичном веб-маршруте записи Clarity фиксирует фактические этапы:

| Событие | Когда отправляется |
|---|---|
| `registration_intent` | Нажатие кнопки записи на карточке или в списке турниров |
| `registration_form_opened` | Показ формы пары |
| `registration_contact_form_opened` | Показ формы обязательных контактов |
| `registration_submit_attempt` | Запуск одиночной записи или попытка отправки парной формы, включая невалидные поля |
| `registration_error` | Ошибка полей, требование указать уровень, изменение условий, отклонение сервером, сбой запроса или ошибка формы контактов |
| `registration_confirmed` | Сервер подтвердил место |
| `registration_waitlisted`, `registration_partner_pending`, `registration_solo_requested` | Сервер принял заявку в резерв, приглашение партнёру или заявку без пары соответственно |
| `registration_confirmed_after_return` | Сервер подтвердил место по тому же турниру в новом сеансе Clarity в том же браузере в пределах семи дней после первого отслеженного шага |

В Clarity фильтры используют события и теги `registration_<этап>_tournament`, а для ошибок — `registration_error_code`. Для хронологии дополнительно отправляется событие `registration_error_<код>`. Код выбирается из фиксированного списка. Тексты ответов, контакты и идентификаторы аккаунтов в события не передаются.

В браузере хранятся только ID турнира, ID первого сеанса Clarity и срок его действия, максимум 30 турниров. Для сравнения используется SDK Clarity. Если SDK не предоставил сеанс или браузер не сохранил историю, подтверждение отмечается без признака возврата. Запись удаляется после подтверждения, при отзыве согласия или при следующей обработке после истечения срока. Работа возможна только при согласии на аналитику.

Покрытие ограничено страницами с уже подключённым Clarity. Вход, кабинет игрока и приложение сохраняют действующее покрытие. Семантика событий GA4, регистрация и распределение мест сохраняются.
