# Запрос на доработку

## Что нужно сделать
Добавить в административную часть сайта компактный переключатель языка.

Расположение: в верхней части страницы справа, рядом с профилем администратора / кнопкой выхода.

Варианты:
- ES — Español
- EN — English
- RU — Русский

Требования:
1. Переключатель должен быть компактным и не перегружать шапку.
2. При выборе языка интерфейс админской панели должен сразу переключаться на выбранный язык.
3. Ручной выбор пользователя должен иметь приоритет над автоматическим определением языка браузера.
4. Выбранный язык желательно сохранять: для следующего перехода по страницам; после обновления страницы; при следующем входе в админку.
5. На первом этапе достаточно реализовать переключение только для административной панели.
6. Названия клубов, имена игроков, адреса и другие собственные данные не переводить.

## Где это происходит
Административная панель (`/admin/**`) — шапка страницы.

## Зачем это нужно
Администратор, координатор или клуб должны иметь возможность быстро переключить язык интерфейса без изменения языка браузера.

## Кто это увидит/использует
- [ ] Игроки
- [x] Организаторы/владельцы клубов
- [x] Только я (суперадмин) — и координаторы/клубные аккаунты (`ROLE_CLUB_ADMIN`), у всех есть доступ к админ-панели

## Насколько срочно
- [ ] Горит — блокирует текущую работу
- [x] Важно, но не горит — в ближайших неделях

## Примеры / референсы
Нет, обычный паттерн переключателя локали (ES/EN/RU) в шапке.

## Есть ли ограничения
- Собственные данные (названия клубов, имена игроков, адреса) не переводятся — это сознательно не затрагивается.
- Публичный сайт и личный кабинет игрока — не в этом запросе, только админ-панель.
