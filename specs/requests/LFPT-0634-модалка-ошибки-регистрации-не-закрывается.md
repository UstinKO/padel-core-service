# Запрос на доработку

## Что нужно сделать
После внедрения проверки уровня (LFPT-0303) обнаружен дефект на странице турнира: игрок с уровнем C6 пытается зарегистрироваться на турнир категории C8, получает правильное сообщение об ограничении, но кнопка «OK»/«Aceptar» не закрывает это окно.

Причина указана заказчиком: в `src/main/resources/static/js/tournament-details.js` обработчик всех кнопок с `data-dismiss="modal"` вызывает `closeModal()`, а эта функция закрывает только окно выбора партнёра (`#partnerModal`). Кроме того, окно ошибки дополнительно получает `style.display = 'block'`, что мешает закрытию через CSS-класс.

Предложенное решение (от заказчика):
- Заменить обработчик кнопок закрытия так, чтобы он закрывал то модальное окно, внутри которого находится нажатая кнопка (через `btn.closest('.modal')`), а не всегда `#partnerModal`.
- В ветке обработки ошибки регистрации убрать строку `resultModal.style.display = 'block'` — класса `.show` достаточно для отображения окна.

## Где это происходит
Страница турнира (`/torneo/{id}`), окно с сообщением об ошибке регистрации (ограничение по уровню и, возможно, другие ошибки регистрации, использующие то же окно).

## Зачем это нужно
Игрок не может закрыть окно с сообщением об ошибке и продолжить работу со страницей иначе как перезагрузкой страницы — это баг, ухудшающий пользовательский опыт сразу после внедрения проверки уровня.

## Примеры / референсы
Заказчик приложил готовый фрагмент кода с решением (см. выше) и шаги проверки:
- сообщение для C6 → C8 появляется;
- OK закрывает окно и затемнение;
- повторная попытка снова показывает сообщение;
- закрытие формы выбора партнёра продолжает работать.

## Есть ли ограничения
Не ломать существующее поведение `#partnerModal` (закрытие с очисткой формы/выбранного партнёра) и `#cancelModal` (у него уже есть отдельный, рабочий обходной путь через клонирование кнопок — не трогать эту логику).
