# Запрос на доработку

> Этот файл заполняет заказчик/владелец продукта. Без технических терминов — просто опишите, что нужно и зачем. Технической проработкой (превращением этого в полную фиче-спеку) занимается agent-аналитик.

## Что нужно сделать
Сейчас проводится турнир, и не у всех команд отражаются оба игрока пары. Желательно стандартизировать, чтобы всегда были видны оба игрока команды.

## Где это происходит
Публичная страница турнира на 1-padel.com — вид по кортам и вид квалификационных матчей раунда (похоже на Team Playoff/Team Americano).

## Зачем это нужно
На скриншотах с турнира: в списке матчей по кортам для одних команд отображаются оба игрока пары (например «№3 Tomás Jarowisky / Agustín Zeballos»), а для других — только один игрок, партнёр вообще не показан (например «№8 Leandro Randazzo» без партнёра рядом, «№5 Leonardo Rodríguez» без партнёра рядом, «№2 Elizaveta Voroshilova / Павел Ворошилов» — тоже только один явно подписан партнёром). Игрокам и зрителям должно быть одинаково понятно, кто с кем играет в паре, независимо от команды.

## Кто это увидит/использует
- [x] Игроки
- [x] Организаторы/владельцы клубов

## Насколько срочно
- [x] Горит — блокирует текущую работу (турнир идёт прямо сейчас)

## Примеры / референсы
Скриншоты организатора с публичной страницы турнира во время реального турнира (переданы через Telegram-канал поддержки, не приложены к этому файлу напрямую).

## Есть ли ограничения
Не отменять и не переделывать саму механику "гостевого" (незарегистрированного на сайте) второго игрока пары — только исправить отображение уже существующих команд/матчей так, чтобы оба игрока были видны единообразно.
