## Что нужно сделать
Автоматически устанавливать статус нового турнира «Регистрация открыта» при создании турнира клубной учётной записью.

При создании турнира сейчас администратор/клуб должен самостоятельно выбирать статус из списка:
— Черновик;
— Опубликован;
— Регистрация открыта;
— Закрыт;
— Завершён;
— Отменён.

Для клубной учётной записи это создаёт лишнюю путаницу между статусами «Опубликован» и «Регистрация открыта».

Нужно: при создании нового турнира клубной учётной записью автоматически устанавливать статус «Регистрация открыта». Организатор не должен отдельно выбирать этот статус каждый раз. После создания турнир должен быть в состоянии, в котором пользователи могут зарегистрироваться. В дальнейшем статус можно менять обычной логикой управления турниром. Поле «Дополнительная информация / Описание» оставить без изменений — клуб самостоятельно заполняет дополнительные условия турнира.

## Где это происходит
Форма создания турнира в админ-панели (`/admin/tournaments/new`), доступная клубной учётной записи.

## Зачем это нужно
Максимально упростить создание стандартного турнира клубом — убрать лишний выбор, который и так всегда должен быть одним и тем же значением.
