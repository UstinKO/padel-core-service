# Запрос на доработку

## Что нужно сделать
При создании или редактировании мероприятия добавить настройку доступа:

**Публичное / Только по ссылке**

Если выбрано «Только по ссылке»:
- мероприятие не показывается в общем расписании и списке доступных турниров;
- не должно находиться через обычную навигацию сайта;
- открыть страницу и зарегистрироваться можно только по прямой уникальной ссылке;
- вся остальная логика турнира работает как обычно.

Ссылку администратор должен иметь возможность скопировать из админки и отправить нужным игрокам.

В дальнейшем можно добавить третий режим — «По приглашению», где доступ разрешён только конкретным пользователям (в этот запрос не входит, только на будущее).

## Где это происходит
Форма создания/редактирования турнира в админке (`/admin/tournaments/new`, `/admin/tournaments/{id}/edit`), страница деталей турнира в админке, все публичные точки, где рендерится список турниров (`/torneos`, главная страница, `/api/tournaments` и связанные эндпоинты).

## Зачем это нужно
Организаторам нужны закрытые мероприятия — доступные только тем, кому дали ссылку напрямую (например, приватные/корпоративные турниры), без публичного анонса на сайте.

## Кто это увидит/использует
- [x] Игроки (те, кому дали ссылку)
- [x] Организаторы/владельцы клубов (создают такие мероприятия и раздают ссылку)
- [ ] Только я (суперадмин)

## Насколько срочно
- [ ] Горит — блокирует текущую работу
- [x] Важно, но не горит — в ближайших неделях

## Примеры / референсы
Нет, обычный паттерн "unlisted"-доступа (как unlisted-видео на YouTube): не в публичных списках, но доступно по прямой ссылке.

## Есть ли ограничения
- Вся остальная бизнес-логика турнира (регистрация, статусы, оплаты, форматы) должна продолжать работать как обычно для турниров «только по ссылке».
- Существующие турниры должны остаться публичными (без скрытой регрессии при миграции).
- Третий режим «По приглашению» — явно не в этом запросе, только задел на будущее.
