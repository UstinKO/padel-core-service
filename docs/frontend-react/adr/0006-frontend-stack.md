# ADR-0006. Стек фронтенда

- **Статус:** Предложено
- **Дата:** 2026-09-28
- **Связано:** [0001](0001-react-spa.md), [0009](0009-i18n-split.md), [0010](0010-realtime.md), [0012](0012-design-tokens.md)

## Контекст

Один разработчик + агенты Claude Code (Analyst → Developer → Tester → Architect), в том числе в облачной роутине. Пользователи — в основном с телефонов (игроки в Аргентине, организаторы на корте). Самые сложные экраны — live-пульты с частыми мутациями и realtime-обновлениями. Выбирать нужно «скучные», массовые библиотеки, которые агенты знают хорошо и которые не придётся менять через год.

## Решение

| Задача | Выбор | Почему |
|---|---|---|
| Сборка | **Vite** | Стандарт для SPA, быстрый dev-сервер с прокси на `:8080` |
| Язык | **TypeScript** (`strict`) | Типы из OpenAPI (ADR-0004) бессмысленны без TS |
| UI | **React 19** | ADR-0001 |
| Роутинг | **React Router** (data-router) | Самый распространённый; ленивые роуты = разбиение бандла по разделам (публичное / игрок / админка) |
| Серверное состояние | **TanStack Query** | Кэш, повторы, инвалидация по событию WebSocket (ADR-0010), оптимистичные обновления для ввода счёта |
| Клиентское состояние | React state + context; **без Redux** | Почти всё состояние — серверное; глобального клиентского почти нет (сессия, язык, тосты) |
| Формы | **React Hook Form + Zod** | Валидация на клиенте, схемы переиспользуются для типов |
| HTTP | тонкая обёртка над `fetch` поверх сгенерированных типов | CSRF-заголовок, `Accept-Language`, единая обработка `401/403/429/ProblemDetail` |
| Локализация | **react-i18next** | ADR-0009 |
| Realtime | **@stomp/stompjs** (+ `sockjs-client` как фоллбэк) | ADR-0010; сервер остаётся SockJS+STOMP |
| Стили | **CSS Modules + CSS-переменные** (дизайн-токены) | ADR-0012. Без Tailwind и без готовой UI-библиотеки (MUI/Ant) — чтобы редизайн по `.agents/DESIGN.md` был заменой токенов, а не борьбой с чужой темой |
| Примитивы доступности | **Radix UI** (только headless: Dialog, Popover, DropdownMenu, Tabs) | Модалки/меню с правильным фокусом и клавиатурой без собственной реализации; стили — свои |
| Иконки | одна система из npm (выбор — по `.agents/DESIGN.md`) | Сейчас три системы, FA 6.0.0-**beta3** с CDN |
| Шрифты | self-host (`@fontsource`) | Убрать Google Fonts из CSP и внешних запросов |
| Экспорт сетки в PNG | `@zumer/snapdom` из npm | То же, что сейчас, но без CDN |
| Юнит/компонентные тесты | **Vitest + Testing Library** | Нативно с Vite |
| E2E | **Playwright** | Уже используется Tester-агентом в облаке |
| Линт/формат | ESLint + Prettier | — |

**Бюджет размера** (важно для мобильного интернета): публичный раздел ≤ 150 КБ JS gzip на первую загрузку, админка грузится отдельными чанками. Проверка — в CI (`size-limit` или аналог), превышение = красный PR.

**Поддержка браузеров:** последние 2 версии evergreen + Safari iOS 15+ (типичный парк телефонов). Проверить по логам/аналитике Cloudflare в Фазе 0.

## Отвергнутые альтернативы

| Вариант | Почему нет |
|---|---|
| Create React App | Не поддерживается |
| Next.js | ADR-0001: нужен Node-сервер; SSR нужен точечно (ADR-0008) |
| Redux Toolkit | Избыточен при серверном состоянии через TanStack Query |
| Tailwind | Хорош, но решение о визуальном языке ещё не принято (`.agents/DESIGN.md` ждёт логотип); CSS-переменные переживут любой выбор, а Tailwind можно добавить поверх тех же токенов позже |
| MUI / Ant Design / Chakra | Навязывают свой визуальный язык; редизайн превратится в переопределение чужой темы |

## Последствия

- Все версии фиксируются в `package-lock.json`; обновления — отдельными PR (Dependabot/Renovate — решить в Фазе 0).
- Агентам конвейера нужны правила по фронту в `.agents/CODE_REVIEW.md` (структура папок, где живёт API-клиент, запрет `any`, запрет прямого `fetch` мимо клиента).
