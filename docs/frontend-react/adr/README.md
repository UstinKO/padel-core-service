# ADR: переход веб-интерфейса на React

Architecture Decision Records — по одному файлу на решение: контекст → решение → отвергнутые альтернативы → последствия. Решение, однажды принятое, не переписывается: если передумали — новый ADR со статусом «Заменяет ADR-00xx», старому ставится «Заменён ADR-00yy».

**Статусы:** `Предложено` — ждёт согласования · `Принято` · `Отклонено` · `Заменено`.
