# 1-Padel — пользовательский интерфейс 0.7

React + TypeScript, утверждённый дизайн Play Concept: светлый фон, глубокий зелёный, лаймовые акценты, читаемые карточки и навигация для телефона. Это интерактивная пользовательская часть с демонстрационными данными, состояниями страниц и модальными окнами.

**Это макет для согласования и интеграции.** Он не создаёт реальные аккаунты, записи, платежи или письма. Google-вход показывает демонстрационный переход, а не настоящую авторизацию Google. Подключение к API и инфраструктуре выполняется в действующем проекте; макеты готовятся независимо от этого подключения. Административные экраны остаются отдельным этапом.

Объём и договорённости из предыдущего этапа сохранены в [docs/DELIVERY-SCOPE.md](docs/DELIVERY-SCOPE.md). Текущее покрытие и ограничения перечислены ниже; наличие экрана не означает готовность production-функции.

## Быстро посмотреть

Начните с `/#/review`: здесь собраны именованные примеры, поиск по ним и кнопка копирования ссылки. Прямые ссылки `/#/preview/<id>` сами устанавливают нужную демосессию и состояние. Настоящая регистрация для просмотра не требуется.

## Запуск

Для разработки и тестов используйте Node.js 24+ и pnpm 11.25.0, как в `packageManager`. Тесты читают TypeScript напрямую.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

`pnpm-workspace.yaml` разрешает build-script esbuild. `dist/` — собранная статическая версия. Открывайте её через HTTP-сервер; запуск `index.html` двойным щелчком не поддерживается. Маршрутизация hash-based, поэтому серверу не нужны правила перенаправления для каждого внутреннего экрана.

## Реализовано в макете

- Главная гостя и игрока, каталог с комбинируемыми фильтрами; пустой результат, загрузка и ошибка с повтором.
- Отдельные карточки King of Court, индивидуального Американо, постоянных пар, тренировки и Cancha abierta. Правила, участники, резерв, организатор, FAQ, поделиться и состояния турнира.
- Вход/регистрация с заметной кнопкой Google; имя, фамилия, email и телефон обязательны, Telegram необязателен. Дополнение контактов после входа, продолжение записи без подтверждения почты, восстановление и новый пароль, ошибка OAuth.
- Индивидуальная запись и резерв, согласие с условиями, подтверждения; примеры конфликта последнего места, ошибки отправки и неизвестного результата запроса.
- Постоянные пары: поиск зарегистрированного партнёра либо его данные, «добавлю позже», «ищу партнёра»; предложения и их принятие/отказ, срок приглашения, несовместимая категория и приватность контактов.
- Мои мероприятия, история, статусы заявок и оплаты, отмена, подтверждение участия после автоматического перевода в основу, профиль и редактирование.
- Три пользовательских просмотра проведения: корты, сетка, полный рейтинг, история, завершённый турнир, ошибки и ожидание распределения. У индивидуального Американо представлены все 19 раундов, у постоянных пар — квалификация и плей-офф.
- Клубы и страницы клубов, информация о приложении, юридические тексты из текущего проекта, системные экраны. Лига и общий рейтинг имеют явное состояние «В разработке».
- Общая мобильная навигация, меню, баннеры, формы, диалоги и уведомления; прямой просмотр примеров без серверного входа.

## Что подключить и довести перед запуском

- Реальную авторизацию, Google OAuth, почту/токены и серверную сессию; права и защиту операций. Демо не проверяет действующий пароль.
- Настоящее расписание, вместимость, очередь резерва, сроки, приглашения, результаты, оплату и состояние запроса после обрыва соединения. Значения в макете не являются новыми API-контрактами.
- Серверные алгоритмы сеток, посева и подсчёта рейтингов. Локальные fixtures служат только демонстрации интерфейса и не заменяют существующую систему.
- Синхронизацию переключателя ES/RU/EN с существующим языковым механизмом сайта и перевод контента API. Подробнее: docs/I18N.md.
- SEO/OG, реальные данные клубов и входящие ссылки старого сайта. Утверждённые владельцем юридические тексты подключаются отдельно; правовой аудит не является задачей этого пакета.
- Серверную готовность лиги/общего рейтинга, интеграцию с существующим Expo-приложением и push. Административная часть в этот пакет не входит.

## Демоданные и закрытый контур

Данные профиля, включая введённые контакты и записи, сохраняются в браузере под ключом `1padel-react-demo-v1`. Пароли не сохраняются. Для проверки используйте вымышленные данные. Смена сценария заменяет текущую демосессию; «Сбросить демоданные» на странице проверки очищает профиль и заявки.

Публичный дизайн-концепт не является закрытым тестовым контуром. Интегрированную версию разворачивают на отдельном адресе с серверным ограничением для одного-двух IP. Старая версия сохраняется до проверки всего функционала и отдельного переключения с возможностью возврата. `/app/` уже занят существующим Expo web-приложением — не заменять его этой сборкой.

ZIP для разработчика содержит исходники, lock-файл, инструкции, ассеты и `dist/`. В него **не включаются** `.openai`, `node_modules`, `.git`, `.env`, ключи/токены, настройки хостинга и данные локальных сессий.

Подробно: [карта экранов](docs/SCREEN-MAP.md), [матрица примеров](docs/STATES.md), [интеграция](docs/INTEGRATION.md), [ассеты](docs/ASSETS.md), [согласованный объём](docs/DELIVERY-SCOPE.md). Актуальные результаты проверки: [docs/QA.md](docs/QA.md).

## Передача изменений

Задачи на действующий сайт владелец передаёт через своего Telegram-бота; далее их выполняет настроенный исполнитель Claude. Архив — материалы интерфейса, не команда автоматически менять production. Сначала закрытый тестовый контур, затем проверка владельцем и отдельное решение о переключении. Юридические вопросы оставлены владельцу и не входят в техническое задание.
