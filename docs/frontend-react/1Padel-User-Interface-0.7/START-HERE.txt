9. Задачи в действующем проекте передаются владельцем через Telegram-бота. Этот ZIP сам по себе не разрешает переключение production.
10. Юридический аудит исключён из технического ZIP. Тексты юридических страниц пока имеют предупреждение о необходимости проверки владельцем.

В архиве нет node_modules, Git, ключей, .env и настройки хостинга Sites. Нет административной части или исходников Expo-приложения.
