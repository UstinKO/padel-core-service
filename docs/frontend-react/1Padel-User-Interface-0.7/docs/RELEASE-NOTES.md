# Комплект 0.6 · 27 октября 2026

- Обновлён единый каталог: прямые примеры, поиск, выгрузка всех ссылок и инструкция просмотра.
- Добавлены прямые ссылки на сетку, историю и зрительский просмотр каждого формата, плей-офф пар, записанного игрока и резерв.
- В комплекте сохранены последние изменения: регистрация без подтверждения почты, обязательный телефон, Google с дополнением контактов, понятные ошибки формы.
- Парный резерв поддерживает все три способа записи; готовая пара получает приоритет. Перевод из резерва занимает место до подтверждения участия.
- Король корта: раздельные очки матча и бонусы, персональная карточка и подсветка корта, история матчей по нажатию на игрока. Парный рейтинг включает расширенные показатели.
- LINKS.txt и STATES.md формируются из одного реестра. Старые варианты кабинета и отдельные прежние концепции не включены.
- Уточнено, что демонстрация не подключена к рабочему серверу, русская локализация не равна готовой испанской, юридические решения принадлежат владельцу.

Пользовательский просмотр проведения включён. Административный ввод результатов, запуск/сохранение раундов и старые отдельные админ-прототипы не входят в этот React-комплект. Не выдавать их за готовые React-страницы.
