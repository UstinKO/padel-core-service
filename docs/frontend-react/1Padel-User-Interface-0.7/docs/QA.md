## Границы проверки

Проверена локальная production-сборка и демонстрационные данные. Не проверялись реальный сервер 1-padel.com, реальные Google OAuth, почтовая доставка, платежи, push, нагрузка, безопасность всей инфраструктуры и юридическое соответствие. Русская версия служит согласованию; испанские тексты ещё нужны. Эмуляция размеров не заменяет проверку на реальных iPhone/Android, с клавиатурой, VoiceOver и TalkBack. Краткие переходные состояния загрузки могут успевать завершиться при открытии.

Технический архив проверяется отдельно на целостность, состав, контрольные суммы и отсутствие служебных данных; результат фиксируется в DELIVERY-MANIFEST.json рядом с архивом.
