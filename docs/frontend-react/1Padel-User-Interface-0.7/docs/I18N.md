# Языки интерфейса · 0.7

В шапке ES/RU/EN, в мобильном меню Español / Русский / English. Переведены страницы, формы, состояния, модальные окна и 99 сценариев. Имена игроков, контакты, коды категорий и значения полей не переводятся. Документация и скачиваемый реестр ссылок остаются на русском.

## Автоматическое определение и ручной выбор

На первом посещении используется язык браузера (es-AR → es, ru-RU → ru, en-US → en). Для остальных языков — es. Явно выбранный язык сохраняется в localStorage и имеет приоритет над браузером при следующих посещениях. Прямая ссылка ?lang=es#/home позволяет открыть конкретный язык для проверки; URL-параметр имеет приоритет в такой ссылке. Смена языка сохраняет маршрут, фильтры и несохранённые поля формы. Язык общения в профиле — отдельное предпочтение контакта.

На действующем сайте автоматическое определение уже есть. При интеграции использовать его как единственный источник языка: адаптировать src/i18n/store.ts к текущей cookie/профилю/серверному locale, не запускать два независимых детектора. Не привязывать язык к IP. Ручной выбор должен переопределять автоматический.

## Файлы и ограничения

- src/components/LanguagePicker.tsx — доступный нативный select, без флагов стран.
- src/i18n/store.ts, react.ts — определение, хранение и подписки.
- src/i18n/messages.ts — испанские и английские тексты, исходный русский ключ.
- src/i18n/translate.ts — точные строки и шаблоны с подстановками.
- src/i18n/jsx-runtime.ts — адаптер представления React, переводит текст и доступные подписи, не меняет значения модели. Не переводит DOM после отрисовки и не отправляет данные стороннему переводчику. Настройки JSX в tsconfig и Vite нужно переносить вместе с исходниками. В dev исключено дублирование хранилища языка при предварительной сборке зависимостей.
- src/i18n/legal.ts — существующие ES/EN тексты из исходников текущего сайта; юридическая проверка владельцем остаётся необходимой.

Для нового контента API нужно передавать локализованные описания или устойчивые message ID. Не рассчитывать на перевод произвольного текста этим словарём. Даты событий демо переведены как фиксированные примеры; реальные даты форматировать из ISO через Intl с часовым поясом America/Argentina/Buenos_Aires. Проверить поддержку английского языка общения сервером перед отправкой значения en в профиль.

Проверка: pnpm test, pnpm build; переключение внутри формы и мобильные варианты. Демо не подключает API, Google, оплату, email или push.
