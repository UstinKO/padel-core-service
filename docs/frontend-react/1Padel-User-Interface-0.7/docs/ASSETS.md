# Ассеты Play Concept 0.6

В ZIP отдельно лежит `assets/`. Рабочее приложение использует исходники в `public/`, компоненте Icon и пакете Fontsource; копии для передачи можно переносить в систему ассетов действующего проекта.

| Материал | Файл / папка | Использование / происхождение |
|---|---|---|
| Знак концепции | `assets/logos/mark.svg`, рабочий `public/assets/mark.svg` | Сохранённый знак утверждённого Play Concept; шапка и favicon. Надпись 1-PADEL выводится текстом |
| 19 пиктограмм | `assets/icons/*.svg`, рабочий `src/components/Icon.tsx` | Векторные линии текущего интерфейса. `currentColor`, 24×24, подходят для всех размеров. Это файлы того же набора, что использует приложение |
| Manrope 400/500/600/700/800 | `assets/fonts/*.woff2` | Локальные латинские и кириллические наборы из @fontsource/manrope. В приложении импортируются из зависимости |
| Лицензия шрифта | `assets/fonts/OFL.txt`, `docs/MANROPE-LICENSE.txt` | SIL Open Font License; сохранять при передаче шрифтов |
| Цвета и размеры | `src/styles/styles.css`, `:root` | Тёмно-зелёный, лайм, тёплый светлый фон, границы, размеры и радиусы |
| Данные макета | `src/data/events.ts`, `src/data/scenarios.ts`, `src/domain/pairs.ts`, `src/domain/live.ts` | Вымышленные данные. Не импортировать в production как настоящие записи |
| Юридический текст | `src/data/legal.ts` | Русская ветка действующих шаблонов `padel-pair-integration/src/main/resources/templates/legal/`. Перенесён существующий текст; новая правовая политика не создавалась |

Фотографии и видео в этом дизайне не используются. Карточки клубов оформлены векторными пиктограммами, поэтому зависимость от сторонних фотографий и их лицензий отсутствует. Старые картинки из предыдущих концепций не добавлялись.

`dist/assets/` генерируется сборкой, содержит хешированные файлы и не является местом редактирования. В основной реализации пиктограммы остаются общим React-компонентом; экспорт SVG нужен для передачи и переиспользования.
