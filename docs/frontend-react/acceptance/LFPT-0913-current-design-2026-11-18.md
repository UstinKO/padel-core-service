# Повторная приёмка: текущий дизайн и кабинет с рейтингом

18 ноября 2026. Подготовлена закрытая версия на основе master 3c16455, серверной подготовки #1118 и записи #909. Включение production-маршрутов не выполнялось. Общая задача #913 остаётся открытой до решения владельца о выпуске.

## Что сохранено и что изменено

Кабинет и профиль используют действующие серверные страницы. Рейтинг, график, достижения, история, фильтры, правила доступа пилота и существующие действия сохраняются в исходной реализации. Ссылки из шапки открывают эти страницы. Старый адрес /preview/players/dashboard возвращает на /players/dashboard с сохранением языка.

Дополнительные действия с регистрациями сохраняются на /preview/players/events. Ссылка «Управление заявками» появляется в кабинете только в профиле preview. Панель не заменяет кабинет с рейтингом. В ней доступны резерв, подтверждение и отказ, отмена, история отмен, оплата, поиск замены и видимость контактов.

React-страницы используют оранжевые основные акценты, фиолетовые дополнительные, светлые поверхности и исходный логотип текущего сайта. Inter загружается локально. Мобильная шапка сохраняет название бренда и компактное раскрываемое меню; Escape закрывает меню и возвращает фокус. Бизнес-правила, расчёт рейтинга и production-переключатели не изменялись.

## Версия и свидетельства

Сценарный прогон и репетиция выполнены на коммите приложения 90ae865ad2406f6df5f3a3677d0dbff03f90285f. После этого прогона уточнён контракт входных данных общего smoke и добавлен отчёт. Деревья приложения frontend и src не изменились. Проверенные деревья приложения:

- frontend: b9c2fd9c105ab41dfe217902d657fffb0b89ce04;
- src: 0194603377376953cc656347eddfab282da39e99.

Тестовый PostgreSQL и Mailpit выделены этому контуру. Для рейтинга подготовлен отдельный синтетический срез двух игроков, без копирования игроков или результатов production. Отдельный обычный игрок проверен без доступа к рейтинговому пилоту. Runtime, доступы и ссылки с токенами не публикуются.

## Реальные браузерные сценарии

| Сценарий | Экран и контракт | Результат |
|---|---|---|
| Вход и возврат | /login → карточка /preview/torneo/{id} | Обычный игрок возвращается к записи |
| Индивидуальная запись | POST /players/tournaments/{id}/register | CONFIRMED в свободном мероприятии |
| Резерв при потере ответа | Тот же POST и my-registration | WAITLIST, серверная позиция, одна отправка без повторной мутации |
| Пара с существующим игроком | Поиск и /api/tournaments/double/{id}/register | Пара сформирована, CONFIRMED |
| Новый гостевой партнёр | Ручные поля и тот же API | Пара сформирована, WAITLIST в заполненном мероприятии |
| Партнёр позже | register-solo → add-partner | SOLO_ADD_LATER → готовая пара WAITLIST |
| Предложение пары из письма | Mailpit → accept-pair → decline/accept | Отказ сохраняет одиночные заявки; принятие формирует пару в резерве; повторная ссылка отклоняется |
| Отмена всей пары | Панель заявок, pair-cancellation | Отмена сохранена в истории, следующая пара продвинута |
| Подтверждение после продвижения | Панель и participation API | Ответ сохранён в действующей сессии |
| Контакты | Панель, contact-visibility | Включение и выключение сохраняются после refresh |
| Live-обновления и переподключение | Публичный snapshot, STOMP/WebSocket | Новый результат получен; после восстановления доступного шлюза подписка и версия состояния восстановлены |
| Статус оплаты | Панель и /api/players/me/events | Синтетическая PAID видна своему игроку, другому не приписывается |
| Рейтинг и достижения | Действующий /players/dashboard | Elo, оба места, титулы и вторые места отображаются |
| График и история | Тот же кабинет | Выбор периода, выбор события, раскрытие и сворачивание десяти записей, переключатель движения работают |
| Возврат в кабинет | Панель → ссылка кабинета | Открывается текущая страница, рейтинг сохраняется |
| Игрок вне пилота | /players/dashboard | Обычный кабинет без чужого рейтингового блока |
| Публичные страницы закрытой копии | Главная, каталог, клубы, формы, документы | GET/HEAD согласованы с меню; каталог после refresh отвечает 200 |
| Панель заявок после refresh | /preview/players/events | HTTP 200, сессионные данные сохранены |

Синтетический платёж подготовлен непосредственно в собственной БД; реальная обработка денег и интерфейс кассира не входят в этот сценарий. Для гостевых сценариев использованы новые синтетические контакты. Ранее созданный профиль без уровня корректно отклоняется действующим правилом PARTNER_LEVEL_REQUIRED; ослабление проверки уровня не выполнялось.

## Выпуск и откат

Повторная automation/releases/rehearse.py прошла: два синтетических выпуска, сохранность прежнего lazy chunk, ручной откат, откат после отсутствующего chunk и неготового readiness, восстановление по журналу. По окончании восстановлен полный исходный выпуск закрытой копии вместе с конфигурацией синтетического рейтинга. Production и посторонние контуры не использовались.

Общий smoke теперь получает явный fixtureSet: регистрации с шестью tournamentIds либо отдельный плей-офф. Это устраняет падение CI при вызове общего smoke из пилота без данных регистраций. Сценарии записей сохраняются в check.py; прогон пилота не изменяет их повторно. При проверке live сменился адрес Wi-Fi Mac: старый LAN-порт не восстановился после restart. После перенастройки только локального шлюза на текущий адрес реальные WebSocket update/reconnect и refresh прошли. Код live-соединения не менялся.

## Статус замечаний и границы

- #1189 реализован отдельным серверным PR #1194: ограниченные права профиля preview и корректный статус личной панели. В других профилях preview остаётся административным.
- #1190: из дополнительной панели ссылка события сохраняет маршрут React-карточки. Переходы из текущего кабинета сохраняют действующие адреса.
- #1192 пересматривается по решению владельца: возврат после входа в действующий кабинет является ожидаемым поведением. Он не должен заменяться прежним зелёным экраном.
- Физические Safari/iPhone, Android и озвучивание VoiceOver повторно не проверены. Эмуляция мобильного Chromium не считается проверкой устройства.
- Полная приёмка Expo, внешний Google OAuth и доставка через реального почтового провайдера не повторялись. Проверены изоляция внешних отправок и доставка тестовых ссылок внутри Mailpit.
- PR остаются черновиками без меток автоматического выпуска. Переключение рабочего сайта требует отдельного поручения владельца после просмотра итоговой версии.

Создание нового аккаунта и полный сброс пароля в React-формах в этом повторном живом прогоне отдельно не выполнялись; они покрываются существующим моделируемым браузерным набором. Основные кабинет и профиль сохраняют текущую серверную реализацию.
