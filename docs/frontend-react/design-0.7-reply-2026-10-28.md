## Таблица допуска по уровню (п. 1.1)

**Правило.** Игрок может записаться сам, если его уровень отличается от категории турнира не больше чем на одну ступень. Мужские (C) и женские (D) категории сравниваются по общей шкале: **Dn соответствует C(n+1)**, например D6 ≈ C7, D9 ≈ C10. Поэтому пол категории сам по себе запись не запрещает.

| Уровень игрока | Может записаться на категории |
|---|---|
| C9 | C9, C8 · D9, D8, D7 |
| C8 | C9, C8, C7 · D8, D7, D6 |
| C7 | C8, C7, C6 · D7, D6 |
| C6 | C7, C6, C5 · D6 |
| C5 | C6, C5, C4 |
| C4 | C5, C4 |
| D9 | C9 · D9, D8 |
| D8 | C9, C8 · D9, D8, D7 |
| D7 | C9, C8, C7 · D8, D7, D6 |
| D6 | C8, C7, C6 · D7, D6 |

**Проверка не применяется:**
- к форматам Cancha abierta и «Тренировка + игра» (Padel Clinic);
- к категориям-диапазонам (C9/C8, D7/D6 и т. п.), «Todos», «Principiante», суммам уровней пары (10+…16+), а также D5 и D4;
- к записи, которую делает организатор.

**Если уровень не указан**, перед записью на турнир с проверкой мы просим его указать (п. 1.2).

**Для пары** уровень проверяется у того, кто записывает, и у партнёра, если у партнёра уже есть аккаунт. У партнёра без аккаунта уровень неизвестен, поэтому его не проверяем.

**Текст отказа сейчас:** «Ваш текущий уровень — C6. Регистрация на турнир категории C8 недоступна. Вы можете участвовать в турнирах категорий: C7, C6, C5, D6». В новом экране добавим к нему действия «Выбрать другое мероприятие» и «Связаться с организатором».

## Вопросы

### 1. Регистрация без подтверждения почты (п. 1.3)

Сейчас аккаунт начинает работать после перехода по ссылке из письма. Это защищает от регистрации на чужие и несуществующие адреса. Если убрать подтверждение совсем:
- письма о записи и резерве будут уходить на непроверенные адреса. У сайта есть дневной лимит писем, а недоставленные письма ухудшают доставку всем остальным;
- кто-то сможет зарегистрироваться на чужую почту.

**Предлагаем:** не блокировать вход и запись, как вы и хотите, но оставить ссылку подтверждения в приветственном письме и отметку «почта не подтверждена» в профиле. Подходит?

### 2. Как подтверждать, что телефон принадлежит человеку (п. 1.7)

Когда партнёр, записанный без аккаунта, позже регистрируется сам, мы должны связать его аккаунт с уже существующей записью. Для «проверки принадлежности контакта» нужен канал подтверждения. Сейчас на сайте нет кодов по SMS, а WhatsApp вы на этом этапе не подключаете. Варианты:
- **а)** код по SMS — новый платный сервис;
- **б)** связывает организатор вручную в админке по запросу игрока;
- **в)** по почте, если её указал тот, кто записал пару.

Какой вариант выбираем?

### 3. Круговой Americano для пар

Вы пишете, что круговой парный турнир пока только в планах. Но такой вид турнира на сайте уже есть: организатор может создать Americano в парах без плей-офф, и для него есть отдельная публичная страница. Что делаем с такими турнирами:
- **а)** не даём создавать, пока круговой формат не появится в дизайне;
- **б)** показываем игрокам экран «В разработке»;
- **в)** рисуем вариант страницы «Американо · пары» без плей-офф?

### 4. «Подтверждение перед турниром сохраняется» (п. 2.2)

Сейчас игрок перед турниром получает только напоминание. Отдельного действия «подтвердить участие» у него нет, участие отмечает организатор. Что вы имеете в виду:
- новое действие игрока перед каждым турниром;
- или существующее напоминание?
