# Экспорт результатов в админке

Главный администратор открывает карточку мероприятия и нажимает «Экспорт результатов» / «Exportar resultados» / «Export results». По умолчанию выбран Excel и выключены телефоны. Окно показывает счётчики, предварительность и предупреждения. Excel содержит Tournament, Participants, Matches; CSV скачивается архивом из трёх файлов. Контакты включаются только явным выбором с подтверждением необходимости; эта возможность не означает разрешения передавать данные третьим лицам.

Просмотр не отправляет формы мероприятия или оплат, не сохраняет счёт и не создаёт запись экспорта. Скачивание использует существующий механизм CSRF. Результат виден в окне и после его закрытия; предупреждение предварительности приходит также от фактически сформированного файла. HTML страницы входа не превращается в фиктивный .xlsx. Закрытие отменяет незавершённый запрос. Контактный режим не запоминается между открытиями.

Права проверяет [сервер](endpoints/tournament-results-export.md), кнопка и диалог не рендерятся другим ролям. Нативный dialog поддерживает клавиатуру и Escape; закрытие возвращает фокус на кнопку. Учебный файл содержит только синтетические записи и не включает контакты.

## Приёмка на отдельном стенде

27.11.2026: PostgreSQL с синтетическими профилями, локальное приложение, уведомления и аналитика выключены. Рабочие мероприятия не используются.

- Настоящий браузер: Excel без телефонов и CSV с учебными телефонами сформированы, показан результат. Открытие, скачивание и закрытие не изменили значения остальных полей страницы.
- Контактный режим блокирует скачивание до отдельного подтверждения; повторное открытие сбрасывает обе галочки. Формат файла может сохранять последний выбор в пределах страницы.
- Desktop, CSS 390×844 и 320×740: окно внутри экрана, горизонтального переполнения нет; кнопки от 44px. Общее мобильное правило ширины кнопок явно переопределено для крестика.
- ES/RU/EN: показаны локализованные счётчики и сообщения. На тренировке без матчей — явные предупреждения; истёкшая сессия показала предложение войти, а не скачивание HTML.
- Клубный аккаунт открыл собственное учебное мероприятие без кнопки/диалога; прямой переход к предпросмотру отклонён. Автотесты дополнительно проверяют остальные роли и оба формата прямых запросов.
- Серверные проверки охватывают индивидуальные Americano и King of Court, парный плей-офф, круговые режимы по очкам и сетам с дополнительным финалом, классические матчи, тренировки и Cancha Abierta без результатов.
