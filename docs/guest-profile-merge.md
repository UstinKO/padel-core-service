# Объединение профилей

Предварительная GET-проверка `/api/admin/guest-profile-claims/manual?guestId=…&accountId=…` не выполняет перенос. `readiness` отделено от статуса заявки: AVAILABLE, NEEDS_RESOLUTION, FORBIDDEN, COMPLETED. При ручном выборе ID номер заявки равен нулю. Поля guest/active явно описывают тип и состояние профиля.

POST того же адреса принимает guestId, accountId, verified, verificationMethod и необязательные contactChoice, whatsappSenderPhone, replacePhone, sideChoice. KEEP_ACCOUNT сохраняет существующий телефон основного аккаунта без переноса телефонного поля гостя. USE_GUEST_PHONE допускается для валидного однозначного номера. Для отсутствующего/некорректного номера нужен KEEP_ACCOUNT и проверка IN_PERSON/OTHER. Telegram основного аккаунта и его уровень не перезаписываются.

Роли, CSRF, проверки истории/рейтинга и транзакция сохранены. Повтор для той же пары возвращает результат; другой получатель уже объединённого гостя отклоняется. `guest_profile_claims` хранит автора, время, способ проверки и contact_resolution. Телефонные заявки проверяют свой номер независимо от ручного пути.

Миграция v1.90: nullable phone_key ограничен завершёнными ручными проверками IN_PERSON/OTHER. Откат схемы блокируется, если появились записи без номера; аудит не удаляется автоматически.

## Экран администратора

В /admin/players кнопка объединения остаётся видимой при запрете, а причина показывается рядом. Статус заявки отделён от результата проверки ручного выбора. Сводка перед подтверждением описывает направление, сохраняемые данные входа/уровень и обработку контактов. При некорректном телефоне нужно выбрать KEEP_ACCOUNT и способ проверки IN_PERSON/OTHER, при разных сторонах — sideChoice, затем подтвердить личность.

Во время отправки поля и кнопка блокируются. После потери ответа интерфейс читает результат; автоматического повторного POST нет. Браузерный тест GuestProfileMergeBrowserTest включён в существующий browser job; сценарии RU/ES/EN, desktop/mobile, конфликт события и потеря ответа, артефакты target/guest-merge-browser-qa.
