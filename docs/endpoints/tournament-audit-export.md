# Выгрузка данных турниров

`GET /admin/export/tournament-audit` скачивает `1padel-tournament-audit.json`. Доступ требуется на уровне `ROLE_SUPER_ADMIN`. Сервер запрещает кэширование ответа.

Файл формата `schemaVersion: 1` содержит внутренние ID, результаты, статусы, регистрации, признаки дублей и версии матчей. Поля сравниваются с явным списком разрешённых данных. Имена, контакты, учётные данные, платежи и произвольный текст исключены из ответа.

Запрос выполняется только для чтения с ограничением в 30 секунд.
