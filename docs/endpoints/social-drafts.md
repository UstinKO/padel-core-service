# Черновики публикаций по результатам турнира

## GET /admin/tournaments/{id}/social-draft

Маршрут веб-админки под сессионной авторизацией. Разрешены административные роли с правом управления данным турниром. Только чтение, ответ `Cache-Control: no-store`.

- **200:** номер турнира, формат, категория, ISO-дата, клуб, относительная ссылка на результаты и необязательный блок будущего мероприятия. Для Team Playoff — пары и счёт финала. Для «Короля корта» — два первых места и их очки из завершённого проведения.
- **403:** недостаточно прав для управления.
- **404:** турнир отсутствует.
- **409:** турнир или проведение не завершены, итоговые места неоднозначны или имена неполны.
- **422:** формат не поддерживается. Поддерживаются Team Playoff с постоянными парами и индивидуальный «Король корта».

На странице `/admin/tournaments/{id}` раздел «Подготовить публикации» запрашивает данные при открытии. Две карточки парного турнира или общее фото индивидуального генерируются в браузере, изображения и тексты скачиваются в JPG/TXT либо одним ZIP. У Team Playoff PNG сетки можно выбрать для третьего кадра. Сервер не принимает файлы. Для Safari на iPhone нужно проверить открытие оригинального HEIC; JPEG/PNG остаются запасным вариантом для браузеров, которые не декодируют HEIC. Соцсети на этом этапе не подключены.
