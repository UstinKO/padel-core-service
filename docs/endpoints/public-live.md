# Публичные live-состояния UI v2 — LFPT-0903

Аутентификация: анонимные GET/HEAD, `no-store`; для владельца и игрока тот же публичный DTO. Ограничитель публичных запросов остаётся включённым. Записи, инициализации и уведомлений при чтении нет. Snapshot читается в read-only REPEATABLE_READ транзакции; история загружается целиком пакетными запросами, без молчаливого отсечения.

| Метод | URL | Назначение |
|---|---|---|
| GET/HEAD | `/api/public/events/{eventId}/live` | Формат и актуальный инстанс по родительскому событию |
| GET/HEAD | `/api/public/king-of-court/{kingId}/live` | Проверка текущего KoC по instance ID |

[OpenAPI 3.1](../frontend-react/contract/public-live.openapi.json) описывает поля четырёх вариантов. `metadata` содержит серверные фазу и статус события, текущий instance ID, версию проведения, время чтения, canonical URL, флаг уровней, topic и polling 20 секунд. `rounds` включают матчи, фактические пары, счёт/геймы, server winner, bye и доступные `nextMatchId/nextSlot`. `firstWinner` имеет значение null при ничьей, незавершённом матче или неполном счёте; для парного формата исход берётся из геймов, для индивидуального — из очков. Отсутствующая связь не означает разрешение достроить сетку: следующие стадии формируются существующим серверным алгоритмом.

- KING_OF_COURT: раунды CALIBRATION/MAIN, корты, рейтинг в порядке `KingOfCourtService`; `matchPoints`, `bonusPoints`, `additionalPoints.total/stages`, `totalPoints` раздельно. Место назначает сервер.
- AMERICANO: раунды и рейтинг `AmericanoService`, по умолчанию score descending; формат сетки — enum без локализованного demo-описания. Топик пустой, применяется polling.
- TEAM_PLAYOFF: квалификация разделена на серверные волны; номера матчей команды, квалификационный рейтинг и статусы, очередь, стадии и доступные связи плей-офф. Общий read-service используется и Thymeleaf.
- TEAM_PAIRS: ещё не инициализированное парное проведение; пустые раунды, формат не угадывается как Team Playoff. Неинициализированные KoC/Americano также возвращают 200 с пустыми коллекциями. FINISHED/CANCELLED определяются сервером, временный сетевой сбой фазу не меняет.

Уровни рейтинга скрываются при `mostrarNivel=false`; карточки матчей отдают только ID/имена участников. Причины и авторы ручных корректировок не входят в ответ. Нет пользовательских session-полей или административных actions.

| HTTP | code | Значение |
|---|---|---|
| 404 | LIVE_EVENT_NOT_FOUND | Нет доступного публичного события/инстанса, включая BORRADOR и inactive |
| 409 | LIVE_FORMAT_UNSUPPORTED | Round-robin Team Americano/нетурнирный формат; безопасный canonicalUrl ведёт в прежний просмотр |
| 409 | LIVE_INSTANCE_CHANGED | Старый KoC-инстанс; canonicalUrl ведёт к текущему проведению родительского события |
| 422 | LIVE_INVALID_ID | Неположительный, нечисловой или переполненный ID |
| 503 | LIVE_DATA_UNAVAILABLE | БД недоступна; без SQL и деталей инфраструктуры |

Ошибки — локализованный ProblemDetail ES/RU/EN с машинным code, `no-store`; 429 сохраняет общий Retry-After. Фильтров в endpoint нет: выбор вкладки, раунда и участника — представление уже полученного snapshot.

## Уведомления

SockJS `/ws`, STOMP SUBSCRIBE на **точный** `/topic/public/live/{eventId}`: `{"eventId":42,"type":"CHANGED"}`. Клиент SEND в этот topic отклоняется; подписка проверяет ту же публичную видимость. Шаблонные подписки брокера отклоняются, чтобы wildcard не обходил проверку. Старые точные подписки и payload не меняются.

KoC/Team Playoff уведомляют после commit; rollback не публикуется. Несколько сигналов одной транзакции объединяются по eventId. Изменения conduct history (в том числе ручные очки и restore) используют тот же механизм. Доставка in-memory не гарантирует воспроизведение пропущенных событий: клиент перечитывает snapshot после reconnect/focus и раз в 20 секунд в видимой вкладке. Для индивидуального Americano новые WS-события не добавляются. Изменения общей карточки события без conduct-сигнала отражаются через bounded polling.

Новые preview live URL получают серверные статусы/метаданные и noindex; `/preview/**` по-прежнему требует SUPER_ADMIN. Production SPA allowlist и legacy live-маршруты не переключены.
