# Изменение имени игрока в админке

`POST /admin/players/{id}/name` доступен суперадминистратору. Поля формы: `firstName`, `lastName`. Требуется CSRF-токен.

Имя обязательно. Фамилия может быть пустой. Лишние пробелы удаляются, максимальная длина каждого поля — 100 символов. Обновляются только имя и фамилия для указанного ID.

После сохранения или ошибки валидации сервер перенаправляет в карточку игрока и передаёт соответствующий статус для сообщения. Для отсутствующего ID возвращается 404.
