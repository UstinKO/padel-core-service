## Как тестировать (без изменения реального языка браузера)

### Через curl (серверная часть — HTML шаблоны)
```bash
# Русский
curl -s -H "Accept-Language: ru" http://localhost:8080/login | grep -o '<h2[^>]*>.*</h2>'

# Английский
curl -s -H "Accept-Language: en" http://localhost:8080/login | grep -o '<h2[^>]*>.*</h2>'

# Испанский (default)
curl -s -H "Accept-Language: es" http://localhost:8080/login | grep -o '<h2[^>]*>.*</h2>'

# Неподдерживаемый язык → должен упасть на es
curl -s -H "Accept-Language: fr" http://localhost:8080/login | grep -o '<h2[^>]*>.*</h2>'
```

### Через Chrome DevTools (включая JS)
1. DevTools → Network → правый клик на запрос → "Edit and Resend" — не работает для Accept-Language
2. Лучше: DevTools → Settings → Languages → добавить нужный язык первым
3. Или использовать расширение "Modify Headers" для Chrome

### Через Firefox
Настройки → Язык → добавить нужный язык первым в списке → перезапустить браузер.

### Через `ModHeader` (расширение Chrome/Firefox)
Добавить header `Accept-Language: ru` — самый быстрый способ тестирования.

## Проверка fallback (критично)

```bash
# Неподдерживаемые языки должны отображать испанский (es — default)
curl -s -H "Accept-Language: zh,zh-CN" http://localhost:8080/ | grep '<html'
# Ожидаем: <html lang="es" ...>

curl -s -H "Accept-Language: ar" http://localhost:8080/ | grep '<html'
# Ожидаем: <html lang="es" ...>

curl -s -H "Accept-Language: fr" http://localhost:8080/ | grep '<html'
# Ожидаем: <html lang="es" ...>
```

## Проверка на missing keys

```bash
# В логах приложения при работе с ru/en НЕ должно быть:
grep "NoSuchMessageException\|No message found" app.log

# В консоли браузера при работе с ru/en НЕ должно быть:
# [i18n] Missing translation key: xxx
```

## Визуальные проверки

### Нет смешения языков на одной странице
- [ ] Все элементы на странице на одном языке
- [ ] Нет испанских строк на русской версии (кроме: имена собственные, уровни C9/C8, форматы турниров)

### Layout не ломается
- [ ] Русские строки длиннее испанских — проверить что кнопки/карточки не переполняются
- [ ] Особое внимание: `nav` кнопки, `btn` кнопки в формах, заголовки карточек

### HTML в переводах рендерится корректно
- [ ] `login.error.rate_limit.text` — `<strong>` отображается жирным, не как текст
- [ ] `registro.terms` — `<a>` ссылки кликабельны
