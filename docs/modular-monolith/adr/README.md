Будущий вынос по измеренной нагрузке допустим как отдельное решение. Сейчас межмодульные вызовы — Java в одном процессе; микросервисная инфраструктура не создаётся. Исторический микросервисный план сохраняется как материал возможного будущего.

Принятие фиксируется основанием и датой. Семь модулей и PlayoffMatchingEngine подтверждены отдельным ответом владельца. Первая фаза оформлена задачами #1047 → #1048 → #1049 → #1050 → #1045. Новое решение не переписывает исторические frontend ADR задним числом.
