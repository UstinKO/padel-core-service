# Внутреннее чтение клубов

[LFPT-1440](https://github.com/UstinKO/padel-core-service/issues/1440) после [#1439](club-baseline.md). Исходный master `a206e7848e8db2f10cb911c3b8f2f7a4401a6d70` включает PR #1448.

`padel-application` владеет `InternalClubReadPort` и `ClubDetails`. Модель содержит ID, имя, исходный и форматированный адрес и признак активности. `LegacyClubReadAdapter` использует прежние `ClubRepository.findById` и `findAllById`. MapStruct преобразует строки в модель, используя существующий расчёт полного адреса. Чтение по ID находит и выключенный клуб. Пакетный результат индексируется по ID и содержит только найденные клубы.

| Потребители | Поведение |
|---|---|
| `TournamentService` | Карточка и чтение имени идут по ID. Каталог и другие списки получают клубы одним запросом по уникальным ID и сохраняют порядок турниров. При смене клуба по-прежнему проверяются право доступа и активность выбранного клуба |
| `PlayerEventsService` | Один пакет на список событий игрока. Имя выключенного клуба сохраняется. Для отсутствующего клуба имя остаётся `null` в DTO |
| `DoubleTournamentRegistrationService`, `AmericanoService`, `TournamentNotificationService` | Точечное чтение для регистрации и уведомлений. Сохраняются исходные подстановки, тексты и момент отправки |
| `IndividualTournamentReminderScheduler`, `PairTournamentReminderScheduler`, `TelegramReminderScheduler`, `SoloRegistrationSchedulerService`, `PlayerTelegramNotifications` | Точечное чтение для email и Telegram. Напоминания получают прежний исходный адрес, включая `null` в email при наличии клуба без адреса |

`PublicClubQuery` сохраняет фильтр активности для списка, карточки и счётчика публичных клубов. Внутренние чтения используют текущие транзакции вызывающих сценариев и транзакции репозитория. В корневом коде к `ClubRepository` обращаются `LegacyClubReadAdapter`, `ClubService` и `ClubAccountService`. В #1441 переходят операции двух клубных фасадов, включая используемые ими MVC/API-чтения. В #1442 единственный JPA-адаптер и Liquibase получают владельца в `padel-persistence`.
