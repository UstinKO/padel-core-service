## Что дополнено в автоматизации

- STOMP-наблюдатель разбирает SockJS-обёртку и считает именно MESSAGE указанного destination. До restore сохраняются отдельные счётчики: прежнее сообщение результата больше не может подтвердить доставку восстановления.
- После restore проверяются новые сообщения обеих тем, отсутствие отменённого счёта на legacy и React, сохранение React-страницы без навигации. Сравниваются все публичные поля снимка, включая ID/пары/корты/связи, кроме времени чтения и новой версии истории.
- В M04A неверные 5:4 не отправляются. Отдельная QA-маршрутизация удаляет CSRF-заголовок настоящего запроса: сервер возвращает действующий HTML-отказ 302 на `/error/403`, результаты и отсутствие кнопки сохраняются. Затем штатный запрос с CSRF сохраняет 6:4, кнопка появляется на той же странице и создаёт четыре QF.
- Отдельный browser smoke Expo сначала подтверждает обычный 401 с Basic challenge. Затем добавляет доступ внешнего шлюза только к same-origin API, получает фактический 200 и проверяет отрисовку событий. Это QA-адаптер, не изменение клиента или защиты.
- PR Check запускает также ранние 9/16/SF и сохраняет extended/Expo evidence. Скрипты используют только собственные синтетические данные.

## Решение, требующее владельца

Технический результат повтора и ручная приёмка — разные доказательства. Исправления уже включены; остаётся принять совокупность ручного сеанса 18.11 и текущих автоматических повторов либо повторить только M04A/M08 руками.

Для принятия сохраняются ограничения: concurrent — прежний ACCEPTED_LIMITED без измеренного перекрытия; технические HTTP/WS/JWT и исходные регистрации выполнял агент; обычный Expo в защищённом preview требует доступ шлюза и сохраняет 401 без QA-адаптера. #1067 остаётся отдельным прежним текстовым дефектом после play-in.

До явного решения владельца #1045 остаётся открытой, PR #1180 — draft; #1199 не запускается. Основание — [спецификация #1045](../../../specs/features/LFPT-1045-modular-pilot-e2e.md): «Браузерная автоматизация не заменяет отдельный ручной проход». При принятии ограниченного совокупного результата это решение записывается отдельно, без переписывания исторического журнала и без объявления новых ручных действий.
