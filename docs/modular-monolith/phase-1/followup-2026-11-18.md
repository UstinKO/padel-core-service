## Expo / ограничение preview

Браузер подтвердил: первоначальный same-origin GET /api/public/tournaments получает 401 с WWW-Authenticate: Basic. Клиент расписания использует credentials: omit; доступ шлюза не передаётся.

Для диагностики только к этому same-origin API в контролируемой QA-сессии добавлен Basic-заголовок внешнего preview-шлюза. После него API вернул 200 и 10 событий, список отрисован. Внешние запросы блокировались. Заголовок/доступы не логировались и не включены в Git.

Это подтверждает функциональную загрузку через QA-адаптер и источник прежнего 401. Обычный preview-клиент без адаптера по-прежнему имеет это ограничение. Production, мобильный код и защита шлюза не менялись; исправление продукта на основании этого 401 не заявляется.
