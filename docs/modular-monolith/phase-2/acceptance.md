# Независимая приёмка клубного среза — LFPT-1201

Источник — [issue #1201](https://github.com/UstinKO/padel-core-service/issues/1201). Backend-переносы включены через #1234 и #1238. Приёмка выполняется отдельным прогоном на jar принятого master; прежние отчёты backend-задач и PASS движка не засчитываются как новое выполнение.

[Baseline и воспроизведение](baseline.md), [ручные действия и ограничения](manual.md). Данные владельца и исходный ручной стенд первой фазы не используются. Подготовка, команды и браузер выполняются агентом, не владельцем.

## Объём

| Проверка | Способ |
|---|---|
| HTTP/JSON/headers | Реальные запросы двух GET в RU/ES/EN, отдельный baseline до обоих переносов на тех же данных |
| Порядок и активность | Полный порядок ID сопоставляется с SQL nombre/id; неактивные отсутствуют в списке и дают 404 |
| Nullable и приватность | Шесть nullable полей реального клуба; девять wire-полей; публичный текст с `<&>`; контактный маркер отсутствует в JSON/DOM |
| Браузер | Chromium 1440/390 × RU/ES/EN, список/карточка/refresh/canonical, фильтр и каталог → событие → клуб, unknown/inactive и настоящий пустой список |
| Перезапуск и возврат | Перезапуск своей JVM, прежний jar, штатный rollback; весь клубный набор и пять live snapshots, схема/Liquibase |
| Границы | Корневой verify, artifact-guards трёх библиотек, детерминизм Club, прежняя OpenAPI-проба |
| Клиенты | Отдельные frontend check/E2E и общий legacy/API/React/Expo/session/CSRF/роли/JWT smoke конечного jar |

## Итог технической приёмки

**PASS**, выполнено агентом. [Безопасная машинная сводка](acceptance-2026-11-20.json). На одной БД ответы до/после обоих переносов совпали для девяти случаев × RU/ES/EN, включая реальную пустую выборку. Текущий список отдельно проверен против SQL-порядка; девять полей, null, canonicalUrl, локализованный ProblemDetail и HTTP/headers сохранены. Полные baseline JSON не опубликованы.

Двенадцать реальных браузерных случаев прошли: шесть обычных 1440/390 × RU/ES/EN и шесть с настоящим пустым серверным списком. В обычных случаях проверены порядок/активность, nullable-карточка, экранирование публичного текста, отсутствие приватных полей, canonical, deep link/refresh, фильтр клуба, цепочка каталог → событие → клуб и unknown/inactive 404 с noindex. JavaScript errors — 0; дополнительных ответов-моков или изменения защиты не было.

Перезапуск своей JVM, переключение на jar до обоих переносов и штатный rollback сохранили полные клубные записи и пять контрольных live snapshots. Сверен отпечаток колонок схем public/ui_preview и упорядоченных записей журнала Liquibase. Синтетические клубы удалены в finally; исходные клубные записи и флаги активности восстановлены.

Общий legacy/API/React/Expo/session/CSRF/роли/участие/JWT smoke выполнен свежим прогоном на том же jar. Сценарии участия меняли отдельные fixtures Preview 2/3; пять контрольных турниров клубного baseline не пересоздавались. До/после всего общего smoke дополнительно сопоставлены их snapshots, клубные данные и отпечаток схемы/журнала. Репетиция двух выпусков, старого lazy chunk, HTTP-ошибок chunk/readiness, rollback и восстановления журнала прошла. Expo получил фактический API 200 и отрисовал события через прежний same-origin QA-адаптер; обычный preview сохраняет Basic 401.

Продуктовых регрессий в проверенном объёме не обнаружено, отдельные Fix issues не создавались. При подготовке нового наблюдателя исправлены два его селектора (заголовок карточки события h3 и неоднозначный общий блок фактов); последующий полный клубный прогон прошёл. Это доработка приёмочных тестов, не исправление production UI. Последняя дополнительная проверка локального Docker socket/Compose перед запуском наблюдателя также выполнена.

Клубный срез технически готов к продолжению поэтапной миграции. Следующий срез требует своей спецификации и проверки зависимостей; persistence/Liquibase #1051 остаётся поздней задачей. Приёмка не выделяет остальные модули и не меняет физическую БД или Swarm. Публикация/CI/ручной мерж PR учитываются отдельно. Новый ручной PASS владельца не заявляется; [принятые ограничения](manual.md) сохраняются.
