# Проверка первой версии Telegram

Сервер #1294, база master 7a40799. Новые пользовательские сценарии не включались на production; реальный Telegram в проверках не вызывается.

- Компиляция Java 17 release на установленном JDK 21 успешна, frontend-сборка отключена для серверного прогона.
- 17 целевых unit-тестов: привязка/хеш/срок/идентичность, typed Telegram API, успешная/заблокированная/неопределённая отправка, защита повторов, подтверждение/чужой игрок/перенос/цикл регистрации, поздняя регистрация и выключенная автоматическая рассылка. Ошибок нет.
- Maven verify запущен с остановкой после первой ошибки. PostgreSQL-соединение запрещено средой: java.net.SocketException: Operation not permitted. Полный интеграционный прогон, включая PlayerTelegramStoreIntegrationTest, локально не выполнен; требуется CI с отдельной PostgreSQL.
- docs-drift и check-agent-migration: 0 расхождений. git diff --check успешен.
- relay: запущены 48 тестов, 6 ошибок из-за запрещённого bind локального сокета. Изменений relay нет.
- Браузерный сценарий с сервером/БД и реальный бот не проверены. PR остаётся черновиком до прохождения требуемых проверок; отправка, мерж и деплой не выполнялись.

Первый полный CI выполнил 1263 теста приложения: 2 ошибки в новой fixture (обязательный preferred_locale не был задан). В тестовых профилях язык установлен явно; требуется повтор CI. Остальные тесты прошли, 2 штатных пропуска. Предыдущая попытка останавливалась до приложения на Maven Central 429 и была повторена.

Подтверждение в привязанном личном Telegram использует права авторизованного участника, как кабинет сайта; срок email-ссылки не ограничивает этот канал. Проверены просроченная email-ссылка, чужой игрок, перенос и другая версия регистрации. Повтор CI после исправления preferred_locale прошёл этап Build and test; остальные этапы и новая финальная ревизия проверяются отдельно.
# Дополнение: предпочтение связи

По выбору владельца игрокам выделен отдельный бот: новый секрет TELEGRAM_PLAYERS_BOT_TOKEN без fallback на бот технических инцидентов. API больше не зависит от TelegramProperties служебного канала. После разделения прошли 21 целевой backend unit-тест; тест доступности проверяет собственный токен и feature flag.

Добавлены серверное сохранение способа связи, прекращение Telegram при выборе WhatsApp, аннулирование старых ссылок, сохранение locale сайта при создании ссылки и сведения о ручных контактах в сводке. Unit-тесты проверяют сохранение для текущего профиля без внешнего bot token и языковой fallback. Интеграционный тест проверяет независимость аккаунтов, отключение, недействительность старой ссылки, пакетное чтение и повторное подключение. Запуск интеграционных тестов требует изолированной PostgreSQL; локальное ограничение сокетов сохраняется.

Последний опубликованный до расширения коммит `7b5ea2d` прошёл полный PR Check: https://github.com/UstinKO/padel-core-service/actions/runs/45281268027. Для нового объёма это не заменяет повторный CI. После расширения прошли 20 целевых unit-тестов; API/миграция дополнительно проверяются в CI с PostgreSQL. Включён актуальный master `094d1c4`, миграция предпочтения получила v1.87 после v1.86 организаций.

## Ограничение первого живого прохода

Пилот по умолчанию закрыт: один player ID и один event ID, без заполненных ID никто не может подключиться или получить DM. Защитные проверки охватывают прежние ссылки и связи, ручной запрос, автоматический планировщик, подтверждение и сводку. Проверки пилота добавлены отдельно от общей логики. Реальная Telegram-отправка и production-включение ещё не выполнялись.

Пилот: локально 30 целевых Java-тестов прошли (включая сохранение старого polling/DM для остальных); docs-drift и agent-migration без расхождений. Интеграционный сценарий проверяет реальные API/БД на отдельной CI-базе. Живые Telegram и production пока не проверены.
