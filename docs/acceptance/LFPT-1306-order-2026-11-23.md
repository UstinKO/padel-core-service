Обычный серверный список `/admin/tournaments`, одна серверная задача. Таблица и мобильные карточки получают один порядок. Календарь, виджет последних созданных турниров и действующие правила доступа сохраняются. Пагинации в этом списке нет: сортируется весь результат.

## Автоматические проверки
- Полный `./mvnw verify`: все модули успешны; bootstrap — 1260 тестов, 0 сбоев, 0 ошибок, 2 штатных пропуска браузерных тестов с отдельным условием запуска.
- Четыре новых теста чистой сортировки: разные даты/время и порядок ID, сегодняшний день/прошлое/статусы, одинаковый старт/пустые поля/пустой список, сохранённые локальные времена разных зон.
- Три новых HTTP/сервисных интеграционных теста: общий и клубный порядок; комбинированные фильтры и сброс с чужим организатором на общей площадке; создание и редактирование даты/времени через действующий сервис. Отказ в прямом административном запросе чужого события проверен как 403.
- 48 тестов relay, docs-drift, check-agent-migration, git diff --check — успешно.
- Первый полный прогон выявил пропущенный обязательный контакт организатора в новой тестовой фабрике. Фабрика исправлена; затем весь набор повторно прошёл успешно. Рабочая валидация для обхода тестов не менялась.
