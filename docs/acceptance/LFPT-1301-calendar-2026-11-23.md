# Приёмка компактного календаря — 23.11.2026

Сервер #1300, интерфейс #1301. Отдельная локальная PostgreSQL, синтетические аккаунты и мероприятия; рабочий сайт и реальные профили не менялись. Отправка писем, Telegram, аналитика и фоновые задания стенда отключены.

Проверки в настоящем браузере:

| Сценарий | Результат |
|---|---|

Автоматические проверки: полный Maven verify обеих частей, в bootstrap 1253 теста без ошибок, 2 штатных пропуска; остальные модули также успешны. Frontend check: 60 тестов и сборка, 9 тестов календарных дат Node, 48 relay; docs-drift, check-agent-migration, git diff --check.

Применены только существующие статусы системы. Статус «идёт» не выводится предположением по времени: отдельного такого значения в TournamentStatus нет. Физические телефоны не использовались; мобильная приёмка выполнена в браузере с указанной шириной.

Скриншоты хранятся в локальных результатах задачи. Публикация на рабочий сайт не выполнялась.
